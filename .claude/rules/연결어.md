# 연결어

문장과 문장을 잇는 연결어는 글의 리듬과 논리 흐름을 만든다. 스코프.md의 "담화론/응집장치", "형태소/연결어미" 결정 항목을 구체화한다.

근거는 두 종류다. 원칙은 한국어 담화론과 문서작성원칙.md를 따른다. 증거는 BZCF와 AI 번역 코퍼스의 Level 4 비교 결과다.


## 원칙

**우선순위: 의미 정확성 > 맥락 보존 > 자연스러움 > 간결함.** 아래 금기와 대안은 이 우선순위 안에서만 적용한다. 연결어를 다양화하되 원문의 논리 관계(인과/대조/추가/순서)가 바뀌면 안 된다. 접속 부사를 줄이되 흐름이 끊기면 유지한다.

한국어의 연결어는 두 층에서 작동한다. 첫째는 연결어미다. "~해서", "~하면", "~하고", "~하지만"처럼 동사·형용사 어미에 녹아서 절 관계를 표현한다. 둘째는 문장 시작 접속 부사다. "그래서", "하지만", "그리고", "사실", "특히", "왜냐하면"처럼 문장 처음에 놓여 이전 문장과의 관계를 명시한다.

좋은 한국어는 두 층을 골고루 쓴다. 연결어미로 절을 엮어 호흡을 만들고, 문장 시작 접속 부사로 중요한 전환을 강조한다. 접속 부사가 없어도 되는 자리에 붙이면 과잉이고, 있어야 할 자리에 없으면 흐름이 끊긴다.

연결어 레퍼토리의 크기가 글의 성숙도를 드러낸다. "그리고", "그래서", "하지만" 세 개만 반복하면 초보 번역 티가 난다. 한국어에는 "사실", "특히", "왜냐하면", "게다가", "반면", "즉", "결국", "한편", "어쨌든"처럼 고유한 담화 장치가 풍부하다. 이 레퍼토리를 살려야 자연스러운 한국어가 된다.

문서작성원칙.md에 이미 적혀 있듯, 연결어는 "문장 사이의 관계를 명확하게" 하는 도구다. 인과, 대조, 순서, 추가, 예시 각각에 맞는 연결어를 골라 쓴다.


## 증거

Level 4 비교에서 BZCF와 AI의 연결어 사용이 극명하게 갈렸다.

```
연결어 종류 수        BZCF 33종, AI 14종  (BZCF 2.4배 다양)
연결어 반복률         BZCF 0.29, AI 0.26  (비슷)
```

AI는 연결어 레퍼토리가 빈곤하다. 이는 문장 시작 접속 부사의 종류를 세어본 결과다. BZCF는 33종류를 고르게 쓰는 반면, AI는 14종류에 그쳤고 그중 몇 개에 편중됐다.

개별 연결어별 사용 빈도(/1000줄)는 다음과 같다.

```
하지만           BZCF 34.8, AI 16.6  (BZCF 2.1배)
그리고           BZCF 21.7, AI 31.1  (AI 1.4배)
그래서           BZCF 17.9, AI 18.6  (거의 동률)
사실             BZCF 7.1, AI 0.0    (BZCF 전용)
왜냐하면         BZCF 3.0, AI 0.0    (BZCF 전용)
특히             BZCF 2.5, AI 0.0    (BZCF 전용)
게다가           BZCF 1.9, AI 0.0    (BZCF 전용)
어쨌든           BZCF 1.5, AI 0.0    (BZCF 전용)
따라서           BZCF 1.1, AI 0.0    (BZCF 전용)
즉               BZCF 0.8, AI 0.0    (BZCF 전용)
반면/반면에       BZCF 1.3, AI 2.1    (AI 약간 많음)
결국             BZCF 4.9, AI 2.1    (BZCF 2.3배)

그러니           BZCF 1.8, AI 10.4   (AI 5.9배)
이것은           BZCF 0.8, AI 8.3    (AI 9.9배)
또               BZCF 1.3, AI 8.3    (AI 6.5배)
```

결과가 두 가지를 보여준다. 첫째, AI는 "그리고/그래서/하지만"에 편중되고 담화 부사 레퍼토리가 부족하다. "사실", "왜냐하면", "특히", "게다가", "어쨌든"을 전혀 사용하지 않는다. 이 표현들은 한국어가 영어보다 풍부한 지점이다.

둘째, BZCF는 "하지만"을 AI의 2배로 쓴다. 특이한 발견이다. BZCF의 발화자들이 구어체 전환을 "하지만"으로 자주 표시하기 때문으로 보인다. "그리고 말이죠", "하지만 말이에요" 같은 패턴이 담화 리듬을 만든다.


## 금기

조건부 금기다. 각 항목 오른쪽의 "단, ~일 때는 유지"가 예외다.

### 레퍼토리 빈곤

```
"그리고/그래서/하지만" 편중                →  다양한 연결어로 분산. 단, 문장 간 관계가 실제로 3가지 패턴만 반복되면 억지 다양화 금지
접속 부사 전 문장 부착                    →  필요한 자리에만. 단, 논리 전환이 큰 대목은 명시
같은 접속 부사 3문장 연속                  →  교체. 단, 의도적 반복(수사적 강조)이면 유지
```

### 번역투 연결

```
그리고 (and 직역, 문장 연결 남발)          →  연결어미 "~하고"로 녹임. 단, 강한 추가·전환 신호가 필요하면 유지
또한 (also 직역)                        →  "게다가", "아울러", "나아가". 단, 나열형 문어체·공식문서에서는 유지
그러나 (but 격식 과잉)                    →  "하지만", "그런데". 단, 공식·학술 문체에서는 "그러나"가 자연스러움
더구나 (moreover 직역 느낌)               →  "게다가", "더욱이". 단, 격식체 논증문에서는 유지
그래서 그 (so that 직역)                  →  "따라서", "그러니". 단, 구어적 대화에서는 "그래서"만 자연스러움
이것은 ~이다 (This is ~ 직역 시작)         →  주어 생략 또는 직접 서술. 단, 정의·선언 문장이면 유지
```

### 연결어미 남용

```
~어서 (원인 연결어미) 남용                 →  맥락 확인. 원인이 아니면 "~고"로. 단, 실제 인과 관계면 유지
~는데 (역접 연결어미)를 단순 나열에 사용    →  "~고" 사용. 단, 반전·대조 의미면 유지
~면 (조건)을 단순 선후에 사용              →  "~자", "~고" 사용. 단, 가정·조건이 핵심이면 유지
```


## 대안

### 레퍼토리 확장

인과
```
그래서 / 그러니까 / 그러니 / 그러므로 / 따라서 / 결국 / 그 결과
```

대조·역접
```
하지만 / 그런데 / 반면 / 반면에 / 오히려 / 그럼에도 / 그렇지만 / 한편
```

추가·강조
```
그리고 / 또한 / 또 / 게다가 / 더욱이 / 나아가 / 특히 / 무엇보다
```

근거·이유
```
왜냐하면 / 왜냐면 / 이는 / 사실 / 실은 / 구체적으로 / 이유는
```

요약·결론
```
즉 / 곧 / 요컨대 / 결국 / 정리하면 / 한마디로 / 결론적으로
```

예시
```
예컨대 / 예를 들어 / 가령 / 이를테면
```

### 레퍼토리 활용 예시

```
(빈곤) 이 방식은 빠르다. 그리고 싸다. 그리고 안정적이다.
(풍부) 이 방식은 빠르다. 게다가 싸고, 무엇보다 안정적이다.

(빈곤) 속도가 떨어졌다. 그래서 해결이 필요하다.
(풍부) 속도가 떨어졌다. 이는 사용자 경험을 해치므로 시급히 해결해야 한다.

(빈곤) 비용이 증가했다. 하지만 매출도 증가했다.
(풍부) 비용이 증가했다. 반면 매출도 증가했으니 순이익은 비슷하다.
```

### 연결어미로 녹이기

접속 부사를 남발하는 대신 연결어미로 절을 엮는 것도 방법이다.

```
(부사 남발) 속도가 느리다. 그래서 수정이 필요하다.
(어미 활용) 속도가 느려서 수정이 필요하다.

(부사 남발) 비가 온다. 하지만 나가야 한다.
(어미 활용) 비가 오지만 나가야 한다.

(부사 남발) 그는 말했다. 그리고 떠났다.
(어미 활용) 그는 말하고 떠났다.
```

두 방법은 상호 보완한다. 긴 논리 전환은 문장 시작 부사로, 짧은 절 연결은 연결어미로 쓴다.


## 과교정 경계

연결어 다양화·간결화를 밀어붙이다 원문의 논리 관계가 왜곡되는 경우를 경계한다.

### 관계 오용으로 논리 왜곡

```
(원문) A is slow. Therefore, B is needed.  (인과)
(번역투 주의) A는 느리다. 그래서 B가 필요하다. (자연스러움)
(과교정) A는 느리다. 하지만 B가 필요하다.  ← 인과를 대조로 오용 (다양화 욕심)
```

다양화를 추구하더라도 **인과/대조/추가/순서**의 논리 관계는 절대 바꾸지 않는다. 원문의 `therefore / however / moreover / then`에 맞는 범주를 지킨다.

### 연결어미로 녹여 원인·조건 소실

```
(원문) If it rains, the event will be cancelled
(번역투 주의) 비가 오면 행사가 취소된다 (~면)
(과교정) 비가 오자 행사가 취소된다 (~자)  ← 조건이 연속 사건으로 변형
(적절) 비가 오면 행사가 취소된다
```

조건·가정의 "~면"을 연속 선후의 "~자/~고"로 바꾸면 의미가 달라진다. 어미 선택은 원문의 논리 관계에 일치해야 한다.

### 접속 부사 전면 제거로 흐름 단절

```
(원문) We tried X. However, X failed. Therefore, we moved to Y.
(번역투 주의) X를 시도했다. 하지만 X는 실패했다. 그래서 Y로 전환했다.
(과교정) X를 시도했다. X는 실패했다. Y로 전환했다.  ← 논리 관계가 명시되지 않아 독자 추론 부담
(적절) X를 시도했다. 하지만 실패해서 Y로 전환했다.  ← 부사·어미 혼합
```

접속 부사 감축은 "과잉 명시"를 겨냥한다. 논리 전환이 중요한 대목은 명시적 연결어를 유지한다.

### 공식 문체에서 구어체 연결어로 격식 이탈

```
(원문, 논문·법률) Therefore, the hypothesis is rejected
(번역투 주의) 따라서 가설은 기각된다
(과교정) 그러니까 가설은 기각된다  ← 학술 격식이 구어로 이탈
(적절) 따라서 가설은 기각된다
```

격식 층위(학술·법률·공식)에서는 "따라서·그러나·또한" 같은 격식 연결어가 자연스럽다. 구어 연결어로 바꾸지 않는다.


## 체크리스트

### 1단계: 다양성·자연성 확인

```
□ "그리고/그래서/하지만" 세 개에 80% 이상 편중되지 않았는가
□ "사실", "특히", "왜냐하면", "게다가", "어쨌든", "한편" 같은 한국어 고유 담화어를 최소 2종 이상 썼는가
□ 같은 접속 부사가 한 문단에 3회 이상 반복되지 않았는가
□ 연결어미(~해서, ~하지만, ~하고)로 녹일 수 있는 절이 부사로 나뉘어 있지 않은가
□ "이것은 ~", "그것은 ~" 같은 영어 직역 시작이 없는가
□ 접속 부사가 논리 관계에 맞는가 (그래서로 대조, 하지만으로 인과 등 오용 방지)
□ 모든 문장이 접속 부사로 시작하지 않는가 (과잉 명시 회피)
```

### 2단계: 과교정 역검사

```
□ 다양화 과정에 인과/대조/추가/순서 관계가 뒤바뀌지 않았는가
□ 연결어미 변경이 조건·가정·연속 사건의 의미를 왜곡하지 않았는가
□ 접속 부사를 삭제한 자리에서 논리 전환이 독자에게 전달되는가
□ 공식 문체에서 구어 연결어로 격식이 이탈하지 않았는가
□ 원문의 연결어(therefore/however/moreover 등)가 한국어에서도 동등한 관계로 재현됐는가
```
