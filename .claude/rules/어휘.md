# 어휘

어휘 선택이 글의 격식·온도·신뢰도를 결정한다. 스코프.md의 "단어/한자어-고유어 비율", "단어/부사", "단어/동의어 어감" 결정 항목을 구체화한다.

근거는 두 종류다. 원칙은 국어 어휘론의 일반적 분류와 번역 규범을 따른다. 증거는 BZCF와 AI 번역 코퍼스의 Level 4 비교 결과다.


## 원칙

**우선순위: 의미 정확성 > 맥락 보존 > 자연스러움 > 간결함.** 아래 금기와 대안은 이 우선순위 안에서만 적용한다. 과장 형용사를 제거하되 원문의 평가·수식어가 핵심 정보일 때는 유지한다. 한자어를 줄이되 전문 용어·법률 용어처럼 대체 불가한 한자어는 유지한다.

한국어 어휘는 크게 고유어, 한자어, 외래어로 나뉘고 각자 다른 감정을 실어 나른다. 같은 의미라도 어느 층을 고르느냐에 따라 글의 격식과 친밀감이 달라진다.

고유어는 구어적이고 따뜻하다. "도움", "생각", "바라다"처럼 일상 대화에서 자연스럽게 나오는 단어다. 한자어는 격식 있고 추상적이다. "지원", "사고", "희망"처럼 같은 의미를 더 공식적으로 표현한다. 외래어는 전문성과 이국성을 동시에 준다. "서포트", "아이디어", "호프"처럼 맥락에 따라 세련되거나 어색할 수 있다.

AI 텍스트의 대표 신호 중 하나는 과장 형용사의 반복이다. "매우", "중요한", "탁월한", "주목할 만한" 같은 단어가 특별한 근거 없이 반복되면 글이 AI 같아진다. 한국어 화자는 강조가 필요할 때 부사를 바꾸거나 문장 구조를 바꾸지, 같은 부사를 반복하지 않는다.

부사는 격식도를 미세 조절한다. "매우"(격식) vs "정말"(자연스러움) vs "엄청"(구어) vs "무지"(방언/구어)가 같은 강도를 표현하지만 온도가 다르다. 한자어 부사만 쓰면 딱딱하고, 고유어 부사만 쓰면 가벼운 느낌이 된다. 의도적으로 섞는 게 자연스럽다.

한자어 비율이 AI의 표지라는 속설은 모델에 따라 다르다는 점에 주의해야 한다. KatFishNet 연구(ACL 2025)는 Qwen2가 Sino-Korean nominalization을 과잉 사용한다고 보고했지만, Claude Sonnet은 오히려 BZCF 발화자(CEO·투자자들)보다 한자어를 덜 쓰는 것으로 나타났다. 즉 "한자어가 많으면 AI"라는 규칙은 성립하지 않는다. 모델별 프로파일이 다르다.


## 증거

Level 4 비교에서 AI 시그니처 어휘로 드러난 것들이다.

```
중요한           AI 3.9배  (BZCF 13.7 → AI 53.8 /1000줄)
매우             AI 4.6배
탁월한           AI 28.1배 ← 과장 형용사 극단
주목할           AI 21.1배
돋보이           AI ∞배 (BZCF 0회)
흥미로운         AI 2.7배
다양한           AI 2.0배
인상적           AI 2.6배
```

AI가 이들 어휘를 많이 쓰는 이유는 "안전한 격식 표현"이기 때문이다. 구체적 근거 없이 평가할 때 "탁월한 성과", "주목할 만한 변화", "돋보이는 특징" 같은 공허한 과장으로 채운다. BZCF 번역가는 같은 자리에 구체적 묘사를 넣거나 칭찬 표현 자체를 생략한다.

반면 한자어 비율은 반전된 결과를 보였다.

```
한자어 likely 비율      BZCF 76.1%, AI 73.5%
```

Claude Sonnet은 BZCF보다 한자어를 약간 더 적게 사용했다. BZCF 발화자들은 CEO·투자자·기술인으로, "경제 성장률", "사업 모델", "자율 주행", "데이터 센터" 같은 한자어 복합 명사를 자주 쓴다. AI는 오히려 이런 도메인 어휘를 덜 사용하는 경향이 있었다.

어휘 풍부도(MATTR, window=500)는 비슷하거나 BZCF가 약간 높았다.

```
MATTR            BZCF 0.572, AI 0.540  (BZCF 6% 더 풍부)
```

내용어 기준으로는 BZCF가 약간 풍부했지만 차이가 작다. 통계적으로 강한 결론을 내리기에는 AI 샘플이 작다.


## 금기

조건부 금기다. 각 항목 오른쪽의 "단, ~일 때는 유지"가 예외다.

### 과장 형용사

```
매우 (특히 "매우 중요한", "매우 큰")      →  근거 없이 반복되면 회피. 단, 실제로 극단적 강도가 필요한 자리는 유지
중요한                                 →  근거 없는 사용 회피. 단, 중요성이 글의 논지이고 구체 설명이 뒤따르면 유지
탁월한 / 주목할 만한 / 돋보이는          →  과장형 회피. 단, 원문 텍스트에 동등한 강조(exceptional, remarkable)가 있으면 유지
인상적인 / 흥미로운                     →  회피. 단, 개인의 실제 감상·평가를 서술하는 맥락이면 유지
상당한 / 두드러지는 / 괄목할 만한        →  회피. 단, 통계·수치가 뒷받침될 때는 유지
```

"왜 매우/탁월/주목할 만한가"를 설명할 수 있으면 유지, 공허한 반복이면 제거. **원문에 명시적 강조어가 있으면 번역에서도 강조어를 유지한다.**

### 과장 부사·수식어

```
매우            →  "정말", "꽤", "아주"로 대체 또는 생략. 단, very/extremely 직역이 자연스러우면 유지
너무            →  문어에서는 "지나치게", "심하게". 단, 구어 톤에서는 유지
항상 / 언제나    →  "늘", "대개", "자주"로 대체. 단, 예외 없는 보편을 강조하면 유지
절대 / 반드시    →  생략. 단, 강한 당위·금지를 원문이 강조하면 유지
```

### 공허한 대체 어휘

```
다양한 (종류 나열 없음)      →  "여러", "몇 가지"로 대체. 단, 원문에 various/diverse가 있고 종류 나열이 이어지면 유지
여러 가지 (숫자 없음)        →  구체 숫자·예시로 대체. 단, 실제로 수가 많거나 불확정이면 유지
이러한 / 그러한 (막연한 지시) →  구체 명사 반복. 단, 앞 문장의 특정 대상을 명확히 지시하고 반복이 장황하면 유지
```

### 의존명사 과잉

```
것 ("~하는 것")             →  명사형 어미(~기, ~음) 또는 동사화. 단, 추상화가 필요한 자리는 유지
수 ("할 수 있다" 남발)       →  맥락 생략 또는 "가능하다" 동사화. 단, 능력·가능성이 핵심이면 유지
점 ("~라는 점")             →  직접 언급으로 재구성. 단, 논점을 명시적으로 가리킬 때는 유지
```


## 대안

### 과장 대신 묘사

```
(AI) 이 영화는 매우 인상적이었다.
(대안) 이 영화는 마지막 10분이 기억에 남는다. / 이 영화는 주인공의 표정이 강렬했다.

(AI) 탁월한 성과를 거뒀다.
(대안) 매출이 3배로 뛰었다. / 업계 1위를 차지했다.

(AI) 주목할 만한 변화가 있었다.
(대안) 변화가 있었다: 사용자가 40% 늘었다.

(AI) 다양한 분야에서 활용된다.
(대안) 의료, 교육, 금융에서 활용된다.

(AI) 이러한 문제가 있다.
(대안) 이 문제(구체 명사)가 있다. / 속도 문제가 있다.
```

### 부사 다양화

```
(반복) 매우 중요하고 매우 크다.
(대안) 정말 중요하고 꽤 크다. / 핵심적이고 덩치가 상당하다.

(반복) 매우 매우 좋다.
(대안) 정말 좋다. / 아주 좋다. / 감탄이 나올 정도다.
```

### 한자어와 고유어 섞기

```
(딱딱) 본 서비스는 귀하의 개인정보를 보호합니다.
(자연) 이 서비스는 여러분의 개인정보를 지킵니다.
(중간) 본 서비스는 여러분의 개인정보를 보호합니다.

(딱딱) 지속적으로 증가하는 추세다.
(자연) 꾸준히 늘고 있다.
(중간) 꾸준히 증가하는 추세다.
```

상황에 따라 층을 섞는다. 법률·약관·공식 공지는 한자어 비중이 높아도 자연스럽고, 사용자 안내·온보딩은 고유어 비중이 높아야 편안하다.

### 의존명사 축소

```
(과잉) 그가 말한 것은 사실이다.
(대안) 그가 말한 건 사실이다. / 그 말은 사실이다.

(과잉) 더 나아질 수 있다.
(대안) 더 나아진다. / 나아질 여지가 있다.

(과잉) 중요한 점은 시간이다.
(대안) 중요한 건 시간이다. / 시간이 중요하다.
```


## 과교정 경계

어휘를 단순화하다 원문의 강도·평가·뉘앙스가 사라지는 경우를 경계한다.

### 원문 강조 삭제로 정보 손실

```
(원문) This is an exceptionally rare opportunity
(번역투 주의) 이것은 매우 드문 기회입니다
(과교정) 드문 기회입니다  ← "exceptionally" 강도가 사라져 평범한 진술로 변형
(적절) 이례적으로 드문 기회입니다 / 흔치 않은 기회입니다
```

원문에 명시적 강조어(exceptionally, remarkably, significantly)가 있으면 번역에서도 강조를 유지한다. "과장 형용사 회피"는 공허한 반복을 겨냥하지, 실제 강조를 제거하라는 뜻이 아니다.

### 전문 한자어 과잉 축소

```
(원문) pleaded guilty to the charges
(번역투 주의) 혐의에 대해 유죄를 인정했다
(과교정) 잘못을 인정했다  ← 법적 용어가 일상어로 변형되어 사실 관계 모호
(적절) 혐의 유죄 답변을 했다 / 혐의 인정했다
```

법률·의료·학술 전문 한자어는 대체 불가하면 유지한다. "한자어 회피"는 공식적 과잉 명사화를 겨냥하지, 정확한 전문 용어를 풀어쓰라는 뜻이 아니다.

### 평가 맥락 삭제로 서사 손실

```
(원문) I found her performance deeply moving
(번역투 주의) 저는 그녀의 연기가 매우 감동적이었습니다
(과교정) 그녀의 연기를 봤습니다  ← 화자의 감상이 사라져 단순 서술로 변형
(적절) 그녀의 연기가 깊이 감동적이었습니다 / 그녀의 연기에 깊이 감동받았습니다
```

1인칭 서사·평가문에서 개인의 감상은 핵심 정보다. "평가 대신 묘사"는 근거 없는 칭찬을 겨냥하지, 실제 감상·평가를 지우라는 뜻이 아니다.

### 의존명사 제거로 추상 층위 붕괴

```
(원문) The ability to think clearly matters most
(번역투 주의) 명확하게 사고하는 것이 가장 중요하다
(과교정) 명확히 생각하기가 가장 중요하다  ← 추상적 "능력"이 구체적 "행동"으로 축소
(적절) 명확하게 사고할 수 있는 능력이 가장 중요하다 / 명확한 사고가 가장 중요하다
```

"것·수·점"이 추상 개념·능력·원칙을 나타낼 때는 유지한다. 명사화가 의미 정확성에 필수적이면 의존명사를 남겨둔다.


## 체크리스트

### 1단계: 어휘 선택 확인

```
□ "매우", "중요한", "탁월한", "주목할 만한", "돋보이는"이 근거 없이 쓰이지 않았는가
□ 같은 부사(매우, 정말, 아주)가 한 문단에 반복되지 않았는가
□ "다양한", "여러 가지", "이러한", "그러한"이 구체성을 숨기지 않았는가
□ 부사를 두 종류 이상 섞어 온도를 조절했는가
□ 한자어와 고유어가 대상 독자에 맞게 섞였는가 (약관 ≠ 온보딩)
□ "~것", "~수", "~점" 같은 의존명사가 남발되지 않았는가
□ 평가 대신 묘사로 대체될 수 있는 자리가 없는가 (근거 없는 칭찬에 한정)
□ 글의 과장 농도가 내용의 실제 중요도에 비례하는가
```

### 2단계: 과교정 역검사

```
□ 원문의 명시적 강조어(exceptionally, deeply 등)가 번역에서 사라지지 않았는가
□ 법률·의료·학술 전문 한자어가 일상어로 무리하게 풀어쓰이지 않았는가
□ 1인칭 서사·평가문에서 화자의 감상이 객관 서술로 축소되지 않았는가
□ "것·수·점" 중 추상 개념·능력을 가리키는 자리가 부당하게 삭제되지 않았는가
□ 축약한 어휘가 원문의 격식 층위(법률어·구어·학술어)와 일치하는가
```
