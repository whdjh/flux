# 번역투

AI가 한국어를 생성할 때 영어 구문·어미·관용구를 기계적으로 옮겨 붙이는 현상을 정리한다. 스코프.md의 "형태소/조사 번역체", "문장/번역체 구문", "문장/능동수동", "문장/이중피동" 결정 항목을 구체화한다.

근거는 두 종류다. 원칙은 나무위키 번역체문장/영어와 국립국어원 영한 번역투 자료를 따른다. 증거는 BZCF 번역가 코퍼스 20,359줄과 AI 번역(Claude Sonnet) 코퍼스를 형태소 단위로 비교한 Level 4 분석 결과다. 이 파일에 나오는 배율은 `/1000줄` 또는 `/1000형태소` 기준이다.


## 원칙

**우선순위: 의미 정확성 > 맥락 보존 > 자연스러움 > 간결함.** 아래 금기와 대안은 이 우선순위 안에서만 적용한다. 번역투를 피하되 원문 의미가 바뀌거나 인과·주체 정보가 빠지면 번역투를 유지한다.

한국어는 교착어이면서 주제 중심 언어다. 그래서 영어의 통사 구조(SVO, 주어 필수, 수동태 선호, 접속사 필수)가 그대로 전이되면 어색해진다. 번역투의 본질은 "영어 문장 구조를 한국어 어미·조사에 기계적으로 대응시킨 것"이다.

자연스러운 한국어는 세 가지 방향으로 기울어진다. 첫째, 행위자 중심 능동문을 선호한다. 둘째, 연결어미(-해서, -하면)와 관형어를 활용해 문장 간 관계를 녹인다. 셋째, 같은 의미라도 더 간결한 조사와 동사를 고른다.

번역투 제거의 목표는 "원문 의미를 유지하면서 한국어 화자가 자연스럽게 읽을 수 있는 형태로 재구성"이다. 직역을 피하고 의미 단위 재구성을 선호한다.


## 증거

Level 4 비교에서 AI가 BZCF보다 압도적으로 많이 쓴 번역투 상위 15개다. 숫자는 `(AI 빈도 / BZCF 빈도) 배율` 형식이다.

```
A, B 또는 C               72.9배  (Oxford or 직역)
아무것도 ~지 않            40.5배  (nothing 직역)
~(으)ㄹ 것이다             36.4배  (will 직역)
~에 관하여/관한            29.2배  (regarding 직역)
~처럼 보이                12.1배  (look like 직역)
~로 하여금                12.1배  (let/make 직역)
최고 ~중 하나              8.1배   (one of the best 직역)
아무도 ~지 않              6.9배   (nobody 직역)
can't ~ enough            6.9배   (아무리 ~해도 부족 직역)
그/그녀/그들 남발          5.6배   (he/she/they 직역)
A, B 그리고 C              4.9배   (Oxford and 직역)
~로부터                   4.9배   (from 직역)
~어야 한다                4.5배   (must 직역)
~에 대해(서)               3.6배   (about 직역)
~게 만들다                3.1배   (make X do 직역)
```

형태소 정규화 후 피동 표현의 차이는 작다. 전체 피동은 1.0~1.2배 수준이지만, 이중피동은 AI가 2.6배 많다. 나무위키가 비문으로 지목한 "잊혀지다", "쓰여지다", "되어지다" 같은 표현이 AI 쪽에서 더 자주 나타난다.

Level 4에서 자동 발굴한 n-gram 중 AI 편중이 가장 큰 표현은 "세부 사항 관여"(LLR 29.5, AI 6회 vs BZCF 0회)였다. 영어 "get into the details" 또는 "get into the weeds"의 직역으로 추정되며, 기존 레퍼런스 문서에 등재되지 않은 새 상투구다.


## 금기

조건부 금기다. 조건은 **원문에서 직접 확인 가능한 표면 단서**로 판단한다 (주관적 해석이 아님).

### 구문 전이

```
~어야 한다 / ~어야만 한다       →  must 회피. 단, 원문에 must/shall/have to/required가 있으면 유지
~(으)ㄹ 것이다                 →  will 회피. 단, 원문에 will/shall/going to/predict/expect가 있으면 유지
~할 수 있다                    →  can 회피. 단, 원문에 can/able to/possible/allowed가 있으면 유지
~에 관하여 / ~에 관한           →  regarding/concerning 회피. "~에 대한" 또는 주제격("~은/는")으로 대체 (예외 없음)
~에 대해(서) / ~에 대한         →  about 회피. 단, 원문이 논문·학술·법률 장르이고 about이 범위 한정에 쓰이면 유지
~로부터                       →  from 회피. "~에서", "~한테서"로 대체 (예외 없음)
~에 있어(서)                   →  in terms of/regarding 회피. "~에서"로 대체 (예외 없음)
~로 하여금                     →  let/make 회피. 사동 어미(-게 하다, -이/히/리/기-)로 재구성 (예외 없음)
~로 인해                      →  due to 회피. "~ 때문에"로 대체 (예외 없음)
~에 의해(서)                   →  by 수동태 회피. 단, 원문 행위자가 불명(by 없는 수동)이면 수동 유지
~에 위치해 있다                →  be located 회피. "~에 있다"로 대체 (예외 없음)
```

"~에 의하면"은 "~에 따르면"으로 관용화돼 번역투로 취급하지 않는다.

### 관용구 전이

```
A, B 그리고/또는 C             →  Oxford comma 회피. "A, B, C" 또는 "A와 B, C"로 대체 (예외 없음)
아무도 ~지 않는다              →  nobody 회피. "~는 사람이 없다". 단, 원문이 구어 대사(따옴표 안)이면 유지 가능
아무것도 ~지 않는다            →  nothing 회피. "~는 것이 없다"로 대체 (예외 없음)
가장 ~중 하나 / 최고 ~중 하나   →  one of the 최상급 회피. 단, 원문이 "among the X-est"나 "in the top N"처럼 복수 전제를 명시하면 유지
~처럼 보이다 / ~처럼 들리다     →  look/sound like 회피. "~같다", "~듯하다". 단, 시각·청각이 실제 감각 대상이면 유지 ("빨간색처럼 보인다")
~게 만들다 / ~도록 만들다       →  make X do 회피. "~덕분에", "~때문에". 단, 원문이 물리적 제작(build/construct)이면 유지
~을 가지고 있다 / ~을 가진      →  have 회피. "~에게 ~이 있다". 단, 원문이 own/possess이고 법적 소유가 핵심이면 유지
만약 ~한다면                  →  if 회피. "~하면"으로 대체. 단, 원문이 반사실(hypothetical/counterfactual) 가정이면 "만일 ~했다면"으로 유지
~가 있다/있었다 (서두)         →  there is/was 회피. 단, "태초에 빛이 있었다" 같은 관용·성경 인용이면 유지
세부 사항에 관여 / 세부 사항을 파고들   →  get into the details/weeds 회피. "자세히 살피다" (예외 없음)
~라는 점에서                  →  in that 회피. "~한다는 점에서"로 줄이거나 생략
~라고 말할 수 있다             →  one could say 회피. 단정 또는 "~라고 볼 수 있다"로 대체
```

### 대명사 전이

```
그는 / 그녀는 / 그들은          →  he/she/they 회피. 단, 직전 문장에서 명사 언급 없이 대명사가 쓰이면 첫 등장 때는 명사로 복원, 이후는 생략 또는 유지
그것은 / 이것은                →  it/this 회피. 단, 앞 문장의 특정 대상을 가리키는 지시이고 명사 반복이 장황하면 유지
나는 / 저는                   →  I 회피. 단, 원문 I에 강조(emphatic)나 대조(vs you/they)가 있으면 유지
우리는 / 우리가                →  we 회피. 단, 원문 we가 "저자와 독자 포함" 뜻이면 유지. 저자 단독 we(learned we)는 생략
~의 그것                      →  that of. 비문이므로 예외 없이 금지. 명사 반복 또는 비교 구조 재작성
```

### 이중피동

```
쓰여지다                      →  쓰이다 (쓰+이의 피동에 -어지 중복)
잊혀지다                      →  잊히다
보여지다                      →  보이다
믿겨지다                      →  믿기다
되어지다                      →  되다 (되 자체가 피동)
```

이중피동은 비문이므로 예외 없이 교정한다.

### 피동·사동 일반

```
수동태 문장                    →  행위자 중심 능동태로 전환. 단, 행위자가 불명·불필요·회피 대상이면 수동 유지
영어의 감정 피동 (bored/interested 등)  →  한국어 감정 동사(지루해하다/관심 있다)로 전환
~게 되다 (change of state)     →  사동 직역 회피. 자연스러운 자동사로 전환. 단, 외력 개입이 핵심이면 유지
```


## 대안

### 구문 재구성

```
(직역) 그는 결정을 내려야 한다.
(대안) 그는 결정해야 한다. / 그는 결정한다.

(직역) 이것은 중요한 사안이 될 것이다.
(대안) 이건 중요해진다. / 중요한 사안이다.

(직역) 우리 회사는 서울에 위치해 있다.
(대안) 우리 회사는 서울에 있다.

(직역) 그녀는 아름다운 목소리를 가지고 있다.
(대안) 그녀는 목소리가 아름답다.

(직역) 이에 관하여 논의할 필요가 있다.
(대안) 이 문제를 논의해야 한다.

(직역) 집회를 알리는 벽보를 만드는 데 엄청난 노력이 기울여졌다.
(대안) 집회를 알리는 벽보를 만드는 데 엄청난 노력을 기울였다.
```

### 관용구 재구성

```
(직역) A, B 그리고 C가 있다.
(대안) A, B, C가 있다. / A와 B, 그리고 C가 있다.

(직역) 아무도 그것을 알지 못했다.
(대안) 그걸 아는 사람이 없었다. / 모두 몰랐다.

(직역) 그는 키가 가장 큰 학생들 중 하나이다.
(대안) 그는 키가 큰 학생 중 한 명이다. / 반에서도 특히 키가 큰 학생이다.

(직역) 그 소식은 사실처럼 들렸다.
(대안) 그 소식은 사실 같았다.

(직역) 그 일은 나를 행복하게 만들었다.
(대안) 그 일 덕분에 행복했다. / 그 일로 기분이 좋았다.
```

### 이중피동 교정

```
쓰여진 글  →  쓰인 글 / 쓴 글
잊혀진 추억  →  잊힌 추억
보여지는 것  →  보이는 것
만들어지는 과정  →  만들어지는 과정 (이건 정상, -어지다 단일 피동)
검토되어지는 중  →  검토되는 중 / 검토 중
```


## 과교정 경계

번역투 회피가 의미·주체·인과를 손상시키면 **번역투를 유지**하는 것이 더 좋다. 아래는 실제 번역 테스트에서 발견된 과교정 사례들이다.

### 주체·대상 정보 손실

```
(원문) school was familiar to me
(번역투) 학교는 저에게 익숙한 곳이었습니다
(과교정) 학교는 익숙했습니다  ← "저에게"가 빠져 누구에게 익숙한지 모호
(적절) 학교는 저에게 익숙했습니다
```

부사격 조사 "~에게", "~한테"가 핵심 의미 운반자이면 생략하지 않는다. "대명사 남발 회피"를 적용할 때 특히 주의.

### 동사 방향성 오역

```
(원문) I knew they had to first go to law school
(번역투) 로스쿨에 먼저 가야 한다는 것을 알았다
(과교정) 법대를 먼저 나와야 한다  ← "가다(go to)"가 "나오다(graduate from)"로 반대 방향
(적절) 법대에 먼저 가야 한다
```

간결화하면서 동사 자체의 의미 방향을 바꾸면 오역이다. 축약할 때는 원문 동사의 방향(in/out, give/receive, come/go)이 유지되는지 확인한다.

### 인과 연결 단절

```
(원문) The system slows because the index is fragmented, so we rebuilt it
(번역투) 인덱스가 조각나서 시스템이 느려졌다. 그래서 우리는 인덱스를 재구축했다
(과교정) 인덱스가 조각났다. 시스템이 느려졌다. 인덱스를 재구축했다  ← 인과 접속(because, so)이 삭제되어 세 사건이 병렬로 읽힘
(적절) 인덱스가 조각나 시스템이 느려져서 인덱스를 재구축했다
```

접속 부사를 줄일 때 원문의 인과 표지(because, so, therefore, since)가 한국어 어미·접속사 어느 층에라도 남아야 한다. 완전 삭제 금지.

### 조건·의무의 뉘앙스 소실

```
(원문) You must wear a seatbelt by law
(번역투) 법적으로 안전벨트를 착용해야만 합니다
(과교정) 안전벨트를 착용합니다  ← "의무"가 사라져 단순 서술이 됨
(적절) 안전벨트를 착용해야 합니다 (법적 의무이므로 "~어야 한다" 유지)
```

"~어야 한다"는 법적·윤리적·강한 당위가 핵심 의미이면 유지한다.

### 미래 예측의 축약

```
(원문) It will be important later
(번역투) 나중에 중요할 것입니다
(과교정) 나중에 중요합니다  ← 미래 예측이 현재 사실로 바뀜
(적절) 나중에 중요해집니다 / 나중에 중요할 겁니다
```

"~(으)ㄹ 것이다"를 현재형으로 바꿀 때 시제 뉘앙스가 사라지지 않는지 확인한다.


## 체크리스트

글을 쓴 뒤 두 단계로 확인한다.

### 1단계: 번역투 회피 (긍정 확인)

```
□ ~어야 한다 / ~것이다 / ~에 관하여 / ~에 대해서가 의미상 불필요한 자리에 남지 않았는가
□ A, B 그리고 C 같은 Oxford comma 직역이 없는가
□ 아무도/아무것도 ~지 않는 대신 ~는 사람/것이 없다로 쓰였는가 (구어 강조 맥락 제외)
□ 가장 ~중 하나 대신 손에 꼽히는 / 특히 ~한으로 대체됐는가 (실제 복수 전제 제외)
□ ~처럼 보이다/들리다 대신 ~같다/~듯하다로 대체됐는가
□ ~게 만들다 대신 덕분에/때문에로 재구성됐는가 (실제 물리적 사동 제외)
□ 이중피동(쓰여지다/잊혀지다/보여지다)이 단일 피동으로 교정됐는가
□ 주어 대명사(그/그녀/그들/나/우리)가 불필요하게 반복되지 않는가
□ ~의 그것 같은 비문이 없는가
□ 수동태가 능동태로 전환될 수 있는 자리에 남아있지 않은가 (행위자 중요/불필요에 따라 판단)
□ 세부 사항 관여 같은 정체 불명 AI 상투구가 없는가
```

### 2단계: 과교정 역검사 (의미 보존 확인)

```
□ "~에게", "~한테" 같은 주체·대상 표시가 간결화 과정에 빠지지 않았는가
□ 원문 동사의 방향(in/out, 가다/나오다)이 유지됐는가
□ 문장 분리로 원문의 인과 순서가 뒤바뀌지 않았는가
□ "~어야 한다"를 삭제한 자리에서 법적·당위적 뉘앙스가 소실되지 않았는가
□ "~(으)ㄹ 것이다"를 현재형으로 바꾼 자리에서 미래 예측이 현재 사실로 왜곡되지 않았는가
□ 축약한 문장이 앞뒤 문맥과 논리적으로 연결되는가
```
