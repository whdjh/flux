# UI/UX 에센스 - 어떻게 보이는가

데스크톱 정보 수집/관리 앱의 UI/UX 전체 명세를 통합한 문서다. 디자인 토큰, 레이아웃, 와이어프레임, UX 패턴, 접근성, 상태 처리를 다룬다.


## 디자인 토큰

모든 색상, 크기, 간격, 반경, 모션은 `tokens-and-shell.json` 기반이다. 임의 px 직접 입력을 금지한다.

### 컬러

브랜드 컬러는 primary 400:#7B4BA7, 500:#5D3587, 600:#4A2A6D다. accent 400:#A06CD5다.

모드별 토큰:
- light: bg #F8F4F0, panel #FFF, panel2 #F3F3F4, text #111216, text2 #6B7280, border #E5E7EB
- dark: bg #1C1C1C, panel #2A2B2C, panel2 #343536, text #EDEEF0, text2 #A9AFB8, border #2F323A
- high-contrast: bg #0B0B0B, panel #121416, panel2 #191C1F, text #FFF, text2 #D1D5DB, border #8B5CF6

의미색: success #10B981, warning #F59E0B, danger #EF4444, info #3B82F6

Liquid Glass 효과: blur 22px, 배경 알파 0.06, 보더 알파 0.16

### 타이포그래피

폰트: Inter, Pretendard. 웨이트: 400, 500, 600, 700.

크기 스케일: xs 12, sm 14, md 16, lg 20, xl 24, xxl 32, display 40. 행간: body 1.5, heading 1.4.

### 스페이싱

8pt 스케일만 사용한다: 4, 8, 12, 16, 24, 32, 40, 48, 64. 기본 레이아웃 패딩 24, 카드 내 패딩 16.

### 반경

입력/버튼/카드 r12, 패널/모달 r20, 칩 r8. 세부: sm 4, md 8, lg 12, xl 16.

### 아이콘

기본 24px, 보조 20px, 작은 것 16px. 스트로크 2px.

### 포커스 링

색상 #5D3587, 두께 2px, 오프셋 2px, 반경 6px.

### 섀도우

shadow-1: 0 1px 2px rgba(0,0,0,.08). shadow-2: 0 4px 8px rgba(0,0,0,.12).

### 모션

duration: fast 100ms, normal 150ms, slow 200ms. easing: standard cubic-bezier(0.2,0,0,1), enter cubic-bezier(0,0,0.2,1), exit cubic-bezier(0.4,0,1,1).

패널 열고닫기 40ms ease-out. 리사이즈는 실시간(0ms). 오버레이 사이드바: 페이드+슬라이드 40ms.

### ZIndex

base 0, dropdown 1000, modal 2000, toast 3000, drag 4000. 오버레이 스크림 rgba(0,0,0,0.40).

### 인터랙션 상태

neutral hover rgba(0,0,0,0.04), pressed rgba(0,0,0,0.08), selected rgba(93,53,135,0.10). primary hover #4A2A6D, pressed #3C2259.

### 밀도

compact 0.9, comfortable 1.0(기본), spacious 1.1. 간격에 배수를 적용한다.

### 브레이크포인트

base 1280, large 1440.


## 레이아웃 시스템

### App Shell 구조

VS Code 스타일의 3-패널 레이아웃을 채택한다. 인지 과학적 근거(Fitt's Law, F-Pattern, Miller's Law)와 시장 검증(3,500만 개발자 사용, 74% 만족도)을 기반으로 선택했다.

```
Topbar(56) ─────────────────────────────────
Tabs(34) ───────────────────────────────────
Sidebar(336) │ Content Area │ Right Panel(336)
             │ (Splitter 8) │ (선택)
```

### 캔버스와 그리드

기본 캔버스 1680x1050. 변형: 1440x900, 1280x800. 12컬럼 그리드, 거터 24, 좌우 마진 24.

창 프리셋: 1280x800, 1440x900, 1680x1050, 1920x1200, 2560x1600. 첫 실행 시 1440x900 기본, 대형/저배율 디스플레이에서 1680x1050 자동 선택. 이후 실행은 마지막 창 크기를 복원한다.

### Topbar(56px)

좌측: 제품명/앱 로고(24), 창 제어(최소/최대/닫기). 중앙: 빈 상태 또는 전역 탭/페이지 타이틀. 우측: 전역 검색 입력(폭 320, 높이 36, r12), 알림 아이콘(24), 프로필(24). 내부 패딩 좌우 24, 요소 간 간격 16.

### 탭바(34px)

탭 리스트(핀/스크롤), 새 탭 버튼(+, 24). 탭 아이템: 높이 34, 좌우 패딩 12~16, 닫기(x 16) 우측 정렬, 상태 hover/focus/active.

### 좌측 사이드바(336px)

섹션: Inbox, Projects, Tags, Views, Favorites. 항목 높이 40~44, 섹션 헤더 상단 패딩 12/하단 8, 아이콘 20. 리사이즈 핸들 8, 스냅 24 단위. 최소 240px, 최대 360px.

접힘 너비 64px(아이콘 모드). 도킹/오버레이 모드 지원. 1200px 미만에서 자동 오버레이 전환.

### 우측 패널(336px, 선택)

헤더 48~56, 내용 스크롤, 닫기 아이콘 20. 메모나 AI 어시스턴트를 표시한다.

### 콘텐츠 영역

상단 바(높이 52, 내부 패딩 16~24)에 필터/정렬/검색. 뷰: List(행 52), Grid, Masonry, Justified. 카드 160x200, r12, gutter 24.

### 분할(Split View)

VS Code의 분할 뷰 시스템을 채택한다. 비교/참조 작업 시 30~40% 속도 향상. 동시 콘텐츠 표시가 작업 효율 40% 증가. 화면 전환마다 23분의 집중력 손실을 방지한다.

프리셋: 1분할 100%, 2분할 50/50 33/67 67/33, 3분할 25/50/25 20/60/20, 4분할 25/25/25/25(최대 4분할).

리사이즈: 패널 최소 폭 320px, 사이드바 240~420px. 핸들 6px, 더블클릭으로 균등 분할 리셋. 스냅 2% 단위, 임계 8px, Alt 키로 스냅 무시.

탭: 각 패널 상단 탭바, 재정렬/핀 고정/스크롤 지원.

### 상태 저장

범위: 앱 전역 + 프로젝트(폴더) 단위. 항목: 좌/우 사이드바 상태와 폭, 분할 프리셋/비율, 활성 탭. 시점: 앱 시작/종료, 프로젝트 전환 시 자동 저장/복원.

### Masonry 레이아웃

masonic(가상화 내장)을 고정 채택한다. 열 계산: floor((콘텐츠폭 + gutter) / (카드폭 + gutter)). 카드 160px, gutter 24, 사이드바 336 기준:
- 1280 캔버스 -> 콘텐츠 약 944 -> 5열
- 1440 캔버스 -> 콘텐츠 약 1104 -> 6열
- 1680 캔버스 -> 콘텐츠 약 1344 -> 7열

masonic 설정:
- overscan 1~2 viewport
- estimateHeight: 카드 비율(16:9) 기반 추정, 로딩 후 실측 교정, 크기 캐시 유지
- positioner 캐시 재사용: 필터/정렬/리사이즈 시 스크롤 앵커 유지
- 이미지 로딩: LQIP/Skeleton + IntersectionObserver
- DnD: key 안정적 유지, 드래그 중 측정 pause
- Ctrl+F 대체: 앱 내 검색 UI 제공(가상화로 화면 밖 DOM 미생성)
- Export/Print: 비가상화 모드 토글로 전체 렌더 후 캡처
- 성능 타겟: 60FPS, 메모리 300~400MB 이내

### 접근성(레이아웃)

분할 핸들: role="separator", aria-orientation="vertical". 키보드 리사이즈: 핸들 포커스 상태에서 좌우 10px, Shift+좌우 50px. 포커스 링과 명확한 대비 모드 제공.

투명 배경(Liquid Glass) 사용 시 패널 경계선/그림자 보강. 멀티모니터: 새 창 중앙 배치, 마지막 위치/크기 기억.

### 라이브러리 선택

Resizable(shadcn): ResizablePanelGroup / ResizablePanel / ResizableHandle. Masonry(masonic): 가상화 내장, 대량 목록 최적.

## UX 패턴

### 선택(Selection)

Click = 단일, Shift = 구간, Ctrl/Cmd = 개별 토글. 벌크 액션: 선택 시 상단/하단 바 노출(이동/태그/삭제). 키보드: Arrow로 포커스 이동, Space/Enter로 선택 토글.

### DnD(Drag and Drop)

드래그 시작: 카드/행 핸들 혹은 전체 영역 허용. 드롭 피드백: hover 강조, 유효/무효 영역 구분. 실패 시 원복(revert) + 토스트. 키보드 대체: 컨텍스트 메뉴의 이동으로 대체.

### 검색/필터/정렬

입력 디바운스(200~300ms), 히스토리/추천 제공. 정렬/필터 변경 즉시 반영, 스켈레톤 상태로 전환.

## UX 상태 처리

### 상태 모델

- Loading: 스켈레톤 우선(스피너 최소), 레이아웃 점프 금지
- Empty: 설명 + 1차 CTA(예: "첫 아이템 추가"), 2차 학습 링크 선택
- Success: 기본 상태, 중복 피드백 지양
- Offline: 읽기 우선, 쓰기 큐잉/보류, 상단 오프라인 인디케이터
- Error: 발생 위치 인라인 메시지 + 상황에 따라 토스트/모달, 재시도 명시
- Processing(Long): 진행률/단계 표시, 취소 가능 시 버튼

### 글로벌 규칙

네트워크 인디케이터: Topbar에 Online/Offline 배지. 글로벌 에러 바운더리: 복구 버튼(새로고침/상위로 이동). 토스트: 우상단, 3~5초, 수동 닫기, aria-live="polite". 재시도: 즉시 재시도 + 지수 백오프(1s, 2s, 4s), 대기 중 비활성. 키보드 우선: ESC 오버레이 닫기, Tab 순서 보장, 포커스 링. 히트 영역: 최소 44px.

### 에디터 상태

자동저장 인디케이터(저장됨/저장 중/오류). 오프라인 로컬 캐시 + 온라인 복구 시 병합(충돌 해결 규칙 명시). 나가기 전 미저장 경고.

### AI 어시스턴트 상태

스트리밍 표시, 중지 버튼. 요청 오류/토큰 초과: 에러 메시지 + 입력 보존 + 재시도.

### 검색 상태(오프라인)

의미검색 비활성, 키워드만 허용(로컬 인덱스). 쿼리/필터/정렬 상태 유지.


## 접근성(A11y)

색상 대비: 본문 4.5:1, UI 3:1 (AA). 히트 영역 최소 44x44px. reduce motion 지원.

라이브 피드백: aria-live("polite"/"assertive") 적절 사용. 모달: role="dialog"/"alertdialog", 포커스 트랩, ESC 닫기. 단축키 목록 제공(도움말/명령 팔레트). 브레드크럼: Projects 트리 경로를 상단 보조 내비로 표시(접근성 라벨 포함).


## 스타일가이드

### CSS 프레임워크

Tailwind CSS v4 + Shadcn UI를 사용한다. 다크모드는 `class` 전략(`<html>` 태그에 `dark` 클래스 토글).

컬러 시스템은 CSS 변수로 관리한다:

```css
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 221.2 83.2% 53.3%;
  --secondary: 210 40% 96.1%;
}

.dark {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  --primary: 217.2 91.2% 59.8%;
  --secondary: 217.2 32.6% 17.5%;
}
```

유틸리티 클래스는 시맨틱하게 사용한다. 중복/불필요 클래스를 나열하지 않는다.

### Shadcn UI

컴포넌트 설치 후 프로젝트에 맞게 커스터마이징한다. variant를 추가해서 확장한다. `cn` 유틸리티로 Tailwind 클래스를 조건부 관리한다.

### Glassmorphism

hackathon UI에서 Glassmorphism 기반 스타일을 채택한다. GlassCard, Button, Input, Badge 등 커스텀 컴포넌트를 쓴다. Framer Motion으로 애니메이션을 처리한다.

### 컴포넌트 상태

새 컴포넌트는 반드시 상태 변형을 포함한다: hover, focus, active, disabled, selected, drag-over.


## ADR 요약

### ADR-001: 3-패널 레이아웃

VS Code 스타일의 좌측 사이드바 20% / 중앙 메인 뷰 60% / 우측 사이드바 20% 레이아웃을 채택한다.

인지 과학 근거: Fitt's Law(빈번한 액션이 시작 위치에 가까움), F-Pattern(자연스러운 시선 이동), Miller's Law(3개 영역이 인지 청크 한계 내). 실용적 이점: 영구 네비게이션, 컨텍스트 유지, 도구 접근성.

핵심 컴포넌트: MasterLayout(최상위), ResizablePanel(범용 패널), PanelSplitter(드래그 핸들), LayoutStore(Zustand 상태). 성능 최적화: 가상 스크롤, 지연 로딩, 메모이즈된 렌더, CSS transforms(리플로우 방지).

### ADR-002: 탭 애니메이션

Chrome의 200ms 탭 애니메이션을 채택한다.

- Tab Open: 0 -> Full Width (200ms, ease-out)
- Tab Close: Full Width -> 0 (200ms, ease-in)
- Tab Reorder: Position A -> B (300ms, ease-in-out)
- Tab Hover: Opacity 0.8 -> 1.0 (150ms, ease)

200ms는 시각적 추적과 속도의 최적 균형점이다. 부드러운 전환이 오류율 23% 감소, 애니메이션이 공간 기억력 40% 향상. CSS transitions + GPU 가속으로 60fps 보장. `prefers-reduced-motion`에서 transition 비활성화.

### ADR-003: 분할 뷰

VS Code의 분할 뷰 시스템을 채택한다. 수평/수직 분할 + 중첩 레이아웃.

비교/참조 작업 시 30~40% 속도 향상. 동시 콘텐츠 표시가 작업 효율 40% 증가. 핵심: 탭 드래그 분할, 키보드 단축키 완벽 지원(Cmd/Ctrl+\), 작업공간별 레이아웃 기억, 동기화 스크롤 옵션.
