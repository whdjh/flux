UI:
- 약한 대비, 약한 블루라이트로 눈의 피로도 저하.(필립스 참고. 파스텔톤 가능. RGB 000의 다크모드 x 303030~404040 정도 ok 차가우려면 39 40 41, 따뜻하려면 41 40 39 이런식.)
  라이트, 다크모드, 다크모드보다 덜 어두운 회색, 커스텀 배경색 지원.
- Obsidian의 테마 Minimal에서 좋은 점들을 따 올 예정
- Figma 커뮤니티의 작품인 aakarshna의 폰트와 테마를 따 올 예정.

1. 심플 모드:
   - 토글 버튼으로 전체 상단 바 표시/숨기기

2. 창 크기 조절:
   a. 그리드 기반 창 크기 조절:
      - (아이콘)버튼 클릭으로 전체 창에 가이드라인 표시
      - 가로 세로 선으로 정사각형 그리드 생성
      - 드래그 시 앱의 창과 배경색이 동일한 투명한 창 표시
      - 드래그 종료 시 선택된 크기로 창 변경
      - 선택한 크기를 단축키(Ctrl + 1~9)로 저장 및 불러오기

   b. 동적 가이드라인 창 크기 조절:
      - 창을 화면 가장자리로 끌 때 가이드라인 자동 표시
      - 3분할과 5분할(상단, 중상단, 중단, 중하단, 하단) 가이드라인 동시 표시
      - 가이드라인에 맞춰 창 크기 자동 조절
      - 화면 모서리에서는 그리드 기반 방식으로 전환, 정밀한 크기 조절 가능
      - 두 번째 끌어당김부터는 이전에 선택한 창 크기 자동 적용(기억된 창 크기 수정 가능)

1. 메뉴바:
   - 파일, 편집, 보기, 도구, 설정, 도움말

2. 좌측 사이드바:
   - 홈 화면
   - 사이드바 접기/펼치기 버튼
   - 최신 스크랩
   - 북마크 메모장
   - 폴더 구조식 프로젝트와 메모 나열
   - 메모, 이미지, 링크, 동영상, 음성기록, 클립보드 카테고리
   - 템플릿 사이트
   - 휴지통
   - 설정

3. 우측 사이드바:
   - 스크랩 된 데이터들 표시
   - 메모장에서 빠른 이동되는 정보들 모음
   - 북마크 아이콘: 빈 체크박스, 체크박스, X 체크박스, 동그란 체크박스, 동그라미, 세모, X, 별. 아이콘 디자인은 정했음.

4. 헤더:
   - 제목 표시
   - 검색창
   - 필터 옵션
   - 창 상단 고정 버튼

5. 메인 영역:
   - 스크랩 정보 나열 (시간순, 주제별, 키워드별 등 다양한 방식으로 표시 가능)
   - 메모 편집 영역

6. 푸터 (상태바):
   - 동기화 상태 표시
   - 현재 문서의 줄 수, 열 수, 글자 수 표시
   - 공백 크기 조절 옵션

7. 추가 기능:
   - 도움말은 마우스 커서 옆에 툴팁 형태로 표시
   - 화면 분할 기능(창 드래그 하면 화면 가이드 제공)

9. 반응형 디자인:
   - 사이드바를 접을 수 있는 옵션으로 작은 화면에서도 사용 가능

## UI 컴포넌트 구조

### 1 레이아웃 구성

- **헤더**: 제목, 검색창, 필터, 창 상단 고정 버튼
- **좌측 사이드바**: 내비게이션 메뉴
- **메인 영역**: 스크랩 정보 나열 및 메모 편집 영역
- **우측 사이드바**: 스크랩된 데이터와 북마크된 정보 표시
- **푸터**: 상태바 (동기화 상태, 줄/열/글자수 등)
