# 리서치도구 개요

## 문제정의

정보 수집/정리 과정에서 생각의 흐름이 끊어진다.

링크, 스크린샷, 메모, 이미지가 여러 앱에 흩어져 있고, 앱 전환할 때마다 사고의 깊이가 감소한다. 전환 비용(switch cost)으로 생산성이 40% 감소하고 회복 시간은 23분이 걸린다. Gloria Mark의 연구가 이를 증명한다.

## 솔루션

AI 기반 통합 지식 관리 도구다. 수집부터 발상까지 한 곳에서 해결한다.

### 핵심 워크플로우
```
수집 → 검토 → 통합 → 정제 → 아이디어 발상
```

### 7가지 핵심 기능

| 기능 | 설명 | 주요 특징 |
|------|------|----------|
| **수집** | Alt+우클릭, 드래그앤드롭 | 확장프로그램 연동, AI 요약+키워드 자동 생성 |
| **정리** | 카테고리별 자동 분류 | All/텍스트/링크/이미지/동영상/클립보드/스크린샷 폴더 |
| **메모** | Monaco Editor 통합 | 메인창, 우측 사이드바, 포스트잇 세 곳에서 공유 |
| **창관리** | Liquid Glass UI 포스트잇 | 항상 위, 투명, 크기/위치 자유, 웹서핑 방해 없음 |
| **검색** | 유의어 검색 (Elasticsearch-rs) | AI 키워드+요약 포함 검색, 빠른 쿼리 |
| **AI** | RAG 기반 대화형 어시스턴트 | 수집 정보 컨텍스트, Elevenlabs TTS/STT, MCP 지원 |
| **협업** | Figma 스타일 실시간 협업 | 동시 수정, 슬래시(/) 커서 채팅, 채팅창 |

## 기술 스택

```yaml
프론트엔드: Electron, React, Remix, Shadcn/UI, TailwindCSS
백엔드: Supabase (Auth, DB)
검색: Elasticsearch-rs
에디터: Monaco Editor
AI: Openrouter, Elevenlabs React SDK
DB: PostgreSQL, Drizzle
배포: Netlify
UI컨셉: Apple Liquid Glass (2025-06-08)
```

## 핵심 가치

1. 전환 비용 제거: 모든 정보를 한 곳에서 관리
2. 몰입 유지: 투명 UI로 생각의 흐름을 끊지 않음
3. AI 자동화: 요약, 키워드, 검색 자동화로 정리 부담 감소

## 사용 시나리오

- 웹서핑 중 정보 수집 (드래그앤드롭)
- 게임/작업 중 떠있는 메모 (포스트잇 모드)
- 팀 협업 (실시간 공유)
