# 리서치도구 기능명세

## 프로젝트 정의

웹 서핑 중 발견한 정보를 단축키 하나로 수집하고, AI가 자동으로 분류 및 요약하며, 이를 바탕으로 아이디어를 발전시킬 수 있는 통합 작업 공간을 제공하는 데스크톱 애플리케이션이다.

현재 지식 노동자들은 정보 과부하와 싸우고 있다. 북마크, 카카오톡, 다운로드 폴더, 스크린샷이 여기저기 흩어져 있고, 이전에 찾은 정보를 다시 찾는 데 많은 시간을 낭비한다. 기존 도구들은 각자의 영역에서는 훌륭하지만 수집부터 정리, 아이디어 발상까지 전체 과정을 하나의 플랫폼에서 끊김 없이 지원하지 못한다. 이 도구는 그 간극을 메운다.

## 기술 스택

Electron과 React 조합으로 데스크톱 네이티브 경험을 제공한다. Remix는 React Router v7 프레임워크로 라우팅과 데이터 로딩을 담당하고, Shadcn/UI와 TailwindCSS로 Apple Liquid Glass 디자인을 구현한다. Liquid Glass는 2025년 6월 8일 Apple이 발표한 투명하고 유려한 UI 컨셉이다.

백엔드는 Supabase를 쓴다. PostgreSQL 데이터베이스와 인증, 실시간 협업 기능을 한 번에 해결한다. Drizzle ORM으로 타입 안전한 데이터 접근을 보장한다. 검색 엔진은 Elasticsearch-rs다. 유의어 검색과 빠른 쿼리 속도가 핵심이다.

Monaco Editor는 메인 창, 우측 사이드바, 포스트잇 세 곳에서 공유된다. VSCode와 같은 에디터 엔진이라 코드 하이라이팅과 자동완성이 기본으로 들어간다. AI는 Openrouter로 다양한 모델을 선택할 수 있고, Elevenlabs React SDK로 TTS/STT 음성 기능까지 연결한다.

아이콘은 Lucide와 Icones를 조합해 일관성 있는 시각 언어를 만든다. 배포는 Netlify다. 프론트엔드 중심 애플리케이션이므로 정적 호스팅으로 충분하다.

```
Frontend: Electron, React, Remix, Shadcn/UI, TailwindCSS
Backend: Supabase (PostgreSQL, Auth, Realtime)
Search: Elasticsearch-rs
Editor: Monaco Editor
AI: Openrouter, Elevenlabs React SDK
DB ORM: Drizzle
Icons: Lucide, Icones
Deploy: Netlify
UI Concept: Apple Liquid Glass (2025-06-08)
```

## 핵심 기능

애플리케이션은 7가지 핵심 기능으로 구성된다. 수집, 정리, 메모, 창관리, 검색, AI 어시스턴트, 협업이다. 이 기능들은 수집→검토→통합→정제→발상이라는 리서치 워크플로우를 따라 설계되었다.

### 수집

크롬 확장프로그램과 연동한다. Alt + 우클릭 또는 드래그앤드롭으로 콘텐츠를 수집한다. 텍스트 하이라이트, 이미지, 링크, 동영상을 지원한다. 클립보드와 스크린샷도 수집 대상이지만 카테고리 폴더에서만 확인할 수 있다. 수집과 동시에 AI가 1~3줄 요약과 키워드 3개를 생성한다. 병렬 처리로 UX가 느려지지 않게 한다.

메타데이터는 제목, URL, 파비콘, AI 요약, 키워드, 생성일을 저장한다. 확장 프로그램과 앱은 로컬 서버를 통해 통신하므로 외부 노출 없이 안전하다.

### 정리

좌측 사이드바에 폴더 트리 구조를 제공한다. 로컬 폴더와 파일을 연동할 수 있으므로 기존 워크플로우를 방해하지 않는다. All 폴더에서 모든 콘텐츠를 모아보고, 카테고리 폴더로 분류한다. 카테고리는 텍스트 하이라이팅, 링크, 이미지, 동영상, 클립보드, 스크린샷이다. 클립보드와 스크린샷은 All 폴더에 안 뜬다.

메인 윈도우 우측 상단에 정렬 옵션 버튼이 있다. Eagle 스타일의 4가지 정렬을 제공한다. 폭포(벽돌 모양), 양쪽, 그리드, 목록이다. 폭포는 Pinterest처럼 masonic으로 구현하고, 양쪽은 Justified 정렬이다.

### 메모

메모 기능은 세 곳에서 작동한다. 메인 윈도우(Obsidian/Notion 스타일 편집기), 우측 사이드바, 포스트잇 창이다. Monaco Editor를 공통으로 쓴다.

한 번 거르는 기능이 핵심이다. 수집→검토→정제→취합 과정에서 검토-정제-취합 단계를 돕는다. 메인 윈도우의 수집 정보를 우측 사이드바 메모 공간으로 드래그해서 옮긴다. 스티커를 붙이거나 텍스트에 형광펜 효과를 준다. 빈 체크박스, 완료 체크박스, X, 별, 동그라미, 세모 같은 시각적 장치로 정보를 걸러낸다.

텍스트 서식은 글자 크기, 볼드, 이탤릭, 밑줄, 실선, 글자 색, 배경 색을 지원한다. 슬래시(/) 커맨드로 제목, 토글, 할 일, 코드, 불렛 포인트, 인덱스, 구분선을 입력한다. 이미지 삽입과 하이퍼링크도 된다. Markdown(.md)과 텍스트(.txt) 형식으로 저장한다.

### 창 관리

프로그램 우측 상단에 포스트잇 버튼이 있다. 누르면 Liquid Glass UI 형태의 포스트잇 창으로 전환된다. 메모 기능을 그대로 가져가되 UI가 투명하고 간소화된다. 사용자가 크기와 위치를 지정하고 여러 창을 띄울 수 있다. 창을 맨 위로 고정시켜 웹서핑이나 게임 중에도 메모할 수 있다.

이 기능은 전환 비용을 제거하기 위해 설계되었다. 게임이나 작업 중 영감이 떠오르면 애플리케이션을 전환하지 않고 바로 기록한다. 투명 UI라서 시야를 가리지 않는다.

### 검색

메인 윈도우 가운데 위에 검색 버튼이 있다. Elasticsearch-rs로 유의어 포함 검색을 지원한다. 극단적으로 '그레이브즈'를 '그브'로 검색해도 찾는다. AI가 달아놓은 요약과 키워드도 검색 대상이다.

### AI 어시스턴트

우측 사이드바에 있으며 메모 UI와 전환 가능하다. 수집한 정보를 RAG 방식으로 가져와 대화한다. Cursor AI IDE처럼 생성, 대화, 수정이 가능하고 파일/폴더 관리까지 할 수 있다. MCP 서버를 연결할 수 있어 확장성이 높다.

Openrouter로 모델을 선택하고 세부 옵션을 정할 수 있다. Elevenlabs TTS/STT로 음성 대화도 지원한다. Elevenlabs AI Voice React SDK를 사용한다.

### 협업

실시간 협업 모드다. Figma 협업 모드처럼 서로 동시에 수정할 수 있다. 슬래시(/) 입력 시 마우스 커서에서 채팅을 칠 수 있고 협업 모드 활성화 시 채팅창도 생긴다. 프로필 겹쳐보기, 커서 색상 구분, 동시 편집을 지원한다.

## 페르소나와 사용자 여정

Jina는 3년차 프로덕트 디자이너다. UI/UX 레퍼런스를 수집하며 새로운 프로젝트의 디자인 시스템을 설계한다. 수많은 시각적 영감과 텍스트 아티클을 체계적으로 수집하고 싶어 한다. 수집한 자료에 자신의 생각을 덧붙여 아이디어를 구체화하고 실제 프로젝트에 빠르게 적용하고자 한다.

Jina의 좌절점은 세 가지다. 스크랩은 많이 해두지만 필요할 때 원하는 자료를 찾기 어렵다. 이미지 레퍼런스와 관련 텍스트 메모가 여러 곳에 흩어져 있어 연결하기가 힘들다. 정보를 수집하기 위해 여러 프로그램을 오가는 과정이 번거롭고 작업 흐름을 방해한다.

### 메인 시나리오: 온보딩 화면 디자인 리서치

Jina가 새로운 모바일 앱의 온보딩 화면 디자인을 위해 레퍼런스를 수집하고, 이를 바탕으로 아이디어를 구체적인 기획 메모로 발전시키는 과정이다.

웹서핑 중 영감을 주는 온보딩 UI 이미지를 발견하고 Alt + 우클릭으로 앱에 수집한다. Inbox에서 '온보딩 프로젝트' 주제 폴더로 드래그해서 이동시킨다. 이 폴더를 기본 수집 위치로 지정하면 앞으로 관련 자료가 바로 저장된다.

아이디어를 정리하기 위해 폴더를 연 상태에서 창 가장자리를 드래그하여 화면을 좌우로 분할한다. 왼쪽에는 레퍼런스 목록, 오른쪽에는 메모장이 나타난다. 마음에 드는 이미지 2~3개를 메모 창으로 드래그앤드롭하면 핵심 시각 자료가 임베딩된다. 이미지 아래에 "첫 번째 이미지의 간결한 일러스트 스타일이 인상적이다"라고 적고, 슬래시(/) 커맨드로 "프로토타입 제작" 체크리스트를 추가한다.

기획의 논리를 강화하기 위해 AI 어시스턴트에게 "성공적인 온보딩 UI의 핵심 원칙은 뭐야?"라고 질문한다. AI의 답변을 참고하여 메모에 '핵심 원칙' 섹션을 추가한다. 며칠 뒤 디자인 팀 회의 직전에 '온보딩'으로 검색하면 이전에 작성한 아이디어 노트를 즉시 찾아 회의 자료로 쓸 수 있다.

디자인 툴로 작업하느라 손이 바쁠 때는 마이크를 켜고 음성으로 "방금 본 '온보딩 아이디어 노트' 요약해줘"라고 명령한다. 시스템은 AI 보이스로 메모의 핵심 내용을 읽어준다.

메모 페이지를 동료에게 공유한다. 초대받은 동료는 실시간으로 아이디어를 확인하고, "이 부분은 개발 리소스가 많이 들 것 같아요"와 같은 피드백을 댓글로 남긴다. 페이지 상단에는 Jina와 동료의 프로필 아이콘이 함께 표시된다. 동료의 피드백을 반영하여 아이디어를 수정하고 체크리스트 항목들을 실행하며 최종 디자인 기획을 완성한다.

최종 기획이 완성되면 PDF나 Markdown 형식으로 내보내 팀의 공식 문서로 활용한다. 파일을 슬랙 채널에 공유하거나 프로젝트 관리 도구(Jira, Asana)의 티켓에 첨부하여 창의적인 과정이 실제 개발 및 디자인 단계로 이어지도록 한다.

## 레이아웃 설계

앱은 상단 타이틀바, 좌·우 사이드바, 메인 분할 영역, 뷰어로 구성된다. 타이틀바는 창 제어 버튼을 제공하고 드래그 이동을 지원한다. 메인 영역은 Shadcn의 Resizable로 패널을 유연하게 분할하고, 뷰어는 masonic 기반 가상화 Masonry로 대량 목록에서도 부드럽게 렌더링한다.

사이드바는 좌·우 모두 토글과 리사이즈가 가능하다. 좁은 폭에서는 오버레이로 전환된다. 좌측 사이드바 최소 폭은 240px, 최대 폭은 420px다. 우측 사이드바도 마찬가지다. 접힘 너비는 64px로 아이콘 모드를 유지한다.

분할은 균등/비율 프리셋을 제공한다. 1분할은 100%, 2분할은 50/50·33/67·67/33, 3분할은 25/50/25·20/60/20, 4분할은 25/25/25/25다. 최대 4분할까지 지원한다. 리사이즈 핸들은 더블클릭으로 균등 분할로 복귀한다. 스냅은 2% 단위로 동작하며 Alt로 무시할 수 있다.

탭은 각 패널 상단 탭바에 있다. 재정렬, 핀 고정, 스크롤을 지원한다. 단축키는 Ctrl+T로 새 탭, Ctrl+W로 닫기, Ctrl+Tab/Shift+Ctrl+Tab으로 이동, Ctrl+1..9로 점프한다.

상태 저장은 앱 전역과 프로젝트(폴더) 단위로 나뉜다. 좌/우 사이드바 상태와 폭, 분할 프리셋/비율, 활성 탭을 저장한다. 앱 시작/종료, 프로젝트 전환 시 자동 저장·복원한다.

애니메이션은 40ms ease-out로 패널 열고닫기를 처리한다. 리사이즈는 실시간(0ms)이다. 오버레이 사이드바는 페이드+슬라이드 40ms다.

접근성은 분할 핸들에 role="separator", aria-orientation="vertical"을 제공한다. 키보드 리사이즈는 핸들 포커스 상태에서 ←/→로 10px, Shift+←/→로 50px 이동한다.

Masonry 브레이크포인트는 콘텐츠 폭 기준이다. ≤1024는 2컬럼, ≤1440은 3컬럼, ≤1920은 4컬럼, >1920은 5컬럼이다. 거터는 16px다.

## 요구사항 정리

### 기본 프레임워크

Electron 기반 데스크톱 앱을 설치하고 실행한다. 앱 배경을 투명하게 설정하여 다른 작업 창 위에 띄워놓고 사용할 수 있다. 좌/우 사이드바를 열고 닫거나 크기를 조절한다. 여러 개의 탭을 생성하고 관리한다. 작업 영역을 1/2, 1/3, 1/4 등 여러 형태로 분할한다.

### 수집

브라우저 확장 프로그램을 설치한다. 웹 페이지의 특정 콘텐츠(텍스트, 이미지, 링크, 동영상)를 Alt + 우클릭 단축키로 앱에 수집한다. 웹 페이지의 콘텐츠를 앱으로 드래그앤드롭하여 수집한다. 콘텐츠 수집 시 제목, 원본 URL, 파비콘, 생성일을 메타데이터로 자동 저장한다. 수집된 콘텐츠에 대해 AI가 생성한 요약과 키워드를 메타데이터로 추가 저장한다. 브라우저 확장 프로그램과 앱 본체 간에 로컬 서버를 통해 안전하게 통신한다.

### 탐색 및 정리

수집된 모든 아이템을 콘텐츠 창에서 확인한다. 모든 데이터를 로컬의 SQLite 데이터베이스와 파일 시스템에 기반하여 관리한다. 폴더 트리 구조를 통해 수동으로 주제(폴더)를 생성, 수정, 삭제한다. 아이템을 특정 주제(폴더)로 이동시켜 분류한다.

키워드를 입력하여 로컬 데이터베이스에 저장된 콘텐츠의 제목과 본문, AI 요약과 키워드를 검색한다. 유의어를 포함한 의미 기반 검색(Semantic Search)을 통해 더 정확하게 정보를 찾는다.

정렬 필터(최신순, 오래된순)를 적용하여 콘텐츠 목록을 본다. 보기 옵션(리스트, 그리드, 양쪽, 벽돌)을 선택하여 콘텐츠 표시 방식을 변경한다.

### 메모

Monaco Editor 기반의 텍스트 편집기에서 새로운 메모를 작성한다. 메모에 제목과 내용을 입력하고 저장 및 불러오기를 한다. 슬래시(/) 커맨드를 입력하여 다양한 기능을 호출한다. 텍스트에 서식(크기, 볼드, 이탤릭, 밑줄, 실선, 색상)을 적용한다.

메모에 로컬 이미지 파일을 삽입한다. [제목](링크) 형식으로 하이퍼링크를 삽입한다. 텍스트 편집 시 확대/축소 기능과 현재 행, 열, 글자 수 정보를 제공한다. Markdown(.md)과 텍스트(.txt) 형식으로 관리한다.

### AI 어시스턴트

Openrouter API를 통해 AI 채팅 기능을 이용한다. 채팅 UI에서 새로운 채팅을 시작하고 과거 채팅 목록을 확인한다. 텍스트를 입력하여 AI에게 질문하고 답변을 받는다. Openrouter가 지원하는 AI 모델을 드롭다운 메뉴에서 선택한다.

### 스티커 메모

메인 창과 독립적으로 스티커 메모를 생성하고 관리한다. 스티커 메모에서 메인 메모장과 동일한 편집 기능을 활용한다. 단축키 또는 창 상단의 버튼을 통해 '창 맨 앞에 고정' 기능을 활성화한다. 웹 콘텐츠를 스티커 메모로 드래그앤드롭하여 가져온다.

빈 체크박스( [ ] ), 완료 체크박스(✅), X 표시(❌), 별(⭐), 동그라미(⚪), 세모(▲) 등 시각적 장치를 사용하여 메모 안의 정보를 선별하고 평가한다.

### UI 요구사항

Liquid Glass 디자인을 적용하여 미려하고 현대적인 인터페이스를 제공한다. 앱 창의 배경을 투명하게 설정하여 다른 작업과 자연스럽게 어우러지도록 한다. 사이드바, 탭, 창 분할 등 핵심 레이아웃 요소를 직관적으로 제어한다.

앱 전체의 아이콘, 버튼, 타이포그래피 등은 Shadcn UI 컴포넌트 라이브러리를 기반으로 일관성을 유지한다. 모든 기능은 사용자의 학습 곡선을 최소화하는 방향으로, 별도의 설명서 없이도 사용법을 유추할 수 있도록 직관적으로 설계한다.

## 경쟁 분석

Notion, Obsidian, Eagle, Raindrop, mymind, Karakeep, Recall AI, Readwise, Evernote, Apple Notes, Microsoft OneNote, Microsoft Sticky note, Google Keep, Boardmix, Keep it, Bear, Goodnotest, Ulysses, Memo it, EdrawMind, Simplenote 등 21개 서비스를 분석했다.

기존 도구들의 공통적인 약점은 정보 수집 단계에서의 마찰이다. 사용자들은 웹페이지를 일일이 복사-붙여넣기 하거나 스크린샷을 찍어야 한다. 이 과정에서 많은 정보가 수집되지 않고 사라진다. 본 서비스는 이 '수집의 마찰'을 제거하는 것에서 출발한다.

차별화 포인트는 세 가지다. 원클릭 수집으로 작업 흐름을 끊지 않는다. AI 자동 정리로 수집 후 정리 부담을 줄인다. 전체 워크플로우 통합으로 수집부터 아이디어 발상까지 한 곳에서 해결한다.

## 철학과 원칙

사용자 경험이 최우선이다. 직관적인 UI로 학습 곡선을 최소화한다. 사용자의 작업 흐름(웹서핑)을 방해하지 않는 설계가 핵심이다. 사용자의 뇌와 손의 에너지를 아껴주며 시간을 절약해주는 설계를 추구한다.

최소한의 에너지로 최대한의 정리 효과를 얻는 것이 목표다. AI가 예측 가능하게 분류하고 프라이버시를 보장한다. 협업 기능으로 팀 작업까지 확장한다.
