## 파일 탐색기

### 요구사항

**필수**:
- 파일 시스템 트리 구조 표시
- 폴더 열기/닫기
- 파일 클릭으로 에디터 열기
- 파일/폴더 아이콘
- Virtual Scrolling (성능)

**선택**:
- 파일/폴더 생성, 삭제, 이름 변경
- 드래그앤드롭으로 이동
- 컨텍스트 메뉴
- 검색 기능

### 사용자 시나리오

1. 사용자가 애플리케이션 실행
2. 좌측 사이드바에 파일 탐색기 표시
3. 폴더 클릭 시 하위 항목 토글
4. 파일 클릭 시 새 탭에서 열림
5. 파일 내용이 Monaco 에디터에 표시

### 기술 스펙

**컴포넌트**:
- `FileExplorer` - 메인 컴포넌트
- `FileTree` - 재귀적 트리 구조
- `FileItem` - 개별 파일/폴더
- `ContextMenu` - 우클릭 메뉴

**상태 관리** (Zustand):
```ts
interface FileSystemStore {
  tree: FileNode[];
  expandedFolders: Set<string>;
  selectedFile: string | null;
  toggleFolder: (path: string) => void;
  selectFile: (path: string) => void;
}
```

**IPC API**:
- `list-directory` - 디렉토리 목록
- `read-file` - 파일 읽기
- `watch-directory` - 파일 변경 감지

**의존성**:
- `react-window` - Virtual Scrolling
- `lucide-react` - 아이콘

## 에디터 그룹 (탭 시스템)

### 요구사항

**필수**:
- 여러 탭 동시 열기
- 탭 간 전환
- 탭 닫기
- 활성 탭 표시
- Monaco 에디터 통합

**선택**:
- 탭 드래그앤드롭 재정렬
- 탭 우클릭 메뉴
- 탭 분할 (Split Editor)
- 탭 그룹 저장/복원

### 사용자 시나리오

1. 파일 탐색기에서 파일 클릭
2. 새 탭이 에디터 영역에 생성
3. 탭 클릭으로 전환
4. X 버튼으로 닫기
5. 변경 사항은 자동 저장 또는 Cmd+S

### 기술 스펙

**컴포넌트**:
- `EditorGroup` - 탭 그룹 컨테이너
- `TabBar` - 탭 목록
- `Tab` - 개별 탭
- `EditorPanel` - Monaco 에디터 래퍼

**상태 관리** (Zustand):
```ts
interface EditorGroupStore {

  addTab: (groupId: string, file: File) => void;
  removeTab: (groupId: string, tabId: string) => void;
  setActiveTab: (groupId: string, tabId: string) => void;
}
```

**의존성**:
- `@monaco-editor/react` - 코드 에디터
- `react-dnd` - 드래그앤드롭

## 보안 시스템 (5-Layer)

### 요구사항

**필수**:
- CSP 정책 적용
- Security Headers 설정
- Zod 입력 검증
- Rate Limiting
- Path Validation

**선택**:
- 보안 로그 기록
- 실시간 모니터링
- 자동 차단 시스템

### 기술 스펙

**Layer 1 - CSP**:
```ts
'Content-Security-Policy': [
  "default-src 'self'",
  "script-src 'self'",
  "style-src 'self' 'unsafe-inline'"
].join('; ')
```

**Layer 3 - Zod**:
```ts
const FilePathSchema = z.string()
  .min(1)
  .max(1024)
  .regex(/^[a-zA-Z0-9\/._-]+$/);
```

**Layer 5 - Path Validation**:
```ts
function validatePath(path: string): string {
  const normalized = path.normalize(path);
  const resolved = path.resolve(basePath, normalized);

  if (!resolved.startsWith(basePath)) {
    throw new Error('Path Traversal');
  }

  return resolved;
}
```
