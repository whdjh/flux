# Part 1: 프로젝트 기초 정의

## 1. 프로젝트 개요

### 1.1 한 줄 요약
하버드 기록학 원칙을 기반으로, 사용자의 에너지를 최소화하면서 데이터를 수집하고 정리하여, 필요할 때 직관적으로 찾을 수 있게 해주는 차세대 메모 & 정보 관리 시스템

### 1.2 핵심 가설
```
1. 기본 가설
"사용자는 정보를 모으고 싶어하지만, 
 정리는 귀찮아하고,
 나중에 꼭 필요할 때 찾고 싶어한다"

2. 확장 가설
- 사용자들은 여러 도구를 사용하며 정보 관리에 많은 에너지를 소비중
- 기존 도구들은 진입장벽이 높거나 복잡함
- 정보의 맥락이 저장 과정에서 손실됨
- 저장된 정보를 찾는 과정이 비효율적
```

### 1.3 핵심 철학
```
1. "정리는 프로그램이, 활용은 사용자가"
   - 사용자는 수집에만 집중
   - 모든 정리/분류는 자동화
   - 직관적인 검색과 활용

2. "심플 is best"
   - 최소한의 UI 요소
   - 명확한 작동 방식
   - 불필요한 기능 제거

3. "작업 흐름을 방해하지 않는 UX"
   - Alt+클릭으로 즉시 수집
   - 백그라운드 처리 우선
   - 작업 중단 최소화

4. "사용자 에너지 최소화"
   - 원클릭 수집 원칙
   - 자동 정리/분류
   - 직관적 검색

5. "기록학적 가치 준수"
   - 진본성: 원본 데이터 보존
   - 맥락성: 수집 환경 기록
   - 무결성: 데이터 안전성
   - 검색성: 효율적 접근
```

## 2. 문제 정의 및 해결 방향

### 2.1 현재 사용자 Pain Points

```
1. 수집 단계의 문제점
- 텍스트: 복사/붙여넣기 반복 작업 필요
- 이미지: 다운로드 후 별도 정리 필요
- 링크: 북마크 폴더 관리 번거로움
- 동영상: URL만 저장 가능, 컨텍스트 손실
- 클립보드: 임시 저장 후 손실 위험
- 스크린샷: 별도 폴더 관리 필요
- 작업 중단: 수집 과정에서 현재 작업 중단

2. 저장 단계의 문제점
- 도구 분산:
  * 노션: 문서 정리
  * 픽픽: 스크린샷
  * 북마크: 링크
  * 갤러리: 이미지
- 중복 저장: 여러 곳에 같은 정보 저장
- 정리 부담: 폴더/태그 구조 관리 필요
- 저장 위치: 어디에 저장했는지 기억 어려움

3. 검색/활용 단계의 문제점
- 위치 파악: 어떤 앱에 저장했는지 기억 안 남
- 맥락 손실: 저장 당시의 컨텍스트 잊어버림
- 연관 검색: 관련 정보 함께 찾기 어려움
- 접근성: 여러 앱을 오가며 검색 필요
- 활용성: 저장된 정보의 재활용 어려움
```

### 2.2 해결 방향

```
1. 수집 단계 해결책
A. 원클릭 통합 수집 시스템
   - Alt + 클릭으로 모든 형식 수집
   - 드래그 없는 텍스트 선택
   - 자동 이미지 저장
   - 링크 컨텍스트 보존
   - 동영상 메타정보 포함
   - 클립보드 자동 감지
   - 스크린샷 영역 인식

B. 자동 메타데이터 생성
   - 수집 시점 타임스탬프
   - 출처 정보 자동 저장
   - 주변 컨텍스트 캡처
   - 연관 탭 정보 저장
   - 작업 환경 기록

2. 저장 단계 해결책
A. 통합 저장소 시스템
   - 단일 저장소로 통합
   - 자동 포맷 관리
   - 중복 방지 시스템
   - 로컬 우선 저장

B. 스마트 자동 정리
   - AI 기반 주제어 추출 (2-3개)
   - 자동 관계도 구성
   - 맥락 기반 분류
   - 7단계 북마크 태그
     * 빈 체크: 미확인
     * 체크박스: 확인
     * X 체크박스: 제외
     * 동그라미: 진행중
     * 세모: 중요
     * X: 취소
     * 별: 즐겨찾기

3. 검색/활용 단계 해결책
A. 통합 검색 시스템
   - 키워드 기반 검색
   - 맥락 기반 검색
   - 메타데이터 검색
   - 연관 검색 추천

B. 직관적 정보 표시
   - 시간순 정렬 기본
   - 관계도 시각화 (선택적)
   - 맥락 정보 복원
   - 연관 컨텐츠 추천
```

### 2.3 차별화 전략
```
1. 극도의 단순함
   - 모든 기능 Alt+클릭으로 통합
   - 최소한의 UI 요소
   - 자동화 극대화

2. 강력한 내부 처리
   - 하버드 기록학 원칙 준수
   - AI 기반 자동 분류
   - 맥락 보존 시스템

3. 에너지 효율성
   - 사용자 액션 최소화
   - 백그라운드 처리 최적화
   - 직관적 인터페이스

4. 실용적 가치
   - 즉각적인 정보 수집
   - 효율적인 정보 검색
   - 맥락 기반 정보 활용
```

    pub async fn collect(&self, event: ClickEvent) -> Result<Content> {
        let raw_content = self.collector.collect(event).await?;

    }
