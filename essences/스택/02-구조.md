## 핵심 폴더 설명

### `src/demos/`
실험적 기능 개발. 빠르게 프로토타입하고 검증 후 features/로 이동.

### `src/features/`
프로덕션 준비 완료. 테스트 및 문서화 완료된 모듈.

### `src/backend/`
Clean Architecture 3계층으로 구성된다.

domain 레이어는 순수 비즈니스 로직을 담는다. 프레임워크에 독립적이다. application 레이어는 Use Cases와 서비스 레이어를 담는다. infrastructure 레이어는 Drizzle ORM, Supabase, 파일 시스템을 담는다.

### `src/main/`
Electron Main Process. Node.js API 접근, 윈도우 관리, IPC 핸들러.

### `src/preload/`
보안 브릿지. contextBridge로 안전한 API만 노출.
