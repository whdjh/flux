# 유저 리서치 인사이트

> 2024년 1주차 사용자 인터뷰에서 추출한 핵심 발견

## 조사 개요

- **기간**: 2024년 1주차 (6일간)
- **방법**: Y Combinator, Amazon Working Backwards, JTBD 프레임워크
- **대상**: 지식 노동자 (R&D, BI, RM, 기획자, 작가 등)
- **목적**: 리서치 워크플로우 통합 도구 검증

## 핵심 Pain Points

### 1. 인지적 마찰 (Cognitive Friction)

**정의**: 정보가 여러 앱에 파편화되어 작업 전환 비용 발생

- **파편화 지점**: Notion, 북마크, 메모, 카톡, 클립보드, 이메일, 바탕화면
- **영향**: "생각의 흐름" 단절 → 깊은 사고(Deep Work) 방해 → 생산성의 질 저하
- **증거**: 글로리아 마크 연구 (작업 전환 시 평균 23분 소요)

> "정보를 찾으러 여러 앱을 헤매는 사이, 원래 생각을 잊어버리는 '사고의 단절' 경험"

### 2. 정보 손실 불안

**정의**: "분명 봤는데 어디에 저장했지?" 반복 경험

- **증상**: 중요 발표 전 자료 못 찾음 → 발표 실패
- **증상**: 획기적 아이디어를 메모했으나 위치 분실 → 영구 손실
- **감정**: 불안감, 좌절감, 통제력 상실

### 3. 도구 간 전환 피로

**정의**: 여러 도구 조합(Patchwork) 사용의 인지 부하

- **현재 대안**: Notion + Obsidian + Readwise + 북마크 + 메모 앱
- **문제**: 각 도구마다 다른 UI/UX 학습 필요 → 인지 부하 증가
- **역설**: 정보 정리 도구가 오히려 복잡성 증가

## 타겟 사용자

### 프로파일

- **직군**: R&D 연구원, 비즈니스 인텔리전스, 시장 조사, 기획자, 작가
- **특징**: 생산성에 민감한 "파워 유저"
- **목표**: Deep Work (깊이 있는 사고) 추구
- **행동**: 적극적으로 더 나은 워크플로우 탐색

### Last Straw Moments (전환 계기)

1. **중요 발표 직전 핵심 자료를 못 찾아 발표 망침**
2. **떠오른 아이디어를 발전시키려다 여러 앱 헤매다가 원래 생각 잊어버림**
3. **마감에 쫓겨 보고서 쓰는데 "분명 봤는데 어디 저장했지?" 반복**

## 핵심 요구사항

### 기능적 요구사항

1. **원클릭 수집**: 드래그앤드롭, 브라우저 확장프로그램으로 텍스트/이미지/링크 수집
2. **AI 자동 정리**: 1줄 요약 + 3개 핵심 키워드 자동 태깅
3. **통합 검색**: 모든 정보를 한곳에서 검색 (유의어 검색은 v2)
4. **유연한 정리**: 폴더/태그 기반 분류

### 감정적 요구사항

| 원하는 감정 | 피하고 싶은 감정 |
|------------|------------------|
| 통제감 | 압도감 |
| 차분함 | 불안감 |
| 창의적 희열 | 좌절감 |

### 사회적 욕구

"체계적이고 통찰력 있는 전문가"로 보이고 싶음

## 경쟁 분석

### 직접 경쟁자

| 제품 | 강점 | 약점 (사용자 불만) |
|------|------|-------------------|
| **Notion** | 올인원, 협업 | 느린 속도, 복잡성 |
| **Obsidian** | 연결 중심, 로컬 우선 | 높은 학습 곡선, 협업 어려움 |
| **Evernote** | 단순함, 안정성 | 기본 기능만, 혁신 부족 |
| **Readwise/Eagle** | 수집 특화 | 아이디어 발상 기능 없음 |

### 간접 경쟁자 (Unexpected Competitors)

**가장 강력한 경쟁자**: 카카오톡 "나에게 보내기", 이메일 "내게 쓰기", 바탕화면 .txt 파일, 머릿속 기억

- **강점**: 즉각적, 마찰 없음
- **약점**: 정보 파편화, 검색 불가, 맥락 손실

### 차별화 전략

1. **"인지 보호막" 컨셉**: 파편화로 인한 인지적 마찰을 근본적으로 해결
2. **전체 워크플로우 통합**: 수집 → 검토 → 통합 → 정제 → 발상 (한 곳에서)
3. **AI 기반 가속**: 요약/태깅으로 "검토" 단계 자동화
4. **즉시 가치**: 5분 안에 "아하!" 모먼트 제공

## 핵심 인사이트

### 발견 1: 문제의 본질 = "인지적 마찰"

**단순 시간 낭비가 아님** → 생각의 흐름 파괴 → 결과물의 질 저하

- 양적 생산성이 아닌 **질적 생산성** 문제
- "생각의 모멘텀" 상실로 Deep Work 불가능
- 지식 노동자의 핵심 경쟁력 위협

### 발견 2: 기존 솔루션의 근본적 한계

**특정 단계에만 특화**
- Notion: 정리/협업
- Readwise: 수집
- Obsidian: 연결

**여러 도구 조합 → 파편화 문제 해결 못함**

**간접 경쟁자가 더 낮은 마찰 제공**
- 카톡 "나에게 보내기"가 더 쉬움
- 사용자는 마찰이 가장 적은 방식 선택

### 발견 3: 성공의 핵심 = "즉각적 가치"

**5분 안에 "아하!" 모먼트 제공해야 채택됨**

1. **기존 습관보다 더 쉬워야 함** (vs 카톡 "나에게 보내기")
2. **AI 자동 요약/태깅이 첫 번째 Wow 포인트**
3. **설치 후 즉시 체감 가능한 편의성**

## 실행 전략

### MVP 핵심 기능 (검증된)

✅ **원클릭 수집**: 드래그앤드롭, 브라우저 확장
✅ **AI 자동 정리**: 요약 + 태깅
✅ **통합 뷰어**: 한곳에서 검색
❌ **제외**: 프로젝트 관리, 복잡한 문서 편집, 모바일 앱 (v1)

### 성공 지표

- **정량**: 주간 활성 통합자(Weekly Active Integrators) 수
- **정량**: 사용자당 주간 아이템 수집 수, 검색 빈도
- **정성**: "정보 찾는 시간 감소 + 창의적 작업 시간 증가" 피드백

### 장기 비전 (10년)

- 개인 세컨드 브레인 → 팀/조직 협업 인텔리전스 플랫폼
- AI 에이전트 마켓플레이스
- 지식 노동자를 위한 "OS"
