## 1. 프로젝트 개요

### 1.1 제품 소개
- **제품명**: 스냅노트 (SnapNote)
- **한줄요약**: 사용자의 에너지를 아껴주는 메모 기반 데이터 수집/정리 생산성 향상 프로그램
- **목표**: 사용자의 최소한의 노력으로 최대한의 데이터 관리 효율성 제공

### 1.2 핵심 가치
- 심플함을 최우선으로 하는 디자인
- 사용자 작업 흐름 방해 최소화
- 직관적이고 접근성 높은 인터페이스
- 사용자의 시간과 에너지 절약

### 1.3 타겟 사용자
- 정보 과부하에 시달리는 지식 노동자
- IT 업계 종사자
- 연구자, 작가, 학생 등 정보 수집이 필요한 직군

## 2. 핵심 기능

### 2.1 창 관리 시스템
- **분할 기능**: 2, 3, 4, 5, 6분할 레이아웃 지원
- **크기 조정**: 4px 단위 그리드 스냅, 1:1 비율 가이드
- **레이아웃 저장**: 사용자 정의 창 크기 설정 저장 기능
- **중앙 정렬**: 화면 중앙 정렬 레이아웃 지원

### 2.2 메모 기능
- **텍스트 편집기**: .txt, .md 형식 지원
- **Ctrl+D 멀티 선택**: VSCode와 유사한 다중 선택/편집 기능
- **자동 저장**: 실시간 변경사항 자동 저장
- **서식 지원**: 기본 마크다운 서식 (제목, 굵게, 목록, 링크 등)

### 2.3 스크래핑 기능
- **원클릭 수집**: Alt+클릭으로 텍스트/링크/이미지 스크래핑
- **드래그 후 Alt+클릭**: 선택 영역 스크래핑
- **클립보드 통합**: 클립보드 내용 자동 캡처 옵션
- **출처 정보 저장**: URL, 앱 이름 등 출처 메타데이터 자동 기록

### 2.4 북마크 시스템
- **7가지 상태 아이콘**:
  - 빈 체크: 미확인
  - 체크박스: 확인 완료
  - X 체크박스: 제외/거절
  - 동그라미: 진행중
  - 세모: 주의/중요
  - X: 취소/폐기
  - 별: 즐겨찾기
- **북마크 모아보기**: 우측 사이드바에 북마크별 컨텐츠 표시
- **상태 필터링**: 북마크 상태별 필터링 기능

### 2.5 자동 정리 기능
- **시간순 정리**: 생성/수정 시간별 정렬
- **AI 태깅**: 컨텐츠 자동 분석 및 태그 생성
- **자동 요약**: 수집된 정보 자동 요약 (3-5줄)
- **유의어 검색**: 관련 키워드 포함 검색 기능

### 2.6 UI/UX 설계
- **카드 레이아웃**: 스크랩 카드 형태 표시
- **다중 뷰**: 리스트뷰, 그리드뷰, 컴팩트뷰
- **테마**: 라이트/다크/커스텀 테마 지원
- **저대비 디자인**: 눈의 피로도를 줄이는 색상 구성

## 3. 기술 스택

### 3.1 프론트엔드
- **프레임워크**: Tauri + React + TypeScript
- **스타일링**: UnoCSS / TailwindCSS
- **상태관리**: Zustand (또는 Redux)
- **UI 라이브러리**: 자체 구현 컴포넌트 (Atomic Design)

### 3.2 백엔드
- **언어**: Rust
- **저장소**: 로컬 파일 시스템 (초기), 선택적 클라우드 연동 (후기)
- **동시성**: Tokio
- **웹 프레임워크**: Actix-web (클라우드 연동 시)

### 3.3 AI/ML 기능
- **텍스트 분석**: Claude-3.5-sonnet API 또는 로컬 모델
- **임베딩**: Rust-bert, fasttext-rs
- **태깅 시스템**: 자체 개발 분류 알고리즘

### 3.4 검색 엔진
- **기본 검색**: Tantivy
- **고급 검색**: ElasticSearch 도입 고려

## 4. 구현 계획

### 4.1 단계별 구현 순서
1. **창 관리 시스템** (3-4주)
   - 기본 애플리케이션 설정
   - 분할 레이아웃 시스템
   - 크기 조절 및 저장 기능

2. **핵심 데이터 구조 및 저장소** (2주)
   - 데이터 모델 설계
   - 로컬 저장소 구현
   - 기본 CRUD 기능

3. **메모 & 스크래핑 기능** (3-4주)
   - 기본 텍스트 편집기
   - Alt+클릭 스크래핑
   - Ctrl+D 다중 선택

4. **북마크 & 정리 기능** (2-3주)
   - 북마크 상태 시스템
   - 카드 레이아웃
   - 정렬 및 필터링

5. **검색 & UI 개선** (2-3주)
   - 기본 검색 기능
   - 테마 시스템
   - 반응형 디자인

6. **AI 기능 통합** (3-4주)
   - 자동 태깅
   - 자동 요약
   - 연관 검색

7. **최적화 및 고급 기능** (2-3주)
   - 성능 최적화
   - 백업/복구
   - 확장 기능

### 4.2 MVP 범위 (2-3개월)
- 창 관리 시스템 (기본 기능)
- 메모 입력 및 편집
- Alt+클릭 스크래핑
- 7가지 북마크 아이콘
- 시간순 정리
- 기본 검색
- 라이트/다크 테마

### 4.3 고급 기능 (추후 개발)
- AI 자동 태깅/요약
- 클라우드 동기화
- 협업 기능
- 플러그인 시스템
- 블록체인 거래소

## 5. 프로젝트 구조

### 5.1 폴더 구조
```
snapnote/
├── src-tauri/                   # Rust 백엔드
│   ├── src/
│   │   ├── commands/            # Tauri 명령어
│   │   ├── services/            # 비즈니스 로직
│   │   ├── models/              # 데이터 모델
│   │   └── main.rs              # 메인 엔트리 포인트
│   └── Cargo.toml               # Rust 의존성
│
├── src/                         # 프론트엔드 (React)
│   ├── components/              # UI 컴포넌트
│   │   ├── atoms/               # 기본 UI 요소 
│   │   ├── molecules/           # 복합 컴포넌트
│   │   ├── organisms/           # 기능 단위 컴포넌트
│   │   └── templates/           # 레이아웃 템플릿
│   │
│   ├── features/                # 기능별 모듈
│   │   ├── window-manager/      # 창 분할 관리
│   │   ├── memo/                # 메모 관리
│   │   ├── scraping/            # 스크래핑 기능
│   │   ├── bookmark/            # 북마크 시스템
│   │   └── search/              # 검색 기능
│   │
│   ├── store/                   # 상태 관리 (Zustand)
│   ├── utils/                   # 유틸리티 함수
│   ├── styles/                  # 스타일 관련
│   └── App.tsx                  # 루트 컴포넌트
│
└── [기타 설정 파일들]
```

### 5.2 주요 컴포넌트
- **WindowManager**: 창 분할 및 관리
- **MemoEditor**: 텍스트 편집기
- **ScrapCard**: 스크랩 정보 카드
- **BookmarkIcon**: 북마크 상태 아이콘
- **Sidebar**: 좌/우 사이드바
- **SearchBar**: 검색 기능

- **단위 테스트**: 핵심 기능 컴포넌트
- **통합 테스트**: 기능 간 상호작용
- **E2E 테스트**: 사용자 워크플로우

### 8.2 품질 지표
- **반응 속도**: 200ms 이내 사용자 입력 반응
- **메모리 사용량**: 최대 500MB 이내
- **저장소 효율성**: 최적화된 데이터 저장
- **오류율**: 99.9% 이상의 작업 신뢰성

## 9. 검증할 가설

### 9.1 사용자 가설
1. 사용자들은 원클릭 스크래핑으로 더 쉽게 정보를 수집할 수 있다
2. 7가지 북마크 아이콘으로 정보의 상태를 직관적으로 관리할 수 있다
3. 창 분할 기능으로 작업 효율성이 향상된다
4. 시간순 정리와 북마크 필터링만으로도 기본적인 정보 관리가 가능하다

### 9.2 기술 가설
1. Tauri + Rust 조합으로 성능과 크로스 플랫폼 지원을 모두 달성할 수 있다
2. 로컬 저장소로 충분한 프라이버시와 속도를 보장할 수 있다
3. 창 분할 UI는 React로 효율적으로 구현 가능하다
