# 보일러플레이트 비전

← [문서 네비게이션](../00-시작/00-시작하기.md)

## 이게 무엇인가

**VS Code의 강력한 레이아웃과 Chrome의 우아한 애니메이션을 결합한 데스크톱 앱 보일러플레이트**

## 왜 만들었나

데스크톱 앱을 처음부터 만드는 것은 시간이 많이 걸린다. 검증된 UX 패턴을 재창조하는 것은 중복 작업이며, 대부분의 보일러플레이트는 전문적인 UI/UX가 부족하다.

이 보일러플레이트는 미리 구축된 VS Code 레이아웃 시스템과 바로 사용 가능한 Chrome 탭 애니메이션을 제공한다. 데모 우선 개발 워크플로우로 빠른 프로토타이핑이 가능하다.

## 핵심 기능

### VS Code에서 가져온 기능

- ✅ 3-패널 레이아웃 (사이드바 + 메인)
- ✅ 분할 뷰 시스템
- ✅ 트리 뷰가 있는 파일 탐색기
- ✅ 상태가 있는 탭 관리
- ✅ 키보드 우선 내비게이션

### Chrome에서 가져온 기능

- ✅ 200ms 부드러운 탭 애니메이션
- ✅ 시각적 피드백이 있는 드래그 앤 드롭
- ✅ 탭 재정렬 애니메이션
- ✅ 호버 효과 및 트랜지션

## 설계 철학

> **"최고의 인터페이스는 인터페이스가 없는 것. 그 다음은 이미 알고 있는 것."**

### 핵심 원칙

1. **익숙함 우선** - 사람들이 이미 아는 패턴 사용
2. **성능이 중요** - 100ms 이하 응답 시간
3. **개발자 경험** - 데모 우선, 타입 안전, 테스트 가능

## 누가 사용해야 하나

생산성 도구를 만드는 개발자, 빠르게 전문적인 UI를 원하는 팀, 검증된 UX 패턴이 필요한 프로젝트에 적합하다.

모바일 우선 애플리케이션, 간단한 단일 페이지 도구, 게임이나 미디어 플레이어에는 적합하지 않다.

## 성공 지표

### 개발 속도

- 클론에서 실행까지: 5분 이내
- 첫 커스텀 기능: 1시간 이내
- 프로덕션 준비: 1주일 이내

### 사용자 경험

- VS Code 사용자는 학습 곡선 제로
- 익숙한 키보드 단축키 작동
- 부드러운 60fps 애니메이션

## 미래 비전

이 보일러플레이트는 더 많은 VS Code 기능(커맨드 팔레트, 확장), 추가 Chrome 패턴(주소창, 개발자 도구), 라이트/다크 모드가 있는 테마 시스템, 확장성을 위한 플러그인 아키텍처와 함께 발전할 것이다.
