## 1. 프로젝트 개요

### 1.1 제품 정의
"심플노트"는 사용자 경험을 최우선으로 하는 지능형 메모 애플리케이션입니다. 심플한 인터페이스와 강력한 AI 기능을 결합해 최소한의 노력으로 최대의 정보 관리 효율성을 달성합니다.

### 1.2 핵심 가치
- 심플함: 불필요한 복잡성 제거
- 효율성: AI 기반 자동화로 사용자 노력 최소화
- 프라이버시: 사용자 데이터 보호 최우선
- 지능형 관리: 컨텍스트 인식 및 예측 가능한 자동 분류
%% - 개성화: 디지털 메모의 획일성 극복 %%

### 1.3 목표
1. 사용자의 생각을 방해 없이 빠르게 기록
2. AI를 활용한 자동 정보 구조화 및 검색 최적화
3. 개인 및 팀 생산성 향상을 위한 협업 도구 제공
%% 4. 메모의 개성을 살려 기억력 향상 지원 %%

## 2. 핵심 기능

### 2.1 심플한 메모
- 지원 형식: .txt, .md
- 특징: 
  - 순수 텍스트 입력에 집중
  - 마크다운 문법 지원으로 간단한 서식 적용 가능
- 페이지 넘기기: 마우스 클릭이나 방향키로 가상 페이지 전환

### 2.2 효율적 데이터 수집
- 단축키 기반 빠른 정보 저장:
  - Ctrl+Shift+H: 텍스트 하이라이팅
  - Ctrl+Shift+L: 링크 저장
  - Ctrl+Shift+I: 이미지 캡처
  - Ctrl+Shift+V: 클립보드 내용 저장

### 2.3 AI 기반 자동 관리
- 자동 분류:
  - 링크: 도메인별 자동 그룹화
  - 시간: 일별, 주별, 월별 자동 정리
  - 형식: 텍스트, 이미지, 링크 등 형식별 분류
- 자동 태깅:
  - NLP 기반 키워드 추출
  - 문맥 분석을 통한 관련 태그 생성
- 내용 요약: 텍스트 자동 요약 (2줄), 키워드 나열(2줄, 1~3순위 강조효과) 
- 키워드 추출: 메모의 핵심 키워드 추출

### 2.4 프라이버시 중심 설계
- 로컬 저장: 기본 설정으로 모든 데이터 로컬 저장
- 암호화: AES-256 암호화로 로컬 데이터 보호
- 선택적 클라우드: 사용자 선택 시 E2EE(발신자와 수신자만이 해독할 수 있는 암호화 방식) 적용된 클라우드 동기화

### 2.5 협업 기능
- 실시간 공동 편집: WebRTC 기반 동시 편집 지원
- 권한 관리: 읽기, 쓰기, 관리자 등 세분화된 권한 설정
- 변경 이력: Git 스타일의 버전 관리 및 롤백 기능

## 3. 사용자 경험 (UX) 설계

### 3.1 직관적 UI
- 단순 구조: 메인 화면에 필수 기능만 노출
%% - 제스처 기반: 스와이프, 핀치 등 자연스러운 제스처 조작 %%
- 컨텍스트 메뉴: 우클릭으로 상황에 맞는 옵션 제공

### 3.2 사용자 작업 흐름 최적화
- 자동 저장: 입력 즉시 자동 저장으로 데이터 손실 방지
- 백그라운드 처리: AI 분석, 동기화 등 무거운 작업은 백그라운드에서 처리
- 오프라인 지원: 인터넷 연결 없이도 주요 기능 사용 가능

### 3.3 커스터마이즈 옵션
- 테마: 라이트/다크 모드, 사용자 정의 색상 (블랙, 화이트, 회색 포함)
- 레이아웃: 그리드/리스트 뷰 전환, 사이드바 위치 조정
- 단축키: 사용자 정의 단축키 설정
- 메모 개성화: 글꼴, 배경, 테두리 등 커스텀 설정

## 4. UI 디자인

### 4.1 전체 레이아웃
- 사이드바 (좌측):
  - 폴더 구조 (트리 뷰)
    - 최상위: 개인/공유 폴더
    - 2단계: 사용자 정의 카테고리
    - 3단계: AI 자동 생성 서브카테고리
  - 태그 목록 (알파벳순 정렬)
  - 즐겨찾기 메모
- 메인 영역 (중앙):
  - 메모 목록 또는 편집 화면
- 검색창 (상단):
  - 전체 텍스트 검색
  - 태그, 날짜 필터 옵션
  - 유의어 포함 자연어 검색

### 4.2 디자인 요소
- 기본 형태: 라운드 처리된 직사각형 (8px 반경)
- 투명도: 0-100% 조절 가능 (기본값 90%)
- 크기 조정: 4px 단위로 창 크기 조절 가능
- 색상: 파스텔 톤 기반, 눈의 피로도 최소화

### 4.3 하단 정보 바
- 왼쪽: 현재 메모의 줄 수, 단어 수, 글자 수
- 중앙: 동기화 상태 표시
- 오른쪽: 화면 크기 (%), 현재 시간

### 4.4 특수 기능 UI
- 핫코너 (우측 하단): 
  - 마우스 오버 시 빠른 메모 작성 창 팝업
- 항상 위 버튼:
  - 메모장을 다른 창 위에 고정
- AI 아트워크:
  - 메모 내용 기반 생성 이미지를 배경 또는 테두리로 표시

## 5. 추가 기능

### 5.1 생산성 도구
- 아이젠하워 매트릭스: 중요도/긴급도 기반 태스크 분류
- Todo 리스트: 체크박스 형식의 할 일 목록
- 뽀모도로 타이머: 25분 작업, 5분 휴식 사이클 관리
- 코넬노트: 노트 템플릿 제공 (요약, 키워드, 본문 구조)

### 5.2 시스템 통합
- 클립보드 관리: 최근 복사 항목 히스토리 관리
- 백그라운드 실행: 시스템 트레이 상주, 빠른 액세스 제공

### 5.3 AI 어시스턴트
- 자연어 명령: "이 내용 요약해줘", "관련 태그 추천해줘" 등
- 컨텍스트 인식: 현재 작업 중인 메모와 관련된 정보 추천
- 링크 요약: 저장된 링크 내용 2-3줄로 자동 요약

### 5.4 시각화
- 마인드맵: 관련 메모 간 연결 시각화
- 타임라인: 시간순 메모 배열 및 중요 이벤트 표시

## 6. 기술 스택

### 6.1 프론트엔드
- Tauri: 경량 크로스 플랫폼 프레임워크 (선택 이유: 네이티브 성능, 작은 번들 크기)
- React  + TypeScript : 컴포넌트 기반 UI 개발, 정적 타입 지원 (선택 이유: 생산성, 유지보수성)
- TailwindCSS: 유틸리티 퍼스트 CSS 프레임워크 (선택 이유: 빠른 UI 개발, 일관성)
- WebAssembly(WASM): 성능 중심 모듈 구현 (선택 이유: 네이티브에 가까운 성능)

### 6.2 백엔드
- Rust 1.68+ (Actix-web 4.x): 고성능 웹 서버 (선택 이유: 안정성, 속도, 메모리 안전성)
- Tokio 1.x: 비동기 런타임 (선택 이유: 효율적인 리소스 관리)

### 6.3 데이터베이스
- PostgreSQL 14+: 메인 데이터베이스, JSON 지원 (선택 이유: 확장성, 복잡한 쿼리 지원)
- SQLite 3.x: 로컬 저장 및 오프라인 모드용 (선택 이유: 가벼움, 내장 가능)
- Redis 6.x: 캐싱, 세션 관리 (선택 이유: 빠른 읽기/쓰기 성능)
- Qdrant: 벡터 유사도 검색 엔진 (선택 이유: 효율적인 유사 메모 검색)

### 6.4 AI 및 NLP
- Claude-3.5-sonnet: 고급 자연어 처리 및 생성 (선택 이유: GPT-4 대비 우수한 성능)
- Rust-bert: 경량 BERT 모델 구현 (선택 이유: 빠른 텍스트 분석)
- lindera: Rust 기반 형태소 분석기 (선택 이유: 다국어 지원)
- fasttext-rs: 빠른 텍스트 분류 및 임베딩 (선택 이유: 효율적인 텍스트 분류)

### 6.5 검색 엔진
- Tantivy: Rust 기반 전문 검색 엔진 (선택 이유: 빠른 검색 속도, Rust 생태계 통합)

### 6.6 보안
- ring 0.16+: 암호화 라이브러리 (선택 이유: 검증된 보안성)
- jsonwebtoken 8.x: JWT 기반 인증 (선택 이유: 표준 준수, 확장성)

### 6.7 협업 및 동기화
- yrs: Rust 기반 CRDT 구현체 (선택 이유: 실시간 협업에 최적화)
- tokio-tungstenite: WebSocket 지원 (선택 이유: 실시간 통신)

### 6.8 기타
- tracing: Rust 로깅 및 계측 프레임워크 (선택 이유: 상세한 모니터링)
- lapin: RabbitMQ 클라이언트 (선택 이유: 메시지 큐 처리)
- Prometheus + Grafana: 모니터링 및 시각화 (선택 이유: 실시간 성능 모니터링)

## 7. 개발 로드맵

### Phase 1: MVP (2개월)
- 기본 메모 기능 구현
- 로컬 저장 및 암호화
- 간단한 자동 분류 (날짜, 형식별)
- 페이지 넘기기 기능 구현

### Phase 2: AI 통합 (3개월)
- 자동 태깅 시스템 구축
- 내용 요약 기능 추가
- 키워드 추출 및 관련 메모 추천
- AI 아트워크 생성 기능 구현

### Phase 3: 협업 기능 (2개월)
- 실시간 공동 편집 구현
- 권한 관리 시스템 개발
- 변경 이력 추적 및 관리

5. 크로스 플랫폼: 모든 기기에서 일관된 경험 제공

## 10. 결론

"심플노트"는 현대인의 복잡한 정보 관리 요구를 충족시키는 혁신적인 메모 애플리케이션입니다. 심플함과 강력한 AI 기능의 조화, 프라이버시 중심 설계, 그리고 사용자 중심의 UX를 통해 기존 메모 앱의 한계를 뛰어넘는 새로운 표준을 제시합니다. 

핵심 차별점:
1. 최소한의 노력으로 최대의 정보 관리 효율성 달성
2. AI 기반 자동화로 사용자의 인지 부하 감소
3. 메모의 개성을 살려 기억력과 창의성 향상 지원
4. 프라이버시와 협업의 균형 잡힌 통합

지속적인 개선과 사용자 피드백 반영을 통해, "심플노트"는 개인과 팀의 생산성을 획기적으로 향상시키는 필수 도구로 자리매김할 것입니다. 우리의 비전은 단순한 메모 앱을 넘어, 사용자의 두 번째 뇌로 기능하는 지능형 정보 관리 플랫폼을 만드는 것입니다.

우리가 메모한 기억과 메모가 수첩의 몇번 째에 있다는 기억은 융합 되어있어. 디지털에선 불가능하지, 해결법으론 기억의 궁전 or 맵 or 레이더 or ...
