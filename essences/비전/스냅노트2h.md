## 한줄 요약
사용자의 에너지를 아껴주는 메모 기반 데이터 수집/정리 생산성 향상 프로그램

## 목표
사용자의 최소한의 노력으로 최대한의 데이터 관리 효율성을 제공하는 것

## 주요 기능

### 1. 메모장
- 기본 텍스트 편집기에 Ctrl + D 기능 추가
- 옵시디언의 마크다운 형식보다 접근성 향상

### 2. 원클릭 스크래핑
- Alt + 클릭 또는 드래그 후 Alt + 클릭으로 텍스트, 이미지, 링크, 동영상을 한 섹션에 수집
- 고려사항: 클립보드 추가 기능

### 3. 검색 기능
- 유의어 포함, 중요 키워드 추출 후 태그 생성 (NLP 또는 무료 LLM 사용)

### 4. 자동 정리
- 수집한 정보들을 한 묶음으로 모아볼 수 있게 함
- 옵션: 시간대별 나열, 키워드별 나열, 주제별 나열

### 5. 북마크 기능
- 우측 사이드바에 메모장을 키고 수집된 정보들에서 Alt + 클릭으로 북마크 나열
- 아이콘: 빈 체크, 체크박스, X 체크박스, 동그라미, 세모, X, 별

### 6. 화면 분할
- 2, 3, 4, 5, 6 분할, 중앙 정렬 지원
- 사용자 정의 창 크기 설정 가능
- 4px 단위로 조정 가능, 1:1 비율 가이드 제안

### 7. 크로스 플랫폼
- PC, 아이폰, 안드로이드, 아이패드 등 다양한 기기 지원

### 8. 보안
- 로컬 저장으로 높은 보안성 제공
