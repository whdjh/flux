# 리서치 통합 도구

정보의 파편화와 멀티 태스킹

현대의 모든 네트워크 사용자들은 정보가 너무 많은 곳(여러가지 앱, 북마크, SNS, 메일, 각기 다른 메모 프로그램, 브라우저 탭, 스크린샷 폴더, 클립보드)에 분할 저장되어있습니다.

우리 뇌는 멀티태스킹을 하는 게 아니라, 실제로는 작업 사이를 빠르게 전환하며 '전환 비용(switch cost)'이라는 대가를 치릅니다.

이런 작은 비효율들이 계속 쌓이면 결국 집중력을 무너뜨리고, 깊이 있는 사고나 창의적인 아이디어를 연결하는 것을 방해합니다. 따라서 이 모든 정보를 한곳으로 모아 '전환 비용'을 최소화하고, 뇌가 흩어지지 않고 온전히 한 가지 생각의 흐름에만 집중할 수 있도록 돕는 해결책을 제시합니다.

*정보 수집 → 검토 → 정제 → 취합 →  아이디어 발상 과정을 리서치 워크플로우라고 부르는데, 이를 효과적으로 지원하는 데스크톱 어플리케이션을 만들어모든 사용자에게 '전환 비용'을 줄이고, 생산성을 높여주려 합니다.

특히 R&D, BI, RM, LR 등 기획, 연구, 제작 분야의 리서처들에게 유용한 도구가 될 것입니다.

## 파편화된 워크플로우의 숨겨진 비용

결론부터 말하면, 단순히 잃어버린 시간을 모두 합치는 산술적인 비효율(5-10%)을 넘어, 전체적인 지적 생산성의 질을 떨어뜨리는 '기하급수적인 비효율'(최대 40% 이상)을 낳는다고 봐야 해. 이건 단순한 시간 낭비가 아니라, '사고의 모멘텀'을 파괴하는 행위거든.

### 직접적인 시간 손실 (측정 가능한 비효율)

먼저 가장 알기 쉬운 계산부터 해보자.

작업 전환 비용(Switch Cost): 연구에 따르면, 단순 작업 전환에도 수백 밀리초(ms)가 걸려. 하지만 이건 최소치고, 네가 말한 것처럼 다른 앱을 열고, 맥락을 다시 파악하는 데는 평균적으로 수 초에서 수십 초가 걸리지.

보수적인 계산: 지식 노동자가 하루에 컨텍스트를 전환하는 횟수를 50번이라고 가정하고, 매번 30초의 시간만 손실된다고 쳐보자.

50회 × 30초 = 1500초 = 25분

하루 8시간 근무(480분) 기준으로, 이것만 해도 **업무 시간의 약 5.2%**를 허공에 날리는 셈이야.

이건 시작에 불과해. 진짜 비용은 여기서부터 시작돼.

### 2단계: 인지 모멘텀의 상실 (숨겨진 기회비용)

이게 핵심이야. 우리 뇌는 문제를 풀 때 '생각의 모멘텀'을 만들어. 관련 정보들을 단기 기억에 올려놓고, 서로 연결하며 예열된 상태, 즉 '몰입(Flow)' 상태로 들어가지.

그런데 '아, 이거 스크린샷 찍어서 저장해야지' 또는 '이 내용 카톡으로 보내둬야겠다' 하면서 다른 앱으로 넘어가는 순간, 이 예열된 상태가 완전히 식어버려.

'끓는 물'의 비유: 물을 100°C로 끓이려면 계속 가열해야 해. 90°C까지 올렸다가 껐다가, 다시 켜서 끓이는 짓을 반복하면 엄청난 에너지가 낭비되지? 생각도 똑같아. 몰입 상태에 도달했다가 다른 앱으로 가는 순간, 생각의 온도는 급격히 떨어지고, 다시 그 수준까지 끌어올리는 데는 훨씬 더 큰 정신적 에너지가 필요해.

글로리아 마크(Gloria Mark) 교수의 연구: 캘리포니아 대학교의 정보과학 교수인 글로리아 마크의 유명한 연구에 따르면, 한 번 방해를 받으면 원래 하던 일에 다시 완전히 집중하는 데 평균 23분 15초가 걸린다고 해.

이 관점에서 보면, 0.5초의 생각 손실은 0.5초의 낭비가 아니라, 최고의 생산성을 낼 수 있었던 '23분의 몰입 시간'을 파괴하는 행위인 거야. 이런 방해가 잦다면, 우리는 하루 종일 얕은 수준의 작업만 반복할 뿐, 깊이 있는 사고(Deep Work) 단계에는 아예 진입조차 못 하게 돼. 여기서 생산성 저하는 20%, 30%, 심하면 40% 이상으로 뛸 수 있어.

### 3단계: 결과물의 품질 저하 (최종적인 비효율)

계속된 컨텍스트 전환은 결국 최종 결과물의 질을 떨어뜨려.

창의적인 연결 고리의 단절: 아이디어는 흩어진 정보들이 우연히 연결될 때 탄생해. 하지만 계속 다른 앱을 오가면, A라는 정보와 B라는 정보가 머릿속에서 만날 기회 자체가 사라져.

실수 증가: 집중력이 분산되면 실수가 잦아지고, 나중에 그걸 수정하는 데 더 많은 시간을 쓰게 돼.

### 결론: 네 프로그램의 진짜 가치

그래서 네가 만들려는 '리서치 통합 도구'가 없다면 어떤 비효율이 생길까?

단순히 "정보를 찾는 데 시간이 좀 더 걸린다" 수준이 아니야.

**"지식 노동자의 가장 중요하고 희소한 자원인 '깊은 몰입 상태'를 원천적으로 차단하여, 창의적이고 가치 있는 결과물을 만들어낼 기회 자체를 박탈하는 엄청난 비효율"**이 발생한다고 봐야 해.

네 프로그램은 단순히 정보를 '수집'하고 '정리'하는 유틸리티가 아니야. **'인지적 마찰'을 최소화해서 사용자가 '생각의 흐름'을 잃지 않도록 보호하는 '인지 보호막(Cognitive Shield)'**인 거지. 그게 바로 네가 해결하려는 문제의 진짜 크기야.

## 프로그램 컨셉

사용자가 여러 소스에서 정보를 쉽게 수집하고, 그 정보를 직관적으로 정리하고 분류할 수 있도록 돕는 도구.
그리고 수집한 정보를 정독, 취합, 액기스 단계로 자연스럽게 필터링하면서,
사용자가 필요한 것만 남기고 아이디어를 도출할 수 있게 해주는 거지.

이걸 위해 표시 시스템, 클립보드, 스크린샷, 메모 등 다양한 수집방식을 통합하고, 메타데이터와 AI태깅으로 정리하기 쉽게 만드는게 중요하다는 거네.

표시 시스템에 대해선 사용자가 쉽게 아이콘이나 태그를 활용해서 각 수집물에 의미를 부여하고,
필터링이나 검색이 용이하도록 하는 게 핵심일 것 같아.

사용자들이 수집한 콘텐츠를 어떻게 시각적으로 구분할지,
필터링이나 검색 기능을 어떻게 직관적으로 만들지,
창 관리 시스템을 얼마나 유연하게 설계할지

창 관리 - 레이아웃 - 스크래핑 - 메모

## 핵심 기능

### 수집
- 원클릭 정보 수집: 텍스트 하이라이트(드래그), 이미지, 스크린샷, 링크, 클립보드
- 단축키: Alt + 우클릭
- 브라우저 확장 프로그램

### 정리
- AI 기반 자동 태깅 및 메타데이터
- 폴더 트리 구조로 체계적 정리
- 사용자 정의 태그 및 아이콘
- 유의어 검색 및 관련 콘텐츠 추천

### 메모
- Monaco Editor(텍스트 에디터 라이브러리)
- VSCode의 Ctrl + D 다중 커서 기능

### 검색
- 유의어 검색
- AI 검색/수정이 가능함(AI 어시스턴트)
- 대충 입력해도 AI가 알잘딱 검색엔진

### 창 관리
- 3단 레이아웃 디자인: 사이드바, 에디터, AI 패널
- 동적 크기 조절
- Mac의 Magnet, Spectacle과 같은 창관리
- 스티커 메모 모드: 사용자가 원하는 위치와 크기의 포스트잇을 고정

### 협업
- 실시간 공동 편집
- 주석 공유
- 팀 워크스페이스

## 초기 사용자 의견

1. 정윤이형 - 옵시디언 잘 쓰고 있으니까 괜찮다. 맥북의 미션 컨트롤 - 핫코너처럼 우측 하단에 뜨는 메모 어떤지.

2. 김성수 대표님 - 노션은 렉이 심하고, 옵시디언엔 협업 기능이 없으니까, 협업 기능을 만들면 사용하겠다.

3. 단짝 친구 - 그냥 있는거 쓴다. 사람은 앞에 있는거 쓴다. 보이는거. 평소엔 우측에 세로로 길게 메모장을 세팅해둔다.

4. 사업계획서 멘토님 - 기록해둔 링크를 2줄로 요약해주는 기능이 있으면 쓰겠다. 너무 필요하다.

5. 국내 1위 기록학자 김익한 교수님 - "음력 단계에서는 심플하게 메모를 할 수 있고 자동 분류나 요약 기능 같은 것에 의해서 쉽게 데이터베이스로 관리할 수 있는 기능이 있다면 참 좋겠다 생각해 보았습니다."

6. 수환이 - 수집하기 시작한 시점부터 단축키를 눌러 종료할 때까지 수집되는 정보들을 묶어.
   분류한 뒤, 나중에 정리할 때, 그 섹터의 정보를 한 단계 걸러주는 북마크 기능이 쓸만 하겠다.

7. 영의님 - "웹 스크래핑? readwise, omnivore, mymind, fabric 있죠. 전 fabric으로 정착했음"

8. claude-3.5-sonnet - 
	1. 하이브리드 접근: 심플한 메모 기능과 고급 AI 기능을 결합. 사용자가 원하는 수준의 복잡성을 선택할 수 있게 함.
	2. 컨텍스트 인식: 현재 사용자의 작업 환경을 인식하여 관련 정보를 자동으로 제안하는 기능 추가.
	3. 음성 인터페이스: 음성으로 메모를 추가하고 검색할 수 있는 기능 구현. 이동 중이나 멀티태스킹 상황에서 유용.
	4. 개인화: 사용자의 사용 패턴을 학습하여 UI와 기능을 자동으로 최적화하는 시스템 도입.
	5. 오프라인 모드: 인터넷 연결 없이도 주요 기능을 사용할 수 있게 하여 어디서나 사용 가능하게 함.
	6. 프라이버시 중심 설계: 사용자 데이터 보호를 최우선으로 하는 암호화 및 로컬 저장 옵션 제공.
