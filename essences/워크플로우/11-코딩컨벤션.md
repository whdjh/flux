## 에러 처리

```ts
// 명시적 에러 처리
try {
  const content = await readFile(path);
  return { success: true, data: content };
} catch (error) {
  if (error instanceof ValidationError) {
    return { success: false, error: error.message };
  }
  throw error;  // 예상치 못한 에러는 상위로
}
```
