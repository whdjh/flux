## 1. 추진 배경 및 목적

### 1) 제안 아이디어 발굴 배경 및 해결하고자 하는 문제

#### 문제의식

현대인들은 스마트워치, 건강 앱 등을 통해 방대한 건강 데이터를 수집하고 있으나, 다음과 같은 근본적인 문제에 직면해 있습니다.

**첫째, 데이터 이해의 어려움**
- 웨어러블 기기: "HRV 28ms", "수면 효율 73%" 등 전문 용어와 숫자만 제시
- 사용자 반응: "이 숫자가 좋은 건지 나쁜 건지 모르겠다"
- 결과: 데이터는 쌓이지만 의미 있는 행동 변화로 이어지지 않음

**둘째, 개인화 부족**
- 기존 건강 앱: 20대와 50대에게 동일한 일반적 조언 제공
- 사용자 반응: "내 상황에 맞는 조언인지 확신이 없다"
- 결과: 조언을 따르지 않거나 며칠 만에 서비스 이탈

**셋째, 실천의 어려움**
- 건강 앱 알림: "오늘 운동하세요!", "물 2L 마시세요!"
- 사용자 반응: "잔소리 같다", "귀찮다"
- 결과: 알림 차단, 앱 삭제, 70% 이상이 3개월 내 이탈

**넷째, 환경 요인 무시**
- 기존 솔루션: 개인의 생체 데이터만 측정
- 현실: 공기질, 온도, 습도 등 환경이 건강에 미치는 영향 큼
- 결과: 불완전한 건강 관리

#### 발굴 계기

A1 제품의 핵심 기술을 분석하던 중, 다음과 같은 인사이트를 발견했습니다.

1. **비접촉 생체 측정**: 웨어러블의 가장 큰 단점인 '착용의 불편함'을 해결
2. **환경 센서 + 제어**: 단순히 측정만 하는 것이 아니라 환경을 직접 바꿀 수 있음
3. **자율주행**: 집 전체를 이동하며 사용자를 따라다니는 것이 가능
4. **24시간 가동**: 배터리 걱정 없이 지속적인 모니터링 가능

→ **A1은 '측정'을 넘어 '환경 최적화'까지 가능한 유일한 플랫폼**

#### 해결하고자 하는 문제 (Problem Statement)

```
"건강 데이터를 누구나 쉽게 이해하고,
환경을 자동으로 최적화하며,
필요할 때 언제든 물어볼 수 있는
24시간 AI 웰니스 코치를 제공한다"
```

**핵심 해결 방안:**
- **이해**: 복잡한 숫자 → 직관적인 설명 ("회복도 70%", "지금 몸이 피곤한 상태")
- **환경**: 조언만 제공 → 환경을 직접 최적화 (온도, 공기질, 조명 자동 조절)
- **대화**: 능동적 알림 최소화 → 물어볼 때만 답변하는 비강압적 소통
- **지속성**: 일시적 동기부여 → 24시간 자연스러운 동행

#### 핵심 내용 (4대 기능)

**1. 복잡한 건강 데이터를 쉽게 이해**

기존 웨어러블의 가장 큰 문제는 전문 용어와 숫자의 나열입니다.

```
기존 (웨어러블):
"HRV: 28ms"
"수면 효율: 73%"
"심박수: 65bpm"
→ 사용자: "이게 좋은 건가? 나쁜 건가?"

NAMU Coach:
"회복도: 70%"
"지금 몸이 피곤한 상태예요"
"충분한 휴식이 필요합니다"
→ 사용자: "아, 그래서 피곤했구나!"
```

**측정 데이터:**
- 생체: 심박수, HRV, 호흡수, 움직임, 체온(추정)
- 환경: CO2, VOC, PM2.5, 온도, 습도, 소음, 조도
- 통합 분석: "CO2가 높아서 집중력이 떨어지고 있어요"

**2. 환경 자동 최적화 (A1의 핵심 강점!)**

타 솔루션과의 가장 큰 차별점은 '조언'에서 끝나지 않고 '환경'을 직접 바꾼다는 것입니다.

```
일반 코치 앱:
"창문을 여세요" → 사용자가 해야 함 (안 함)
"온도를 낮추세요" → 귀찮음 (안 함)

NAMU Coach (A1):
[자동으로 환경 최적화]
• 공기질 자동 조절
• 온도 자동 조절
• 습도 자동 조절
• 조명 자동 조절

사용자가 할 일: 없음!
→ 환경이 알아서 바뀜
→ 자연스럽게 개선
```

**모드별 자동 환경 예시:**

집중 모드:
- CO2 < 800ppm 유지
- 온도 22°C (각성 최적)
- 조명 밝게
- 백색소음 (선택)

회복 모드:
- 공기질 청정
- 온도 20°C (이완)
- 습도 55-60%
- 조명 50%

수면 모드:
- 온도 18-20°C
- 습도 50-60%
- 조명 점진적 감소
- 백색소음/ASMR

**3. 대화형 코칭 (물어볼 때만)**

기존 건강 앱의 가장 큰 문제는 '알림 피로'입니다. 능동적 제안을 최소화하고 대화 중심으로 설계했습니다.

```
일반 건강 앱:
(알림) "오늘 운동하세요!" → 잔소리
(알림) "물 2L 마셔요!" → 부담
(알림) "일찍 주무세요!" → 스트레스

NAMU Coach:
기본: 조용함 (환경만 자동 최적화)

User: "오늘 컨디션 어때?"
A1: "회복도 85%로 좋은 편이에요"

User: "운동해도 돼?"
A1: "네, 중강도 40분 정도 좋아요"

User: "왜 피곤하지?"
A1: "어젯밤 수면 효율이 낮았어요"
    "중간에 3번 깨셨거든요"
```

**음성 대화 특징:**
- 자연스러운 대화 (명령어가 아닌 대화체)
- 맥락 이해 ("그래서 피곤했구나" → "네, 그래서예요")
- 감정 인식 및 공감 ("힘드시겠어요 😊")
- 격려 ("잘하고 계세요!")

**4. AI 개인화 학습**

2주간 사용자의 패턴을 학습하여 완전히 개인화된 코칭을 제공합니다.

```
학습 내용:
• 개인 기준선 (평소 HRV, 수면 패턴 등)
• 생활 패턴 (출근 시간, 운동 시간 등)
• 최적 환경 (선호 온도, 습도 등)
• 반응 패턴 (어떤 조언에 반응하는지)

적용 예시:
학습 결과: "평소 오후 3시에 에너지가 떨어지네요"
→ 오후 2시 50분에 미리 환경 조절

학습 결과: "월요일 아침이 특히 힘들어하시네요"
→ 월요일은 기상 환경을 더 부드럽게

학습 결과: "운동 후 30분 뒤 샤워하시네요"
→ 운동 후 자동으로 욕실 환경 준비
```

**나이대별 자동 맞춤:**
- 20-30대: 성과 최적화 (집중력, 회복 속도)
- 30-40대: 에너지 관리 (워라밸, 피로 관리)
- 40-50대: 체력 유지 (활력, 만성피로 예방)
- 50-60대+: 건강 관리 (안전, 질환 관리)

#### 독창성 (3가지)

**1. "환경까지 바꾸는" 유일한 웰니스 코치**

모든 경쟁 솔루션은 '조언'만 제공합니다. NAMU Coach는 유일하게 환경을 직접 변경합니다.

```
상황: 오후 집중력 저하
A1 분석: "CO2 1200ppm, 온도 25°C"

일반 솔루션:
"창문을 여세요" → 사용자가 해야 함 (안 함)

NAMU Coach:
[자동으로]
• 공기 청정 강화
• 온도 22°C로 조절
• 5분 후: "환경이 개선됐어요"
• 10분 후: "집중력이 회복됐나요?"

→ 웨어러블, 앱으로는 절대 불가능
→ A1의 하드웨어 없이는 불가능
```

**2. "강요하지 않는" 코치**

기존 건강 앱의 가장 큰 문제인 '알림 피로'를 해결했습니다.

```
기존 코치 앱:
매일 아침 8시: "오늘 운동 계획"
점심 12시: "물 마셨나요?"
오후 3시: "간식 자제하세요"
저녁 10시: "일찍 주무세요"
→ 부담스러움 → 알림 차단 → 앱 삭제

NAMU Coach:
기본: 조용함
• 환경만 자동 최적화
• 물어보면 답변
• 긴급 상황만 알림

User: "운동해도 돼?"
A1: "회복도 85%니까 괜찮아요"

→ 사용자 주도적
→ 부담 없음
→ 지속 가능
```

**3. "집 전체가 코칭 공간"**

웨어러블은 손목에만, 앱은 스마트폰에만 존재합니다. NAMU Coach는 집 전체를 따라다닙니다.

```
웨어러블: 손목 (착용 시만)
앱: 스마트폰 (앱 실행 시만)
스마트홈: 한 곳에 고정

NAMU Coach (A1):
아침: 침실 (기상 도움)
  → 온도, 조명 자동 조절
오전: 서재 (집중 환경)
  → 공기질, 집중력 관리
점심: 거실 (회복)
  → 낮잠 환경 세팅
저녁: 다시 침실 (수면 준비)
  → 수면 최적화

→ 자율주행으로 사용자 따라다님
→ 24시간 어디서든
→ 각 공간별 최적 환경 제공
```

#### 우수성 (A1 하드웨어 완벽 활용)

NAMU Coach는 A1의 모든 핵심 기술을 100% 활용하는 서비스입니다.

```
✅ 비접촉 생체 측정
   → 24시간 자연스러운 모니터링

✅ 환경 센서 + 제어
   → 측정을 넘어 환경 최적화

✅ 자율주행
   → 집 전체 공간별 맞춤 케어

✅ 음성 UI
   → 자연스러운 대화형 코칭

✅ 24시간 가동
   → 배터리 걱정 없는 지속적 케어

✅ 프리미엄 디자인
   → 거실에 두어도 거부감 없음

→ A1 없이는 구현 불가능한 서비스
→ A1의 킬러 앱(Killer App)
```

## 4. 안전 및 보안 확보 방안

### 1) 데이터 보안 기본 원칙 및 예방 방안

#### 원칙 1: Edge-First Processing (로컬 우선 처리)

**기본 원칙:**
사용자의 민감한 건강 데이터는 가능한 한 A1 디바이스 내부에서 처리하고, 클라우드 전송을 최소화합니다.

**구체적 실행:**

```
A1 디바이스 내부 처리 (Edge AI):
✅ 실시간 생체 신호 분석
✅ 정상/이상 범위 판단
✅ 환경 제어 결정
✅ 간단한 음성 명령 처리
✅ 긴급 상황 감지

클라우드 전송 (암호화 후 최소한만):
- 심층 분석이 필요한 경우만
- 집계된 데이터 (원본 아님)
- 익명화된 패턴 정보
```

**효과:**
- 네트워크 장애 시에도 기본 기능 동작
- 데이터 유출 리스크 최소화
- 실시간 응답 속도 향상
- 프라이버시 극대화

#### 원칙 2: 최소 수집 및 명확한 동의

**기본 원칙:**
서비스 제공에 필수적인 데이터만 수집하고, 모든 수집에 대해 명확한 동의를 받습니다.

**수집 데이터 분류:**

```
필수 데이터 (서비스 제공 불가피):
✅ 생체 신호 (익명 ID로 저장)
   - 심박수, HRV, 호흡수, 움직임
✅ 환경 데이터
   - CO2, 온습도, 공기질
✅ 기본 프로필
   - 나이대, 성별 (통계 목적)

선택 데이터 (명시적 동의 필요):
☐ 음성 녹음 (개인화 향상)
☐ 활동 영상 (안전 감지, 기본 OFF)
☐ 가족 공유
☐ 전문가 공유
☐ 연구 목적 사용 (완전 익명화)

절대 수집 안 함:
❌ 대화 내용 전체 녹음
❌ 상시 영상 촬영
❌ 위치 정보 (실내 방 정보만)
❌ 제3자 공유용 원본 데이터
```

**동의 관리:**
- 동의 항목별 개별 선택 가능
- 언제든 철회 가능 (앱에서 즉시)
- 철회 시 관련 데이터 30일 내 완전 삭제
- 삭제 증명서 발급

#### 원칙 3: 다층 암호화

**기본 원칙:**
전송 구간, 저장, 백업 등 모든 단계에서 암호화를 적용합니다.

**암호화 체계:**

```
1. 전송 구간 암호화:
   • TLS 1.3 (최신 표준)
   • Certificate Pinning (중간자 공격 방지)
   • E2E 암호화 (가족 간 공유 시)

2. 저장 암호화:
   • AES-256 (미국 정부 표준)
   • 데이터베이스 레벨 암호화
   • 백업 파일 암호화

3. 키 관리:
   • 디바이스별 고유 키
   • HSM(Hardware Security Module)에 저장
   • 90일 주기 키 로테이션
   • 키 분리 저장 (데이터와 별도)
```

#### 원칙 4: 접근 제어 및 감사

**기본 원칙:**
최소 권한 원칙을 적용하고, 모든 접근을 기록합니다.

**권한 체계:**

```
사용자 (User):
- 본인 데이터만 열람
- 가족 공유 설정
- 데이터 다운로드/삭제

가족 (Family):
- 승인된 데이터만
- 승인된 기간만
- 언제든 공유 해제 가능

전문가 (Professional):
- 공유된 데이터만
- 공유 기간 동안만
- 2단계 인증 필수
- 세션 타임아웃 15분

관리자 (Admin):
- 로그 조회만 가능
- 개인 데이터 접근 불가
- 모든 작업 감사 로그 기록
```

**2단계 인증 (2FA) 필수 작업:**
- 가족 구성원 추가
- 전문가와 데이터 공유
- 데이터 다운로드
- 계정 설정 변경
- 결제 정보 변경

#### 위협별 예방 및 대응
