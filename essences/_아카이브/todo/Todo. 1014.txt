## 📋 최종 기획/설계

### 정체성
**"AI가 건강 데이터로 전조 증상을 감지하고, 위험을 예방하며, 지속적인 건강 개선을 가이드하는 의료/헬스 코치"**

---

### 타겟
- 20-80대 계획적인 사람
- 스마트워치 착용자
- 특정 건강 이슈 보유 (편두통, 수면장애, 만성질환, 운동 부상 위험 등)

---

### 핵심 가치

**1차: 위험 예방 (안전)**
- 전조 증상 조기 감지
- 위험 상황 예측
- 사전 경고/조정 제안

**2차: 건강 개선 (성취)**
- 개선 패턴 추적
- 목표 기반 가이드
- 성취 기록/가시화

---

### 데이터 수집

**필수 (워치)**
- HRV (심박 변동성)
- 안정 심박수 (RHR)
- 수면 상세 (REM, 깊은/얕은, 무호흡)
- 활동량, 걸음
- 스트레스 지수

**선택 (추가)**
- 증상 로그 (두통, 어지러움 등)
- 복약 기록
- 식사 기록

**확장 (미래)**
- 구글 캘린더 (일정)
- 의료정보 하이패스 (처방 기록)

---

### 핵심 기능

**전조 감지**
- 개인 기준선 학습 (P10, P50, P90)
- 이상 패턴 감지 (HRV↓, 심박↑, 수면↓)
- 조합 패턴 분석 ("HRV↓ + 야간운동 → 편두통 위험")

**위험 예측**
- 편두통 발생 확률
- 저혈압 위험 신호
- 약물 충돌 경고 (캘린더 + 처방기록)
- 과부하 상태

**코칭**
- 경고: "내일 프리다이빙, 졸피뎀 위험"
- 조정: "오늘 강도 낮추세요"
- 목표: "HRV 개선 중, 3회 더 달성 시 안정화"

**성취 추적**
- 위험 회피 횟수
- 건강 지표 개선 (HRV 상승, 편두통 감소)
- 연속 안전 일수

**AI 채팅/음성**
- 실시간 상담
- 데이터 해석
- 조언 제공

**리포트 생성**
- 주간/월간 분석
- 의사 공유용 PDF
- 패턴 요약

```
    ↓              ↓

```

### 사용 시나리오

**케이스 1: 편두통 예방**
```
데이터: HRV 31.4 (낮음) + 고강도 운동
AI: "편두통 위험 높음"
경고: "내일 강도 낮추세요"
사용자: 따름
결과: 편두통 없음
성취: "위험 회피 +1"
```

**케이스 2: 약물 충돌**
```
캘린더: 내일 프리다이빙
처방기록: 졸피뎀 (중추신경계)
AI: "약물 위험 감지"
경고: "졸피뎀 복용 금지"
사용자: 따름
결과: 안전 다이빙
성취: "사고 예방 +1"
```

**케이스 3: 건강 개선**
```
30일 데이터 누적
AI: "HRV 35 → 45 (10 상승)"
성취: "건강 나이 5세 감소"
코칭: "이 패턴 유지하세요"
```

### 기술 구조

**Multi-Agent 시스템**
- 데이터 수집 Agent
- 분석 Agent (전조 감지, 패턴 학습)
- 코칭 Agent (경고, 가이드 생성)
- 대화 Agent (채팅/음성)
- 리포트 Agent

**AI 모델**
- LLM: Gemini Pro / GPT-4
- 시계열 분석: LSTM, Prophet
- 이상 탐지: Isolation Forest

**데이터 파이프라인**
- 실시간: 전조 감지, 긴급 경고
- 배치: 기준선 계산, 패턴 학습

---

### 차별점
- vs 추적 앱: AI 예측
- vs 헬스 코치: 의료 데이터 통합
- vs 의료 앱: 성취감/동기부여
- vs 재욱 편두통 분석: 제품화

---

### MVP 범위
1. 워치 데이터 수집
2. 기준선 학습
3. 전조 감지 (HRV, 심박, 수면)
4. 간단한 경고
5. 개선 추적
6. AI 채팅

### 확장
7. 캘린더 연동
8. 의료정보 하이패스 (처방기록)
9. 고급 예측 모델
10. 리포트 PDF
