# 상태관리

← [문서 네비게이션](../00-시작/00-시작하기.md)

전역 상태는 Zustand로 관리한다. Feature별로 독립적인 Store를 만든다.

## Store 구조

각 feature가 자신의 store를 가진다. fileSystemStore, editorGroupStore, tabStore, layoutStore가 있다.

```
src/
├── features/
│   ├── file-explorer/
│   │   └── store/
│   │       └── fileSystemStore.ts    # 파일 탐색 상태
│   └── editor-groups/
│       └── store/
│           ├── editorGroupStore.ts   # 에디터 그룹
│           └── tabStore.ts           # 탭 관리
└── app/
    └── layout/
        └── store/
            └── layoutStore.ts        # 레이아웃 상태
```

## Zustand 기본 사용법

### Store 생성

```typescript
// src/features/file-explorer/store/fileSystemStore.ts
import { create } from 'zustand';

interface FileNode {
  path: string;
  name: string;
  type: 'file' | 'directory';
  children?: FileNode[];
}

interface FileSystemStore {
  // 상태
  tree: FileNode[];
  expandedFolders: Set<string>;
  selectedFile: string | null;

  // 액션
  setTree: (tree: FileNode[]) => void;
  toggleFolder: (path: string) => void;
  selectFile: (path: string) => void;
}

export const useFileSystemStore = create<FileSystemStore>((set) => ({
  tree: [],
  expandedFolders: new Set(),
  selectedFile: null,

  setTree: (tree) => set({ tree }),

  toggleFolder: (path) =>
    set((state) => {
      const newExpanded = new Set(state.expandedFolders);
      if (newExpanded.has(path)) {
        newExpanded.delete(path);
      } else {
        newExpanded.add(path);
      }
      return { expandedFolders: newExpanded };
    }),

  selectFile: (path) => set({ selectedFile: path })
}));
```

### 컴포넌트에서 사용

```typescript
// src/features/file-explorer/components/FileTree.tsx
import { useFileSystemStore } from '../store/fileSystemStore';

export function FileTree() {
  // 필요한 상태만 선택 (최적화)
  const tree = useFileSystemStore((state) => state.tree);
  const toggleFolder = useFileSystemStore((state) => state.toggleFolder);

  return (
    <div>
      {tree.map((node) => (
        <FileItem
          key={node.path}
          node={node}
          onToggle={toggleFolder}
        />
      ))}
    </div>
  );
}
```

## 주요 Store 설명

### 1. Layout Store

전체 레이아웃 상태를 관리한다. 사이드바와 패널의 표시 여부, 크기를 제어한다.

```typescript
// src/app/layout/store/layoutStore.ts
interface LayoutStore {
  sidebarOpen: boolean;
  sidebarWidth: number;
  statusBarVisible: boolean;

  toggleSidebar: () => void;
  setSidebarWidth: (width: number) => void;
  toggleStatusBar: () => void;
}

export const useLayoutStore = create<LayoutStore>((set) => ({
  sidebarOpen: true,
  sidebarWidth: 240,
  statusBarVisible: true,

  toggleSidebar: () =>
    set((state) => ({ sidebarOpen: !state.sidebarOpen })),

  setSidebarWidth: (width) => set({ sidebarWidth: width }),

  toggleStatusBar: () =>
    set((state) => ({ statusBarVisible: !state.statusBarVisible }))
}));
```

### 2. Editor Group Store

에디터 그룹과 탭을 관리한다. 여러 탭을 그룹으로 묶고, 각 그룹의 활성 탭을 추적한다.

```typescript
// src/features/editor-groups/store/editorGroupStore.ts
interface Tab {
  id: string;
  filePath: string;
  content: string;
  isDirty: boolean;
}

interface EditorGroup {
  id: string;
  tabs: Tab[];
  activeTabId: string | null;
}

interface EditorGroupStore {
  groups: EditorGroup[];
  activeGroupId: string;

  addTab: (groupId: string, filePath: string, content: string) => void;
  removeTab: (groupId: string, tabId: string) => void;
  setActiveTab: (groupId: string, tabId: string) => void;
  updateTabContent: (groupId: string, tabId: string, content: string) => void;
}

export const useEditorGroupStore = create<EditorGroupStore>((set) => ({
  groups: [
    {
      id: 'default',
      tabs: [],
      activeTabId: null
    }
  ],
  activeGroupId: 'default',

  addTab: (groupId, filePath, content) =>
    set((state) => ({
      groups: state.groups.map((group) =>
        group.id === groupId
          ? {
              ...group,
              tabs: [
                ...group.tabs,
                {
                  id: crypto.randomUUID(),
                  filePath,
                  content,
                  isDirty: false
                }
              ]
            }
          : group
      )
    })),

  removeTab: (groupId, tabId) =>
    set((state) => ({
      groups: state.groups.map((group) =>
        group.id === groupId
          ? {
              ...group,
              tabs: group.tabs.filter((tab) => tab.id !== tabId)
            }
          : group
      )
    })),

  setActiveTab: (groupId, tabId) =>
    set((state) => ({
      groups: state.groups.map((group) =>
        group.id === groupId
          ? { ...group, activeTabId: tabId }
          : group
      )
    })),

  updateTabContent: (groupId, tabId, content) =>
    set((state) => ({
      groups: state.groups.map((group) =>
        group.id === groupId
          ? {
              ...group,
              tabs: group.tabs.map((tab) =>
                tab.id === tabId
                  ? { ...tab, content, isDirty: true }
                  : tab
              )
            }
          : group
      )
    }))
}));
```

### 3. File System Store

파일 탐색기 상태를 관리한다. 파일 트리, 확장된 폴더 목록, 선택된 파일을 추적한다.

```typescript
interface FileSystemStore {
  tree: FileNode[];
  expandedFolders: Set<string>;
  selectedFile: string | null;
  loading: boolean;

  loadTree: () => Promise<void>;
  toggleFolder: (path: string) => void;
  selectFile: (path: string) => void;
}

export const useFileSystemStore = create<FileSystemStore>((set, get) => ({
  tree: [],
  expandedFolders: new Set(),
  selectedFile: null,
  loading: false,

  loadTree: async () => {
    set({ loading: true });

    try {
      // IPC 호출
      const tree = await window.electron.listDirectory('/');
      set({ tree, loading: false });
    } catch (error) {
      console.error('Failed to load tree:', error);
      set({ loading: false });
    }
  },

  toggleFolder: (path) => {
    const { expandedFolders } = get();
    const newExpanded = new Set(expandedFolders);

    if (newExpanded.has(path)) {
      newExpanded.delete(path);
    } else {
      newExpanded.add(path);
    }

    set({ expandedFolders: newExpanded });
  },

  selectFile: (path) => set({ selectedFile: path })
}));
```

## IPC와 상태 동기화

### 파일 열기 플로우

```typescript
// src/app/views/Explorer.tsx
export function Explorer() {
  const selectFile = useFileSystemStore((state) => state.selectFile);
  const addTab = useEditorGroupStore((state) => state.addTab);

  const handleFileClick = async (path: string) => {
    // 1. File System Store 업데이트
    selectFile(path);

    // 2. IPC로 파일 읽기
    const content = await window.electron.readFile(path);

    // 3. Editor Group Store에 탭 추가
    addTab('default', path, content);
  };

  return <FileTree onFileClick={handleFileClick} />;
}
```

### 자동 저장

```typescript
// src/features/editor-groups/hooks/useAutoSave.ts
export function useAutoSave(groupId: string, tabId: string) {
  const tab = useEditorGroupStore((state) =>
    state.groups
      .find((g) => g.id === groupId)
      ?.tabs.find((t) => t.id === tabId)
  );

  useEffect(() => {
    if (!tab?.isDirty) return;

    const timer = setTimeout(async () => {
      await window.electron.writeFile(tab.filePath, tab.content);
      // isDirty false로 변경
    }, 2000);

    return () => clearTimeout(timer);
  }, [tab?.content]);
}
```

### Feature Store

```typescript
// src/features/drag-drop/store/dragDropStore.ts
// ✅ 프로덕션, 테스트 필수, 타입 완벽
export const useDragDropStore = create<DragDropStore>()((set) => ({
  draggedItem: null,

  setDraggedItem: (item) => {
    // Validation
    if (!item || !item.id) {
      throw new Error('Invalid item');
    }
    set({ draggedItem: item });
  }
}));
```

## 최적화 패턴

### Selector 최적화

```typescript
// ❌ Bad: 전체 상태 구독 (불필요한 리렌더)
const store = useEditorGroupStore();
const activeTab = store.groups[0].tabs.find(t => t.id === store.groups[0].activeTabId);

// ✅ Good: 필요한 부분만 선택
const activeTab = useEditorGroupStore((state) => {
  const group = state.groups.find((g) => g.id === state.activeGroupId);
  return group?.tabs.find((t) => t.id === group.activeTabId);
});
```

### Shallow 비교

```typescript
import { shallow } from 'zustand/shallow';

// 객체 구조 비교
const { sidebarOpen, sidebarWidth } = useLayoutStore(
  (state) => ({
    sidebarOpen: state.sidebarOpen,
    sidebarWidth: state.sidebarWidth
  }),
  shallow
);
```

### Immer 미들웨어

```typescript
import { immer } from 'zustand/middleware/immer';

export const useEditorGroupStore = create<EditorGroupStore>()(
  immer((set) => ({
    groups: [],

    updateTabContent: (groupId, tabId, content) =>
      set((state) => {
        // Immer로 불변성 자동 처리
        const group = state.groups.find((g) => g.id === groupId);
        const tab = group?.tabs.find((t) => t.id === tabId);
        if (tab) {
          tab.content = content;
          tab.isDirty = true;
        }
      })
  }))
);
```
