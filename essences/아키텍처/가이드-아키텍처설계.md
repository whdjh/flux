## Electron 프로세스 아키텍처

### Multi-Process Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Main Process                            │
│                     (Node.js Runtime)                        │
│  ┌────────────────────────────────────────────────────────┐│
│  │  • Window Management                                   ││
│  │  • IPC Event Handling                                  ││
│  │  • File System Access                                  ││
│  │  • Native APIs                                         ││
│  │  • Database Connection                                 ││
│  │  • App Lifecycle                                       ││
│  └────────────────────────────────────────────────────────┘│
└──────────────────┬──────────────────┬───────────────────────┘
                   │                  │
                   │  IPC Channel     │
                   │                  │
┌──────────────────▼──────────────────▼───────────────────────┐
│                    Preload Script                            │
│                   (Isolated Bridge)                          │
│  ┌────────────────────────────────────────────────────────┐│
│  │  contextBridge.exposeInMainWorld('electronAPI', {      ││
│  │    file: { read, write, delete },                      ││
│  │    db: { query, insert, update },                      ││
│  │    app: { getVersion, quit }                           ││
│  │  })                                                     ││
│  └────────────────────────────────────────────────────────┘│
└──────────────────────────────┬───────────────────────────────┘
                               │
                               │ Exposed API
                               │
┌──────────────────────────────▼───────────────────────────────┐
│                   Renderer Process                           │
│                  (Chromium Runtime)                          │
│  ┌────────────────────────────────────────────────────────┐│
│  │  React Application                                     ││
│  │  ├─ Components (UI)                                    ││
│  │  ├─ State Management (Zustand)                         ││
│  │  ├─ Routing (React Router)                             ││
│  │  ├─ Monaco Editor                                      ││
│  │  └─ Radix UI Components                                ││
│  └────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

### Process Communication Flow

```
User Action (Renderer)
       ↓
window.electronAPI.file.read(path)
       ↓
Preload Script (contextBridge)
       ↓
IPC Channel (ipcMain.handle)
       ↓
Main Process Handler
       ↓
File System Access (Node.js fs)
       ↓
Result → IPC Response
       ↓
Preload Script
       ↓
Renderer Process (Promise resolves)
       ↓
UI Update (React)
```

##  보안 아키텍처

### 3-Layer Defense System

```
┌─────────────────────────────────────────────────────────────┐
│                      Layer 1: Isolation                      │
│  ┌────────────────────────────────────────────────────────┐│
│  │  Context Isolation: Enabled                            ││
│  │  Node Integration: Disabled in Renderer                ││
│  │  Sandbox: Enabled                                      ││
│  │  → Renderer는 Node.js API에 직접 접근 불가              ││
│  └────────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────────┤
│                    Layer 2: Validation                       │
│  ┌────────────────────────────────────────────────────────┐│
│  │  Zod Schema Validation                                 ││
│  │  ├─ IPC Message Validation                             ││
│  │  ├─ File Path Validation                               ││
│  │  └─ User Input Sanitization                            ││
│  │                                                         ││
│  │  // Example                                             ││
│  │  const FilePathSchema = z.object({                     ││
│  │    path: z.string().refine(isSecurePath),             ││
│  │    mode: z.enum(['read', 'write'])                     ││
│  │  })                                                     ││
│  └────────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────────┤
│                   Layer 3: Restrictions                      │
│  ┌────────────────────────────────────────────────────────┐│
│  │  Content Security Policy (CSP)                         ││
│  │  ├─ script-src 'self'                                  ││
│  │  ├─ style-src 'self' 'unsafe-inline'                   ││
│  │  └─ img-src 'self' data:                               ││
│  │                                                         ││
│  │  Permissions                                            ││
│  │  ├─ webSecurity: true                                  ││
│  │  ├─ allowRunningInsecureContent: false                 ││
│  │  └─ experimentalFeatures: false                        ││
│  └────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

### IPC Security Pattern

```typescript
//  Bad: Direct Node.js access
// Renderer에서 직접 파일 접근 (위험)
const fs = require('fs')
fs.writeFileSync('/etc/passwd', 'hacked')

//  Good: Secure IPC with Validation
// 1. Renderer: 안전한 API 호출
const result = await window.electronAPI.file.write({
  path: './document.txt',
  content: 'Hello'
})

// 2. Preload: contextBridge로 격리
contextBridge.exposeInMainWorld('electronAPI', {
  file: {
    write: (data) => ipcRenderer.invoke('file:write', data)
  }
})

// 3. Main: Zod 검증 + 권한 체크
ipcMain.handle('file:write', async (event, data) => {
  // Zod validation
  const validated = FileWriteSchema.parse(data)

  // Path sanitization
  if (!isSecurePath(validated.path)) {
    throw new Error('Invalid path')
  }

  // File operation
  return await fs.promises.writeFile(validated.path, validated.content)
})
```

  // 200ms cubic-bezier animation
  animateOpen(tab) {

    tab.style.opacity = '0'

      tab.style.opacity = '1'

## 📈 확장성 고려사항

### 플러그인 아키텍처 (예정)

```typescript
interface Plugin {
  id: string
  name: string
  version: string

  // Lifecycle hooks
  activate(context: ExtensionContext): void
  deactivate(): void

  // Contribution points
  contributes: {
    commands?: Command[]
    views?: View[]
    languages?: Language[]
  }
}

// 플러그인 로더
class PluginManager {
  private plugins: Map<string, Plugin> = new Map()

  async load(pluginPath: string) {
    const plugin = await import(pluginPath)
    this.plugins.set(plugin.id, plugin)
    plugin.activate(this.context)
  }

  unload(pluginId: string) {
    const plugin = this.plugins.get(pluginId)
    plugin?.deactivate()
    this.plugins.delete(pluginId)
  }
}
```

export function useAuth() {
  const signIn = async (credentials) => {
    try {
      const user = await authService.signIn(
        credentials.email,
        credentials.password
      )
      // Update global state
      authStore.setUser(user)
    } catch (error) {
      // Handle error
      toast.error('Login failed')
    }
  }

  return { signIn, ... }
}
