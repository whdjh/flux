# 데이터베이스

DB 스택은 Drizzle ORM, Supabase, PostgreSQL이다. Main 프로세스에서 Drizzle로 접근하고, Renderer는 Supabase Client를 사용한다.

## 빠른 시작

세 단계로 시작한다. 환경변수를 설정하고, 스키마를 DB에 동기화하고, Drizzle Studio로 확인한다.

```bash
# 1. 환경변수 설정
cp .env.example .env

# 2. 스키마 → DB 동기화
npm run db:push

# 3. Drizzle Studio (DB GUI)
npm run db:studio
```

## 환경변수 설정

DATABASE_URL은 Main 프로세스용이고, VITE_SUPABASE_*는 Renderer용이다.

### `.env` 파일

DATABASE_URL은 Drizzle이 사용한다. VITE_ 접두사가 붙은 변수는 Renderer에 노출된다.

```bash
# Supabase 프로젝트 정보
DATABASE_URL="postgresql://postgres:[PASSWORD]@db.[PROJECT_ID].supabase.co:5432/postgres"

# Renderer에서 사용 (Vite에서 노출)
VITE_SUPABASE_URL="https://[PROJECT_ID].supabase.co"
VITE_SUPABASE_ANON_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### Supabase 프로젝트 생성

Supabase 대시보드에서 프로젝트를 만든다. Connection String과 API Key를 복사해서 .env에 붙여넣는다.

1. https://supabase.com 접속
2. New Project 생성
3. Project Settings → Database
4. Connection String (URI) 복사
5. `.env`에 `DATABASE_URL` 설정
6. API Settings → Project URL, anon public key 복사
7. `.env`에 `VITE_SUPABASE_*` 설정

## Drizzle ORM 설정

### 스키마 정의

**파일**: `src/backend/infrastructure/db/schema.ts`

```typescript
import { pgTable, uuid, text, timestamp } from 'drizzle-orm/pg-core';

export const files = pgTable('files', {
  id: uuid('id').primaryKey().defaultRandom(),
  path: text('path').notNull().unique(),
  content: text('content'),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow()
});

export const bookmarks = pgTable('bookmarks', {
  id: uuid('id').primaryKey().defaultRandom(),
  filePath: text('file_path').notNull(),
  title: text('title'),
  createdAt: timestamp('created_at').defaultNow()
});
```

### DB 클라이언트

**파일**: `src/backend/infrastructure/db/client.ts`

```typescript
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import * as schema from './schema';

const connectionString = process.env.DATABASE_URL!;

const client = postgres(connectionString);
export const db = drizzle(client, { schema });
```

### 설정 파일

**파일**: `drizzle.config.ts`

```typescript
import type { Config } from 'drizzle-kit';

export default {
  schema: './src/backend/infrastructure/db/schema.ts',
  out: './drizzle',
  driver: 'pg',
  dbCredentials: {
    connectionString: process.env.DATABASE_URL!
  }
} satisfies Config;
```

## CRUD 작업

### Create

```typescript
// Repository Layer
import { db } from '../db/client';
import { files } from '../db/schema';

export async function createFile(path: string, content: string) {
  const [file] = await db
    .insert(files)
    .values({ path, content })
    .returning();

  return file;
}
```

### Read

```typescript
import { eq } from 'drizzle-orm';

// 단일 조회
export async function getFileByPath(path: string) {
  const [file] = await db
    .select()
    .from(files)
    .where(eq(files.path, path));

  return file;
}

// 전체 조회
export async function getAllFiles() {
  return await db
    .select()
    .from(files)
    .orderBy(files.createdAt);
}
```

### Update

```typescript
export async function updateFile(path: string, content: string) {
  const [updated] = await db
    .update(files)
    .set({
      content,
      updatedAt: new Date()
    })
    .where(eq(files.path, path))
    .returning();

  return updated;
}
```

### Delete

```typescript
export async function deleteFile(path: string) {
  await db
    .delete(files)
    .where(eq(files.path, path));
}
```

## 고급 쿼리

### Join

```typescript
import { bookmarks, files } from '../db/schema';

export async function getBookmarksWithFiles() {
  return await db
    .select({
      bookmark: bookmarks,
      file: files
    })
    .from(bookmarks)
    .leftJoin(files, eq(bookmarks.filePath, files.path));
}
```

### 트랜잭션

```typescript
export async function moveFile(oldPath: string, newPath: string) {
  await db.transaction(async (tx) => {
    // 1. 새 경로로 복사
    const [file] = await tx
      .select()
      .from(files)
      .where(eq(files.path, oldPath));

    await tx
      .insert(files)
      .values({ ...file, path: newPath });

    // 2. 기존 파일 삭제
    await tx
      .delete(files)
      .where(eq(files.path, oldPath));
  });
}
```

### 필터링 & 정렬

```typescript
import { like, desc } from 'drizzle-orm';

export async function searchFiles(query: string) {
  return await db
    .select()
    .from(files)
    .where(like(files.path, `%${query}%`))
    .orderBy(desc(files.updatedAt))
    .limit(10);
}
```

```typescript
  findByPath(path: string): Promise<File | null>;

  async findByPath(path: string): Promise<File | null> {
    const row = await db
      .select()
      .from(files)
      .where(eq(files.path, path))
      .limit(1);

    return row ? this.toDomain(row) : null;

      .insert(files)

      });
```

## 에러 처리

```typescript
export async function safeGetFile(path: string) {
  try {
    const file = await getFileByPath(path);
    return { success: true, data: file };
  } catch (error) {
    console.error('DB Error:', error);
    return {
      success: false,
      error: error instanceof Error ? error.message : 'Unknown error'
    };
  }
}
```
