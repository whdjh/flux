# 클론 코딩 체크리스트

Chrome 탭 시스템의 완벽한 클론 코딩을 검증하기 위한 체크리스트.

## 사용법

구현 완료 후 이 체크리스트의 모든 항목을 확인한다. 하나라도 실패하면 클론 코딩이 완벽하지 않다.

**검증 방법**:
- [코드]: 코드 리뷰로 확인
- [시각]: Chrome과 나란히 놓고 육안 비교
- [측정]: DevTools Performance로 타이밍 측정
- [테스트]: 실제 사용해서 동작 확인

## 애니메이션 타이밍

### 드래그 애니메이션
- [ ] [코드] `kDragAnimationMs = 167` 상수 정의됨
- [ ] [측정] 드래그 중 탭 이동 애니메이션 167ms
- [ ] [시각] Chrome과 동일한 속도감

### 탭 추가 애니메이션
- [ ] [코드] `kTabAnimationDurationMs = 200` 상수 정의됨
- [ ] [측정] 탭 추가 애니메이션 200ms
- [ ] [시각] Chrome과 동일하게 부드럽게 나타남
- [ ] [시각] **간격 없이** 즉시 붙어서 나타남

### 탭 닫기 애니메이션
- [ ] [코드] `kCloseAnimationMs = 200` 상수 정의됨
- [ ] [측정] 탭 닫기 애니메이션 200ms
- [ ] [시각] Chrome과 동일하게 부드럽게 사라짐

## Easing 함수

- [ ] [코드] `kEaseOut = 'cubic-bezier(0, 0, 0.2, 1)'` 정의됨
- [ ] [코드] 모든 애니메이션에 `kEaseOut` 사용
- [ ] [시각] Chrome과 동일한 가속/감속 느낌

## 애니메이션 방식

### Opacity
- [ ] [코드] `animateTabAdd()`에서 opacity 키프레임 **없음**
- [ ] [코드] `animateTabClose()`에서 opacity 키프레임 **없음**
- [ ] [코드] CSS `.chrome-tab:not([data-animated])`에서 opacity **없음**
- [ ] [시각] 탭 추가 시 간격 생기지 않음

### Width/Flex 애니메이션
- [ ] [코드] `flexGrow: 0 → 1` 애니메이션 사용
- [ ] [코드] `flexBasis: '0px' → 'auto'` 애니메이션 사용
- [ ] [코드] `minWidth: '0px' → '36px'` 애니메이션 사용
- [ ] [시각] 탭 너비가 가변적으로 조정됨

### CSS 초기 상태
- [ ] [코드] `.chrome-tab:not([data-animated])`에 `width: 0 !important`
- [ ] [코드] `.chrome-tab:not([data-animated])`에 `min-width: 0 !important`
- [ ] [코드] `.chrome-tab:not([data-animated])`에 `max-width: 0 !important`
- [ ] [코드] `.chrome-tab:not([data-animated])`에 `overflow: hidden`

## 드래그앤드롭 알고리즘

### Drop Index 계산
- [ ] [코드] 탭 중심점 기반 계산 (`rect.left + rect.width / 2`)
- [ ] [코드] 마우스 X가 탭 중심보다 작으면 그 위치에 드롭
- [ ] [테스트] 탭 중심 기준으로 정확하게 드롭됨

### Index 조정
- [ ] [코드] `if (calculatedIndex > draggedIndex) calculatedIndex -= 1` 로직 있음
- [ ] [테스트] 오른쪽으로 드래그 시 올바른 위치에 드롭
- [ ] [테스트] 왼쪽으로 드래그 시 올바른 위치에 드롭
- [ ] [테스트] 같은 위치에 드롭 시 변화 없음

### Real-time Shifting
- [ ] [코드] `animateTabShift()` 메서드 구현됨
- [ ] [코드] 드래그 중 다른 탭들이 167ms로 이동
- [ ] [코드] `getTabShift()` 로직으로 이동량 계산
- [ ] [시각] 드래그 중 다른 탭들이 실시간으로 공간 확보
- [ ] [시각] Chrome과 동일한 shifting 느낌

## 드래그 스타일

- [ ] [코드] 드래그 중 `opacity: 0.75` 적용
- [ ] [코드] CSS `.chrome-tab[draggable="true"]:active { opacity: 0.75 !important }`
- [ ] [시각] 드래그 중인 탭이 반투명해짐

## 탭 너비 관리

- [ ] [코드] `.chrome-tab { flex: 1 }` 설정
- [ ] [코드] `min-width: 36px` 최소 너비
- [ ] [코드] `max-width: 240px` 최대 너비
- [ ] [시각] 탭이 공간을 균등하게 나눠가짐
- [ ] [테스트] 탭 많을 때 최소 너비 유지
- [ ] [테스트] 탭 적을 때 최대 너비 제한

## Web Animations API

- [ ] [코드] `element.animate()` 사용
- [ ] [코드] CSS transition/keyframes 사용 안 함
- [ ] [코드] `fill: 'none'` (탭 추가) 또는 `fill: 'forwards'` (탭 닫기)
- [ ] [코드] `onfinish` 콜백에서 animation cleanup
