# VSCode Tabs CSS 테스트 가이드

**목적**: Phase 8에서 구현한 CSS 기능들이 브라우저에서 올바르게 작동하는지 검증

## 테스트 실행 방법

### 1. 앱 시작
```bash
npm start
```

### 2. 데모 페이지 접속
브라우저에서 `/demos` 또는 `/demos/vscode-tabs` 접속

## 테스트 체크리스트

### ✅ Phase 8 구현 사항 검증

#### 1. position: sticky 테스트

**테스트 방법**:
1. 10개 이상의 탭 생성 (가로 스크롤이 생기도록)
2. 첫 번째 탭을 Sticky 상태로 설정 (Pin 버튼 클릭)
3. 탭 목록을 오른쪽으로 스크롤

**예상 동작**:
- ✅ Sticky 탭이 왼쪽에 고정되어 스크롤 시에도 보임
- ✅ 다른 탭들은 왼쪽으로 사라짐
- ✅ Sticky 탭 배경색: #e3f2fd (하늘색)
- ✅ Sticky 탭 왼쪽 테두리: 2px solid #2196f3 (파란색)

**버그 체크**:
- ❌ Sticky 탭이 스크롤 시 사라짐 → `position: sticky` 미작동
- ❌ Sticky 탭이 다른 탭 위로 올라오지 않음 → z-index 문제

---

#### 2. z-index hierarchy 테스트

**테스트 방법**:
1. 여러 탭 생성
2. 탭을 드래그앤드롭으로 순서 변경
3. Active 탭과 일반 탭 비교

**예상 동작**:
- ✅ 드래그 중인 탭이 다른 탭 위에 떠 있음 (z-index: 11)
- ✅ Active 탭의 파란색 테두리가 다른 탭 위에 보임 (z-index: 10)
- ✅ Active 탭의 상단 파란색 선이 보임 (z-index: 6)
- ✅ 일반 탭은 뒤에 있음 (z-index: 0)

**버그 체크**:
- ❌ 드래그 중인 탭이 다른 탭 뒤로 사라짐 → z-index 문제
- ❌ Active 탭 테두리가 다른 요소에 가려짐 → z-index 문제

---

#### 3. Tab label gradient fade 테스트

**테스트 방법**:
1. 긴 파일명을 가진 탭 생성 (예: "VeryLongFileNameThatExceedsTabWidth.tsx")
2. 탭 너비를 조절하여 파일명이 overflow되도록 함

**예상 동작**:
- ✅ 탭 라벨 오른쪽 끝에 5px 그라디언트 fade 보임
- ✅ Inactive 탭: 회색(#f3f3f3)으로 fade
- ✅ Active 탭: 흰색(#ffffff)으로 fade
- ✅ 탭에 focus 시 gradient 사라짐 (opacity: 0)

**버그 체크**:
- ❌ Gradient가 보이지 않음 → ::after 미작동
- ❌ Gradient 색상이 배경과 안 맞음 → CSS 변수 문제

---

### ✅ 기존 기능 회귀 테스트

#### 4. 탭 드래그앤드롭

**테스트 방법**:
1. 탭을 드래그하여 다른 위치로 이동
2. Drop target indicator 확인

**예상 동작**:
- ✅ 드래그 중 탭 opacity: 0.5
- ✅ Drop 가능한 위치에 2px 파란색 선 표시
- ✅ Drop 후 탭 순서 변경

---

#### 5. 탭 선택 (Ctrl/Shift Click)

**테스트 방법**:
1. Ctrl+Click으로 여러 탭 선택
2. Shift+Click으로 범위 선택

**예상 동작**:
- ✅ 선택된 탭 배경: rgba(0, 120, 212, 0.1)
- ✅ 선택된 탭 테두리: 1px solid #007acc

---

#### 6. Close Button

**테스트 방법**:
1. 탭에 마우스 hover
2. Active 탭 확인
3. Close 버튼 클릭

**예상 동작**:
- ✅ Hover 시 close 버튼 opacity: 0 → 1
- ✅ Active 탭은 항상 close 버튼 표시
- ✅ Close 버튼 hover 시 배경색 변경

---

## 버그 발견 시 대응

### CSS 문제
1. 브라우저 개발자 도구 열기 (F12)
2. Elements 탭에서 해당 요소 검사
3. Computed 탭에서 실제 적용된 CSS 확인
4. CSS 파일 수정 필요 시 보고

### z-index 문제
- Computed 탭에서 z-index 값 확인
- Stacking context 문제 확인 (position, opacity, transform 등)

### position: sticky 문제
- 부모 요소의 `overflow` 속성 확인 (`overflow: hidden`이면 sticky 안 됨)
- Computed 탭에서 `position: sticky` 적용 여부 확인
