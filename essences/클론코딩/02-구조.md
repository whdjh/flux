# 구조

## 폴더 구조

프로젝트는 Electron + Remix 기반이다. src는 main, preload, app, backend로 나뉜다.

```
electron-boilerplate/
├── src/
│   ├── main.ts              # Electron 메인 프로세스
│   ├── preload.ts           # IPC 브리지
│   ├── renderer.tsx         # React 엔트리
│   ├── app/                 # Presentation Layer
│   │   ├── layout/          # 3-panel, 탭, 분할 시스템
│   │   ├── views/           # 18개 페이지 컴포넌트
│   │   └── integrations/    # AI, Search, Editor 통합
│   ├── backend/             # Application + Data Layer
│   │   ├── domain/          # 비즈니스 로직
│   │   ├── infrastructure/  # Supabase, Elasticsearch
│   │   └── interfaces/      # IPC 핸들러
│   ├── features/            # 도메인별 기능
│   │   ├── file-explorer/
│   │   └── tab-system/
│   ├── shared/              # 공통 유틸리티
│   │   ├── components/      # Shadcn/UI 기반
│   │   ├── ipc/             # 타입 안전 IPC
│   │   └── types/           # 공통 타입
│   └── demos/               # 데모 페이지 (개발용)
├── docs/                    # 문서
│   ├── 00-시작/
│   ├── 01-워크플로우/
│   ├── 02-아키텍처/
│   ├── 03-참고자료/
│   └── 리서치도구/
└── public/                  # 정적 자산
```

## 레이아웃 구조

애플리케이션은 3-panel 레이아웃을 따른다. 좌측 사이드바 336px, 메인 콘텐츠 영역, 우측 패널 336px로 구성된다. 상단에는 타이틀바 56px와 탭바 34px가 있다.

좌측 사이드바는 Inbox, Projects, Tags, Views, Favorites 섹션으로 나뉜다. 리사이즈 핸들 8px로 조절할 수 있고 최소 240px, 최대 360px다. 접힘 너비는 64px로 아이콘 모드를 유지한다.

메인 콘텐츠 영역은 상단 바 52px에 필터, 정렬, 검색 기능을 둔다. 내부 패딩은 16~24px다. 콘텐츠는 List, Grid, Masonry, Justified 네 가지 뷰를 지원한다.

우측 패널은 폭 336px로 메모나 AI 어시스턴트를 표시한다. 1280px 미만 폭에서는 자동으로 오버레이 모드로 전환된다. 분할은 1/2, 1/3, 1/4 프리셋을 제공한다.

## 페이지 구조

18개 페이지는 M0, M1, M2로 우선순위를 나눈다.

M0 (10개):
- 00_App Shell: 공통 프레임 (타이틀바, 탭바, 사이드바, 테마)
- 01_Inbox: 수집 아이템 피드 (검색, 정렬, 필터, 4가지 뷰)
- 02_Project: 프로젝트 폴더 뷰 (헤더, 퀵 액션, 그리드/리스트)
- 03_Detail: 아이템 상세 (미디어/메타 탭, 편집, 자동저장)
- 04_Editor: 메모 에디터 (Monaco 기반, 슬래시 커맨드, 버전 히스토리)
- 05_Search: 검색 페이지 (의미검색, 하이라이트, 필터)
- 08_Settings: 설정 (계정, 데이터, UI, 단축키)
- 09_Layout: 탭/분할 매니저 (새 탭, 고정, 프리셋)
- 10_Capture: 수집 플로우 (Alt+우클릭, 드롭존, 피드백)
- 15_Onboarding: 온보딩/로그인 (회원가입, 테마 설정)

M1 (5개):
- 06_AI: AI 어시스턴트 (채팅, 스트리밍, 모델 선택)
- 12_Export: 내보내기 (PDF/Markdown, 범위, 스타일)
- 13_Tags: 태그 매니저 (색상, 병합, 일괄 적용)
- 14_Trash: 휴지통 (복구, 영구삭제, 남은일수)
- 17_Viewer: 미디어 뷰어 (줌/팬, 재생, 전체화면)

M2 (3개):
- 07_Sticky: 스티커 메모 (독립 창, 맨앞 고정, 빠른 생성)
- 11_Collab: 협업/공유 (라이브 커서, 댓글, 권한)
- 16_Voice: 보이스 (마이크, TTS 재생)

## 라우팅

라우팅은 Remix 기반이다. 최상위 내비와 딥링크를 정의한다.

```
/inbox                    01_Inbox
/projects                 02_Project 목록
/projects/:folderId       02_Project 상세
/detail/:itemId           03_Detail 모달
/notes/:noteId            04_Editor
/search                   05_Search
/ai                       06_AI
/sticky                   07_Sticky
/settings                 08_Settings
/layout                   09_Layout
/capture                  10_Capture
/collab                   11_Collab
/export                   12_Export
/tags                     13_Tags
/trash                    14_Trash
/onboarding               15_Onboarding
/voice                    16_Voice
/viewer                   17_Viewer
```

사이드 패널 상세는 쿼리로 처리한다. /projects/:folderId?detail=:itemId 형태다. 우측 패널과 모달 전환 기준은 뷰포트 너비다. 1280px 이상은 우측 패널, 미만은 모달이다.
