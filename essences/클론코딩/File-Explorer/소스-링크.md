# File Explorer 소스 링크

VS Code File Explorer 원본 소스.

## 핵심 파일

### explorerView.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/views/explorerView.ts

메인 뷰 컨트롤러. Context Keys 바인딩, autoReveal, 압축 폴더 네비게이션.

### explorerViewer.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/views/explorerViewer.ts

트리 렌더링 핵심. FilesRenderer, FilesFilter, FileSorter, FileDragAndDrop, ExplorerFindProvider, CompressedNavigationController.

### explorerService.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/explorerService.ts

서비스 레이어. select(), findClosest(), applyBulkEdit(), setEditable(), setToCopy(), refresh().

### explorerDecorationsProvider.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/views/explorerDecorationsProvider.ts

데코레이션 제공자. Git 상태, 심볼릭 링크, 오류 표시.

### explorerModel.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/common/explorerModel.ts

ExplorerItem 모델 정의. nestedParent, hasNests 속성.

## 파일 액션/커맨드

### fileActions.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/fileActions.ts

파일 작업 액션. NewFile, NewFolder, Rename, Delete, Copy, Cut, Download, Upload.

### fileCommands.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/fileCommands.ts

커맨드 정의. copyFilePath, copyRelativeFilePath, revealFileInOS, revealInExplorer.

### files.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/common/files.ts

Context Keys 정의. ExplorerFolderContext, ExplorerResourceReadonlyContext, ExplorerResourceCut, ExplorerCompressedFocusContext.

### fileImportExport.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/fileImportExport.ts

파일 업로드/다운로드. BrowserFileUpload, ExternalFileImport.

### explorerFileContrib.ts
https://github.com/microsoft/vscode/blob/main/src/vs/workbench/contrib/files/browser/explorerFileContrib.ts

파일 탐색기 확장 기여도 레지스트리.
