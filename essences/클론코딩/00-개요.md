# 리서치도구

웹 서핑 중 발견한 정보를 단축키 하나로 수집하고, AI가 자동으로 분류 및 요약하며, 이를 바탕으로 아이디어를 발전시킬 수 있는 통합 작업 공간을 제공하는 데스크톱 애플리케이션이다.

## 문제

정보 수집/정리 과정에서 생각의 흐름이 끊어진다.

링크, 스크린샷, 메모, 이미지가 여러 앱에 흩어져 있고, 앱 전환할 때마다 사고의 깊이가 감소한다. 전환 비용(switch cost)으로 생산성이 40% 감소하고 회복 시간은 23분이 걸린다. Gloria Mark의 연구가 이를 증명한다.

## 솔루션

AI 기반 통합 지식 관리 도구다. 수집부터 발상까지 한 곳에서 해결한다.

핵심 워크플로우:
```
수집 → 검토 → 통합 → 정제 → 아이디어 발상
```

## 핵심 가치

1. 전환 비용 제거: 모든 정보를 한 곳에서 관리
2. 몰입 유지: 투명 UI로 생각의 흐름을 끊지 않음
3. AI 자동화: 요약, 키워드, 검색 자동화로 정리 부담 감소

## 주요 기능

7가지 핵심 기능으로 구성된다.

- 수집: Alt+우클릭, 드래그앤드롭, AI 요약+키워드 자동 생성
- 정리: 카테고리별 자동 분류, All/텍스트/링크/이미지/동영상 폴더
- 메모: Monaco Editor, 메인창+사이드바+포스트잇 공유
- 창관리: Liquid Glass UI 포스트잇, 항상 위, 투명
- 검색: Elasticsearch-rs 유의어 검색, AI 키워드+요약 포함
- AI: RAG 기반 대화형 어시스턴트, Elevenlabs TTS/STT, MCP 지원
- 협업: Figma 스타일 실시간 협업, 동시 수정, 채팅
