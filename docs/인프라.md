# 인프라

클라이언트 모노레포의 배포·환경을 정의한다. 서버(flux-be) 인프라는 별도 저장소의 `docs/인프라.md` 참고.

## 플랫폼별 배포

| 플랫폼 | 배포처 | 전략 |
|------|------|------|
| Web (Next.js) | Vercel 또는 EC2 | Vercel이 기본. 비용·제약 시 EC2로 전환 |
| Desktop (Tauri) | GitHub Releases | Tauri updater로 자동 업데이트. macOS/Windows/Linux 3종 |
| Mobile (iOS) | App Store | Expo EAS Build. Apple Developer 계정 필요 |
| Mobile (Android) | Play Store | Expo EAS Build |
| Browser Extension | Chrome Web Store | MV3. 리뷰 대기 3~5일 |

웹이 1순위다. Next.js API Routes가 AI 프록시와 인증 리다이렉트를 담당한다. 모바일·데스크톱은 같은 Rust 서버(flux-be)에 직접 연결한다.

## 서버 연동

클라이언트는 flux-be 서버와 두 채널로 통신한다.

```
Client ──HTTPS──→ flux-be /api/* (REST, 초기 로드/벌크 작업)
       ──WSS───→ flux-be /sync   (실시간 변경 동기화, CRDT delta)
```

서버 엔드포인트는 `flux-be/docs/아키텍처.md`의 API 설계 참고. WebSocket은 재연결 시 지수 백오프로 자동 복구.

## 환경변수

프론트엔드 환경변수는 `NEXT_PUBLIC_` 접두사가 필요한 것만 브라우저에 노출된다. 서버 전용은 프리픽스 없이.

```
# apps/web
NEXT_PUBLIC_API_URL=https://api.flux.app
NEXT_PUBLIC_WS_URL=wss://api.flux.app/sync
OPENROUTER_API_KEY=...   # 서버 전용 (API Routes에서만)

# apps/desktop (Tauri)
VITE_API_URL=...

# apps/mobile (Expo)
EXPO_PUBLIC_API_URL=...

# apps/extension
# 브라우저 확장은 manifest.json permissions로 API 도메인 허용
```

시크릿(OPENROUTER_API_KEY 등)은 git에 올리지 않는다. `.env.example`에 키 이름만 남긴다.

## CI/CD

GitHub Actions 사용. 모노레포 전체에서 워크플로우 두 가지.

- `ci.yml`: PR/main push 시 `pnpm lint`, `pnpm type-check`, `pnpm test`, `pnpm build` 실행. 어느 앱이든 깨지면 머지 차단
- `deploy.yml`: 수동 트리거 또는 tag push. 플랫폼별로 분기:
  - web → Vercel (또는 EC2 blue/green)
  - desktop → GitHub Releases + Tauri updater
  - mobile → Expo EAS Submit
  - extension → Chrome Web Store 제출

Turbo 캐시(Turborepo)로 변경 없는 패키지는 재빌드 건너뛴다.

## 로컬 개발

```bash
pnpm install              # 전체 의존성
pnpm dev --filter web     # 웹만
pnpm dev --filter desktop # Tauri 데스크톱 (Rust 빌드 포함)
pnpm dev --filter mobile  # Expo (QR로 기기 연결)
pnpm dev                  # 전부 (메모리 많이 씀)
```

flux-be 로컬 연결: `.env.local`에서 `NEXT_PUBLIC_API_URL=http://localhost:3001` 설정 후 flux-be를 `cargo run`으로 띄운다.

## 모니터링

초기에는 Vercel Analytics와 Sentry로 시작. 프로덕션 에러와 웹 성능을 본다. 서버 쪽 모니터링은 flux-be 저장소 참고.

```
Sentry: 클라이언트 런타임 에러, crash report
Vercel Analytics: Web Vitals, SSR 응답 시간
PostHog (선택): 사용자 행동, 기능 플래그
```

## 업데이트 전략

| 플랫폼 | 업데이트 | 강제/선택 |
|------|---------|---------|
| Web | 배포 즉시 반영 (브라우저 새로고침) | 강제 |
| Desktop | Tauri updater가 실행 시 체크, 사용자 승인 후 설치 | 선택 |
| Mobile | EAS Update (OTA, JS 번들만) + 스토어 빌드 | 혼합 |
| Extension | Chrome이 자동 업데이트 (최대 5시간 지연) | 강제 |

서버 API 변경은 버전 필드로 하위 호환을 유지한다. 클라이언트가 `X-API-Version` 헤더를 보내고 서버가 요청 버전에 맞게 응답한다.
