# 디자인 가이드

Flux의 디자인 결정사항이다.


## 디자인 원칙

본질: 본질만 간결하게 표현한다
→ 적용: 장식적 요소 배제, 정보 전달에 필요한 것만 남긴다

즉각: 모든 인터랙션은 즉시 반응한다
→ 적용: 전환 150ms 이하, 드래그와 탭은 0ms

몰입: 작업 흐름을 끊지 않는다
→ 적용: 모달 최소화, 인라인 편집 우선

집중: 지금 필요한 것만 보여준다
→ 적용: 화면당 주요 행동 1개, Compact density로 밀도 확보

배려: 사용자가 "나를 생각했구나"를 느끼게 한다
→ 적용: reduce-motion 지원, 포커스 링 항상 표시, 44px 터치 영역

밀도는 Compact (Google Material Design 최고 밀도). 접거나 숨기지 않고, 간격을 줄여서 한 화면에 필요한 정보를 모두 보여준다.

## 레이아웃/스페이싱

4px 기반 배수 체계.

```css
--spacing-0: 0;
--spacing-0-5: 0.125rem;  /* 2px */
--spacing-1: 0.25rem;     /* 4px — 인라인 간격 */
--spacing-2: 0.5rem;      /* 8px — 요소 내부 패딩 */
--spacing-3: 0.75rem;     /* 12px — 카드 gap */
--spacing-4: 1rem;        /* 16px — 섹션 내부 패딩 */
--spacing-6: 1.5rem;      /* 24px — 섹션 간 간격 */
--spacing-8: 2rem;        /* 32px */
--spacing-12: 3rem;       /* 48px */
```

브레이크포인트 (데스크톱 전용, 모바일은 React Native 별도):

| 이름 | 크기 | 대상 |
|------|------|------|
| sm | 900px | 사이드바 자동 접힘 경계 |
| md | 1024px | 사이드바 접기 권장 |
| lg | 1280px | 기준 설계 |
| xl | 1440px | 대형 모니터 |


## 디자인 토큰

3계층 구조: Primitive → Semantic → Component

```css
/* radius (Figma export 기준) */
--radius-sm: 0.25rem;    /* 4px — 탭, 인라인 코드 */
--radius-md: 0.375rem;   /* 6px — 폴더 아이템, 버튼 */
--radius-lg: 0.5rem;     /* 8px — 아이콘 버튼, 코드 블록 */
--radius-xl: 0.75rem;    /* 12px — 갤러리 카드, AI 입력 */
--radius-full: 9999px;   /* 원형 — 아바타, 토글 */

/* shadow (라이트 모드 전용) */
--shadow-sm: 0 1px 2px oklch(0 0 0 / 0.05);
--shadow-md: 0 4px 6px oklch(0 0 0 / 0.07);
--shadow-lg: 0 10px 15px oklch(0 0 0 / 0.1);

/* motion */
--duration-instant: 0ms;
--duration-fast: 100ms;
--duration-normal: 150ms;
--duration-slow: 200ms;
--ease-out: cubic-bezier(0.33, 1, 0.68, 1);
--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
```

토큰 파일: `apps/frontend/web/src/app/globals.css`

모션 사용 가이드:

| 인터랙션 | duration | easing |
|----------|----------|--------|
| hover 효과 | fast (100ms) | ease-in-out |
| 사이드바 토글 | normal (150ms) | ease-out |
| 드롭다운 열기 | fast (100ms) | ease-out |
| 뷰 모드 전환 | slow (200ms) | ease-out |
| 드래그 추종 | instant (0ms) | — |
| 탭 전환 | instant (0ms) | — |

## UI 컴포넌트 목록

기본 입력: Button, Input, Select, Checkbox, Switch
레이아웃: Card, Separator, Tabs, ResizablePanel
오버레이: Dialog, Popover, Tooltip, DropdownMenu, ContextMenu, Sheet
피드백: Toast, Skeleton
데이터: Badge, Avatar
네비게이션: Sidebar, TreeView

커스텀:
- ItemCard: 썸네일 + 제목 + 요약 + 키워드 칩. 아이템 타입별 렌더링.
- TreeView: 폴더/세션 사이드바 트리. h 28px compact.
- StatusBar: h 20px. 평상시 아이콘만, 문제 시 텍스트 확장.
- AIPanel: w 380px. Cursor 스타일 채팅 패널.


## 아이콘

Lucide (라인 스타일). React Symbols는 파일/폴더 타입 보조용.

```tsx
import { Star } from "lucide-react"

<Star size={16} />  // sm: 인라인, 카드 내
<Star size={20} />  // md: 버튼, 메뉴
<Star size={24} />  // lg: 빈 상태, 강조
```


## 다크모드

지원한다. 기본값은 시스템(OS 설정)을 따르고, 앱 내 설정에서 라이트/다크/시스템 중 선택한다.

다크 모드가 Figma export 원본이다. 라이트 모드는 L 반전으로 파생했다. 다크에서는 shadow를 제거하고 border 강조로 대체한다.


## 접근성

WCAG 2.2 AA 준수.

- 텍스트 대비율: 4.5:1 이상
- UI 대비율: 3:1 이상
- 최소 터치 영역: 44x44px (iOS HIG)
- 포커스 링: `outline: 2px solid var(--ring); outline-offset: 2px;`
- reduce-motion: 모든 전환 0ms
- 시맨틱 HTML 우선 (nav, main, aside, section)
- 아이콘: 장식용 aria-hidden, 의미용 aria-label
