# 라우팅

이 프로젝트는 React Router v7를 사용한다. SPA(Single Page Application) 방식으로 동적 라우팅, 중첩 라우팅, 라우트 로더를 지원한다.

## 라우트 구조

```
/ (Root)
├── /explorer          # 파일 탐색기 뷰
├── /settings          # 설정 페이지
├── /editor/:fileId    # 에디터 뷰 (동적)
└── /404               # Not Found
```

## 라우트 설정

**파일**: `src/routes/index.tsx`

```tsx
import { createBrowserRouter } from 'react-router-dom';

const router = createBrowserRouter([
  {
    path: '/',
    element: <RootLayout />,
    children: [
      {
        index: true,
        element: <Navigate to="/explorer" replace />
      },
      {
        path: 'explorer',
        element: <ExplorerView />
      },
      {
        path: 'editor/:fileId',
        element: <EditorView />,
        loader: fileLoader
      },
      {
        path: 'settings',
        element: <SettingsView />
      },
      {
        path: '*',
        element: <NotFoundView />
      }
    ]
  }
]);
```

## 네비게이션

### Link 컴포넌트

```tsx
import { Link } from 'react-router-dom';

<Link to="/explorer">Go to Explorer</Link>
<Link to={`/editor/${fileId}`}>Open File</Link>
```

### 프로그래매틱 네비게이션

```tsx
import { useNavigate } from 'react-router-dom';

function FileItem({ path }: Props) {
  const navigate = useNavigate();

  const handleClick = () => {
    navigate(`/editor/${encodeURIComponent(path)}`);
  };

  return <div onClick={handleClick}>{path}</div>;
}
```

## 라우트 로더

### 데이터 미리 로드

```tsx
const fileLoader = async ({ params }) => {
  const { fileId } = params;
  const content = await window.electron.readFile(fileId);
  return { content };
};

// 컴포넌트에서 사용
import { useLoaderData } from 'react-router-dom';

function EditorView() {
  const { content } = useLoaderData();
}
```

## 라우트 가드

### 인증 체크

```tsx
function ProtectedRoute({ children }: Props) {
  const isAuthenticated = useAuth();

  if (!isAuthenticated) {
    return <Navigate to="/login" replace />;
  }

  return children;
}

// 라우트 적용
{
  path: 'settings',
  element: <ProtectedRoute><SettingsView /></ProtectedRoute>
}
```

## 에러 처리

### Error Boundary

```tsx
{
  path: '/explorer',
  element: <ExplorerView />,
  errorElement: <ErrorBoundary />
}
```

### 에러 컴포넌트

```tsx
import { useRouteError } from 'react-router-dom';

function ErrorBoundary() {
  const error = useRouteError();

  return (
    <div>
      <h1>Oops!</h1>
      <p>{error.message}</p>
    </div>
  );
}
```

## 히스토리 관리

### 뒤로/앞으로 가기

```tsx
import { useNavigate } from 'react-router-dom';

function NavigationButtons() {
  const navigate = useNavigate();

  return (
    <>
      <button onClick={() => navigate(-1)}>Back</button>
      <button onClick={() => navigate(1)}>Forward</button>
    </>
  );
}
```
