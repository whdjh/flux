# 철학 — 기본값과 사용자 지정

flux 전반에 걸쳐 사용자 설정 가능한 모든 영역(테마·창관리·단축키 등)에 적용하는 기본 원칙. 결정은 features·design-system에 옮긴다. 본 파일은 원재료(에센스).

---

## 원칙 (정제)

> **개발자가 최선의 기본값을 끝까지 튜닝하고, 사용자 지정도 항상 열어둔다.**

두 축이 동시에 살아있어야 한다. 어느 한쪽이 빠지면 만족도가 떨어진다.

1. **최선의 기본값**: 개발자(준영)가 자기 취향·관찰·실측을 근거로 가장 합당한 디폴트를 정해 박는다. 끊임없이 튜닝한다 — "그냥 무난한 값"으로 비우지 않는다. 기본값은 무관심의 자리가 아니라 **언제나 최선을 다 하는 자리**다.
2. **사용자 지정 항상 열어둠**: 기본값이 누군가에게 안 맞을 수 있다는 점을 인정하고, **선택지가 가능한 영역이면 모두 사용자 지정 진입로를 둔다**. 가능 여부를 판단하는 주체는 개발자.

이 두 축은 충돌하지 않는다. 기본값을 게을리 둘 핑계로 "사용자가 알아서"를 쓰지 않고, 사용자 지정을 막을 핑계로 "내가 정한 게 답"을 쓰지도 않는다.

---

## 첫 사례 — 테마

설정 페이지의 "테마" 항목 디자인.

- **레이아웃**: 좌측 = 테마 메뉴, 우측 = 기본 팔레트 5개 미리보기 + "사용자 지정 팔레트" 슬롯.
- **기본 팔레트 5개**:
  1. **라이트** (시스템 표준)
  2. **다크** (시스템 표준)
  3. **노란/메모지** — Claude 데스크톱 앱의 노란색 계열. flux는 AI 노트테이킹 앱이라 메모지 같은 톤이 본질에 가장 잘 맞고, **눈 피로 적고 가독성 좋다는 두 조건을 동시에 만족**한다. flux 디폴트 후보 1순위로 의미 있음.
  4. **Dracula soft 계열** — VSCode 익스텐션의 Dracula soft 같은 가독성 좋은 다크 대체. 일반 다크보다 눈에 부드러움.
  5. **칠판색** — 어두운 초록에 약간의 파란이 섞인 톤. 크리스마스 딥 시안에 가깝다. 준영이 블랙 + 칠판색 옷·인테리어를 자주 좋게 봤기 때문에 개인 취향 기반으로 들어감(칠판 자체를 좋아하는 게 아니라 색감이 그렇다는 뜻).
- **사용자 지정 팔레트**: 5개 중 하나도 안 맞으면 직접 만들 수 있는 슬롯. 항상 노출.

테마는 이 원칙의 첫 사례이고, **같은 형식이 다른 설정 영역에도 그대로 적용**된다 — 예: 창관리(기본 zone 크기 + 사용자 지정), 단축키(기본 매핑 + 재정의), 글꼴, 줄간격 등.

## 적용 가이드 (다른 영역에 옮길 때)

새 설정 항목을 도입할 때 다음 체크리스트:

- [ ] 기본값이 1개가 아니라 **여러 후보**인가? 후보 3~5개를 디폴트 메뉴로 노출하는 게 합당한가?
- [ ] 후보 각각에 **개발자가 선호하는 이유**가 있는가? "그냥 모은 것" 금지.
- [ ] 사용자 지정 진입로는 어디에 있는가? **메뉴 속 메뉴로 깊이 묻지 않는다** — 후보 옆에 동등 슬롯으로.
- [ ] 사용자 지정의 결과는 어디에 저장되며, 다른 기기로 동기화되는가? (→동기화 정책)

## 사용자 발화 원본 (2026-05-04)

정제 본문이 사용자 의도와 어긋날 때 본 원본이 진실 기준이다.

> flux 철학을 생각하고 있어. 기본적인 설정은 내가 좋아하는 걸로 맞춰서 두고.
> 나머진 사용자가 사용자 지정할 수 있게 하는거야.
> 예를 들면 테마를 설정하는 세팅 페이지가 있어,
> 좌측엔 테마
> 우측엔 색상 팔레트 5개 + 사용자 지정 팔레트 모양이 보이는거지.
> 색상 팔레트 5개는 기본적으로 우리가 지원하는거야.
> 라이트모드 다크모드 정도가 기본적으로 있겠고,
> flux는 특성상 눈을 피로하지 않게 만들면서 가독성이 좋고 싶어.
> Claude 데스크톱 앱의 색상처럼
> 노란색 계열의 약간 메모지 같은 형태가 좋겠어.
> AI 노트테이킹 앱이기도 하고,
> 그 색이 가장 좋을 것 같아. 그래서 그 팔레트토 하나 있을거고,
> 다크모드 대신 사용할
> 가독성 좋은 뭐 VSCode 익스텐션의 Dracula soft 같은 테마를 하나 넣으면 좋겠고
> 나머지 하나는 내가 칠판색?(칠판을 좋아하는게 아님) 계열을 좋아하거든. 블랙 + 칠판색의 옷이 정말 예뻐서.
> 근데 다른 곳에도 자주 이쁘더라고. 크리스마스 딥 시안? 그런 색인데.
> 어두운 초록색인데 약간의 파란섞인. 칠판색이라고 그냥 표현할게.
>
> 이 색까지. 총 5개를 기본 설정값으로 두고, 사용자 지정을 항상 열어두는 거야.
>
> 그게 나의 만족도를 높일거야.
>
> 창관리와 이 내용을 정리해서 기준으로 만들고 싶어.
>
> 설정쪽의 철학은 항상 개발자인 내가 적절한 기준값을 게속 튜닝, 생각해서 정해두고
> 사용자가 지정해 둘 수 있는 선택지가 되면 넣어두는 형태가 최선인 것 같아. 언제나 최선을 다 하려고 하는거야.
