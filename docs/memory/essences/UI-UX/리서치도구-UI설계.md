# 리서치도구 UI설계

## 레이아웃 시스템

애플리케이션은 3-panel 레이아웃을 따른다. 좌측 사이드바 336px, 메인 콘텐츠 영역, 우측 패널 336px로 구성된다. 상단에는 타이틀바 56px와 탭바 34px가 있다. 모든 수치는 디자인 토큰 기반으로 임의 픽셀값을 쓰지 않는다.

기본 캔버스는 1680×1050이다. 1440×900, 1280×800 변형도 지원한다. 12컬럼 그리드를 쓰며 거터는 24px다. 좌우 마진도 24px다. 모든 간격은 8pt 스케일(4/8/12/16/24/32/40/48/64)만 허용한다.

타이틀바는 좌측에 제품명과 창 제어 버튼, 우측에 전역 검색창(폭 320px), 알림 아이콘, 프로필을 배치한다. 탭바는 탭 리스트와 새 탭 버튼(+)을 제공한다. 탭 아이템은 높이 34px, 좌우 패딩 12~16px, 닫기 버튼(×)을 우측에 둔다.

좌측 사이드바는 Inbox, Projects, Tags, Views, Favorites 섹션으로 나뉜다. 항목 높이는 40~44px다. 섹션 헤더는 상단 패딩 12px, 하단 패딩 8px다. 아이콘 크기는 20px다. 사이드바는 리사이즈 핸들 8px로 조절할 수 있고 최소 240px, 최대 360px다. 접힘 너비는 64px로 아이콘 모드를 유지한다.

메인 콘텐츠 영역은 상단 바(높이 52px)에 필터, 정렬, 검색 기능을 둔다. 내부 패딩은 16~24px다. 콘텐츠는 List, Grid, Masonry, Justified 네 가지 뷰를 지원한다. 카드는 160×200px, 반경 12px, 거터 24px다. 리스트 행 높이는 52px다.

우측 패널은 폭 336px로 메모나 AI 어시스턴트를 표시한다. 헤더 높이는 48~56px다. 내용은 스크롤 가능하다. 닫기 아이콘은 20px다. 1280px 미만 폭에서는 자동으로 오버레이 모드로 전환된다.

분할은 1/2, 1/3, 1/4 프리셋을 제공한다. 리사이즈 핸들은 더블클릭으로 균등 분할로 복귀한다. 스냅은 2% 단위로 작동하며 Alt 키로 무시할 수 있다. 패널 최소 폭은 320px다.

## 디자인 토큰

모든 색상, 크기, 간격, 반경, 모션은 토큰 기반이다. 브랜드 컬러는 primary 500:#5D3587, accent 400:#A06CD5다. 라이트 모드는 배경 #F8F4F0, 패널 #FFF, 텍스트 #111216이다. 다크 모드는 배경 #1C1C1C, 패널 #2A2B2C, 텍스트 #EDEEF0이다. 하이 콘트라스트 모드도 지원한다.

의미색은 success #10B981, warning #F59E0B, danger #EF4444, info #3B82F6다. Liquid Glass 효과는 blur 22px, 배경 알파 0.06, 보더 알파 0.16이다.

아이콘 크기는 기본 24px, 보조 20px, 작은 것 16px다. 스트로크는 2px다. 반경은 입력/버튼/카드 12px, 패널/모달 20px, 칩 8px다.

타이포그래피는 Inter와 Pretendard를 쓴다. 크기는 xs 12px, sm 14px, md 16px, lg 20px, xl 24px, xxl 32px, display 40px다. 본문 행간은 1.5, 제목 행간은 1.4다.

포커스 링은 색상 #5D3587, 두께 2px, 오프셋 2px, 반경 6px다. 섀도우는 shadow-1(0 1px 2px rgba(0,0,0,.08)), shadow-2(0 4px 8px rgba(0,0,0,.12))를 쓴다.

모션은 fast 100ms, normal 150ms, slow 200ms다. 이징은 standard cubic-bezier(0.2,0,0,1), enter cubic-bezier(0,0,0.2,1), exit cubic-bezier(0.4,0,1,1)다. 패널 열고닫기는 40ms ease-out다. 리사이즈는 실시간(0ms)이다.

ZIndex는 base 0, dropdown 1000, modal 2000, toast 3000, drag 4000다. 오버레이 스크림은 rgba(0,0,0,0.40)이다.

## Masonry 레이아웃

Masonry는 콘텐츠 폭에 따라 열 개수를 자동 계산한다. 계산식은 floor((콘텐츠폭 + 24) / (160 + 24))다. 1280px 캔버스에서 콘텐츠폭은 약 944px이므로 5열이다. 1440px는 6열, 1680px는 7열이다.

가상 스크롤을 권장한다. 화면과 소량의 overscan만 렌더해서 DOM, 메모리, 리플로우를 최소화한다. 스켈레톤 카드를 제공한다. 이미지는 LQIP나 Skeleton과 IntersectionObserver로 로딩한다.

드래그앤드롭 시 key를 안정적으로 유지한다. 드래그 중에는 측정을 pause한다. 스크롤 위치를 보존하고 깜빡임이 없어야 한다. 성능 타겟은 60FPS, 메모리는 300~400MB 이내다.

## 18개 페이지 구조

페이지는 M0, M1, M2로 우선순위를 나눈다. M0는 00_App Shell, 01_Inbox, 02_Project, 03_Detail, 04_Editor, 05_Search, 08_Settings, 09_Layout, 10_Capture, 15_Onboarding다. M1은 06_AI, 12_Export, 13_Tags, 14_Trash, 17_Viewer다. M2는 11_Collab, 16_Voice다.

00_App Shell은 공통 프레임이다. 타이틀바, 탭바, 좌측 사이드바, 메인 콘텐츠, 우측 패널을 포함한다. 전역 검색, 알림, 프로필, 단축키 힌트, 창 제어 버튼을 제공한다. 테마는 Liquid Glass로 라이트/다크/하이 콘트라스트를 토글한다. 창 투명도와 데코레이션도 토글할 수 있다.

01_Inbox는 수집된 아이템 피드다. 상단에 검색창, 정렬(최신/오래된순), 필터(타입/태그)가 있다. 보기 모드는 List, Grid, Masonry, Justified를 전환한다. 좌측 폴더 트리에서 드래그앤드롭으로 이동한다. 멀티 선택(Shift/Ctrl)과 벌크 액션(이동/삭제/태그)을 지원한다. 컨텍스트 메뉴가 있고 로딩 스켈레톤과 빈 상태를 구분한다.

02_Project는 프로젝트 폴더 뷰다. 헤더에 이름, 색/아이콘, 공유 상태를 표시한다. 폴더 퀵 액션(추가/이름변경/삭제)을 제공한다. 우측 콘텐츠는 그리드/리스트 스위치로 전환한다. 빈 상태 메시지와 가이드를 보여준다.

03_Detail은 아이템 상세 페이지다. 우측 패널 336px 또는 모달(반경 20px)로 열린다. 미디어 탭(이미지/링크/텍스트)과 메타 탭(제목/URL/생성일/태그/AI 요약/키워드)이 있다. 액션은 즐겨찾기, 이동, 삭제, 복사, 원본 열기다. 제목/태그/노트는 편집 가능하고 자동 저장된다.

04_Editor는 메모 에디터다. Monaco Editor 기반이다. 제목 입력 영역과 툴바(볼드/이탤릭/밑줄/코드/체크리스트)가 있다. 슬래시(/) 커맨드로 이미지/카드/구분선/콜아웃을 삽입한다. 제목 h1~h3, 토글, 할 일, 코드, 불릿 포인트, 인덱스, 구분선을 자동 변환한다. 확대/축소, 행/열/글자 수 인디케이터를 제공한다. 자동 저장, 버전 히스토리, Undo/Redo를 지원한다.

텍스트를 드래그하면 퀵툴(폰트/볼드/이탤릭/밑줄/취소선/코드/글자색/배경색)이 뜬다. 임베드 Pill은 텍스트/이미지/링크를 드래그해서 넣는다. Pill 형태는 파비콘 16px + 도메인 + 제목이다. 텍스트를 생략하지 않고 길이에 따라 폰트를 동적으로 축소한다.

05_Search는 검색 페이지다. 검색창은 추천/히스토리를 제공하고 150ms 디바운스를 적용한다. 의미검색 토글이 있다. 결과 카드는 제목/스니펫/타입/점수를 표시한다. 필터(타입/폴더/날짜)와 정렬(점수/최신)을 제공한다. 하이라이트 처리를 한다. 오프라인 시 의미검색은 비활성화하고 키워드 검색만 허용한다.

06_AI는 AI 어시스턴트다. 좌측에 채팅 리스트(최근 대화), 우측에 대화 뷰(버블, 코드/이미지 렌더)가 있다. 하단은 입력창 + 전송 + 모델 선택 + 첨부 버튼이다. 스트리밍 표시, 중지 버튼, 토큰/비용 경고를 제공한다.

07_Sticky는 스티커 메모다. 독립 창으로 맨앞 고정을 토글한다. 간단 편집 툴(텍스트/체크박스/이모지)을 제공한다. 빠른 생성 단축키가 있다. 시각적 장치(✅⭐❌⚪▲)를 쓴다. 드래그앤드롭 수집과 연동한다.

08_Settings는 설정 페이지다. 섹션은 계정(로그인/프로필), 데이터(백업/복원/클라우드-Supabase), UI(테마/밀도/투명도), 단축키 매핑이다. 로그아웃 버튼도 있다.

09_Layout은 탭/분할 레이아웃 매니저다. 새 탭(+), 고정, 스크롤, 순서 변경(드래그)을 지원한다. 분할 프리셋 버튼(1/2, 1/3, 1/4)과 리사이즈 핸들이 있다. 최소 폭/높이를 강제하고 스냅 포인트를 제공한다.

10_Capture는 수집 플로우다. Alt+우클릭 오버레이로 캡처한다. 메타를 자동 채운다. 드롭존 가시성을 제공하고 성공/실패 피드백을 준다. 확장(브라우저) ↔ 앱 통신 상태를 표시한다.

11_Collab는 협업/공유다. 상단에 프로필 아바타 스택이 있다. 라이브 커서(색상, 이니셜)를 표시한다. 댓글 패널과 인라인 코멘트를 지원한다. 퀵 채팅 패널을 슬래시(/)로 토글한다. 공유/권한 모달(읽기/편집)을 제공한다.

12_Export는 내보내기/공유다. 범위 선택(페이지/선택/전체), 스타일 옵션(이미지 포함/캡션)을 제공한다. 파일명 규칙은 {YYYY-MM-DD}_{title}다. PDF와 Markdown 형식을 지원한다.

13_Tags는 태그/분류 매니저다. 태그 리스트/검색, 색상 선택, 병합, 일괄 태그 적용(선택 아이템)을 제공한다.

14_Trash는 트래시/복구다. 목록에 삭제일과 남은일수를 표시한다. 복구/영구삭제, 일괄 처리를 지원한다.

15_Onboarding은 온보딩/로그인이다. 로그인/회원가입/비밀번호 재설정을 제공한다. 최초 실행 시 테마·밀도·투명도를 설정한다.

16_Voice는 보이스 기능이다. 마이크 on/off 토글과 음성 레벨 인디케이터가 있다. 읽어주기(TTS) 재생/일시정지/정지를 제공한다.

17_Viewer는 미디어 뷰어다. 이미지 줌/팬(핸들/휠), 비디오 재생/시킹/음소거를 지원한다. 전체화면과 회전 기능이 있다.

## 라우팅 구조

라우팅은 최상위 내비와 딥링크를 정의한다. /inbox는 01_Inbox, /projects는 02_Project, /projects/:folderId는 프로젝트 상세, /detail/:itemId는 03_Detail 모달, /notes/:noteId는 04_Editor, /search는 05_Search, /ai는 06_AI, /sticky는 07_Sticky, /settings는 08_Settings, /layout은 09_Layout, /capture는 10_Capture, /collab는 11_Collab, /export는 12_Export, /tags는 13_Tags, /trash는 14_Trash, /onboarding은 15_Onboarding, /voice는 16_Voice, /viewer는 17_Viewer다.

사이드 패널 상세는 쿼리로 처리한다. /projects/:folderId?detail=:itemId 형태다. 우측 패널과 모달 전환 기준은 뷰포트 너비다. 1280px 이상은 우측 패널, 미만은 모달이다. 딥링크는 우측 패널은 쿼리 ?detail=:itemId, 모달은 /detail/:itemId다.

탭, 사이드바 선택, 정렬/필터, 보기 모드를 URL 쿼리로 보존한다. /inbox?view=masonry&sort=latest&filter=tag:design 같은 형태다. 브레드크럼은 Projects 트리 경로를 상단 보조 내비로 표시한다. 접근성 라벨을 포함한다.

## UX 패턴

선택은 단일/멀티를 지원한다. Click은 단일 선택, Shift는 구간 선택, Ctrl/Cmd는 개별 토글이다. 벌크 액션은 선택 시 상단/하단 바를 노출한다(이동/태그/삭제). 키보드는 Arrow로 포커스 이동, Space/Enter로 선택 토글이다.

드래그앤드롭은 카드/행 핸들 혹은 전체 영역을 허용한다. 드롭 피드백은 hover 강조로 유효/무효 영역을 구분한다. 실패 시 원복(revert)하고 토스트를 띄운다. 키보드 대체는 컨텍스트 메뉴의 이동으로 가능하다.

리스트/그리드/Masonry는 가상 스크롤을 권장한다. 스켈레톤을 제공한다. 페이지네이션 vs 인피니트는 데이터 밀집도와 연속성 기준으로 화면별로 결정한다. Inbox는 인피니트 스크롤을 기본으로 한다.

검색/필터/정렬은 입력 디바운스(200~300ms)를 적용한다. 히스토리와 추천을 제공한다. 정렬/필터 변경 시 즉시 반영하고 스켈레톤 상태로 전환한다.

## 상태 처리

상태는 Loading, Empty, Success, Offline, Error, Processing으로 나뉜다. Loading은 스켈레톤 우선이다. 스피너는 최소화한다. 레이아웃 점프를 금지한다. Empty는 설명 + 1차 CTA + 학습 링크를 제공한다. Success는 중복 피드백을 지양한다.

Offline은 읽기를 우선한다. 쓰기는 큐잉하거나 보류 표시를 한다. 상단에 오프라인 인디케이터를 띄운다. Error는 발생 위치에 인라인 메시지를 표시한다. 상황에 따라 토스트나 모달을 쓴다. 재시도를 명시한다. Processing(Long)은 진행률/단계를 표시한다. 취소 가능 시 버튼을 제공한다.

글로벌 규칙은 네트워크 인디케이터를 Topbar에 Online/Offline 배지로 표시한다. 글로벌 에러 바운더리는 복구 버튼(새로고침/상위로 이동)을 제공한다. 토스트는 우상단에 3~5초 동안 표시하고 수동 닫기를 제공한다. aria-live="polite"를 쓴다.

재시도는 즉시 재시도와 지수 백오프(1s, 2s, 4s)를 적용한다. 대기 중 비활성화한다. 키보드 우선으로 Escape로 오버레이를 닫고 Tab 순서를 보장한다. 포커스 링을 표시한다. 히트 영역은 최소 44px다. 색상 토큰 매핑은 success/warning/danger/info를 semantic 토큰으로 쓴다.

드래그앤드롭은 드롭 대상을 가시화한다(hover 강조). 성공/실패 피드백을 제공한다. 실패 시 원복하고 토스트를 띄운다. 데이터 손실을 금지한다. 키보드 대체 경로를 제공한다(컨텍스트 메뉴 이동).

메모 에디터는 자동저장 인디케이터(저장됨/저장 중/오류)를 표시한다. 오프라인 시 로컬 캐시를 쓰고 온라인 복구 시 병합한다. 충돌 해결 규칙을 명시한다. 나가기 전 미저장 경고를 띄운다.

수집(Capture)은 오버레이 단계로 캡처 중 → 메타 추출 → 저장 성공/실패를 표시한다. 권한 문제나 드롭 실패 시 인라인 가이드와 재시도를 제공한다.

AI 어시스턴트는 스트리밍 상태를 표시하고 중지 버튼을 제공한다. 요청 오류/토큰 초과 시 에러 메시지를 표시하고 입력을 보존한다. 재시도를 제공한다.

검색은 오프라인 시 의미검색을 비활성화하고 키워드 검색만 허용한다(로컬 인덱스). 쿼리/필터/정렬 상태를 유지한다.

## 단축키

전역 단축키는 Ctrl/Cmd + K로 커맨드 팔레트를 연다. 슬래시(/)로 퀵 채팅/검색을 토글한다. Tab/Shift+Tab으로 포커스를 순환한다. Ctrl/Cmd + W로 현재 탭을 닫는다. Ctrl/Cmd + T로 새 탭을 연다. Ctrl/Cmd + 1..9로 탭을 전환한다. Ctrl/Cmd + ,로 설정을 연다. F11 또는 Ctrl/Cmd + Ctrl/Cmd + F로 전체화면을 토글한다.

레이아웃/셸 단축키는 Alt + 1/2/3/4로 분할 프리셋을 전환한다. Alt + [ / Alt + ]로 분할 크기를 조절한다. Ctrl/Cmd + \로 사이드바를 토글한다.

Inbox/Project 단축키는 Ctrl/Cmd + A로 모두 선택한다. Delete로 삭제(Trash로)한다. Enter로 상세를 연다(패널/모달). G L / G G로 Grid/List를 전환한다(임시 제안).

Editor 단축키는 슬래시(/)로 명령을 삽입한다. Ctrl/Cmd + B/I/U로 서식(볼드/이탤릭/밑줄)을 적용한다. Ctrl/Cmd + Z / Shift+Ctrl/Cmd+Z로 Undo/Redo를 한다. Ctrl/Cmd + S로 저장한다(자동저장 상태 표시).

Viewer 단축키는 + / -로 줌 인/아웃을 한다. Space로 재생/일시정지(비디오)를 한다. F로 전체화면을 한다.

## 접근성

분할 핸들은 role="separator", aria-orientation="vertical"을 제공한다. 키보드 리사이즈는 핸들 포커스 상태에서 ←/→로 10px, Shift+←/→로 50px 이동한다. 포커스 링과 명확한 대비 모드를 제공한다.

라이브 피드백은 aria-live("polite"/"assertive")를 적절히 쓴다. 모달은 role="dialog"/"alertdialog", 포커스 트랩, ESC 닫기를 제공한다. 단축키 목록을 도움말/명령 팔레트에서 제공한다.

색상 대비는 본문 4.5:1, UI 3:1을 충족한다. 히트 영역은 최소 44×44px를 보장한다. reduce motion을 지원한다.

## 협업과 동기화

프로필 스택을 상단에 표시한다. 라이브 커서는 색상과 이니셜을 보여준다. 인라인 댓글을 지원한다. 권한은 읽기/편집으로 나뉜다. 동기화와 백업은 Supabase를 쓴다(옵션). 충돌 전략은 타임스탬프 우선 + 수동 병합이다.

## 내보내기 정책

형식은 PDF/Markdown이다. 범위는 페이지/선택/전체를 선택한다. 스타일은 이미지 포함/캡션을 옵션으로 제공한다. 파일명은 {YYYY-MM-DD}_{title} 규칙을 따른다.

Pill 내보내기는 md/txt에서 [제목](링크) + favicon:URL 메타 블록(문서 하단) 또는 대괄호 확장 태그로 선택지를 제공한다.
