## Shortcuts (전역/화면별)

- 목적: 전역/화면별 단축키 맵을 한 장으로
- 소스: `WIREFRAME_PAGES_CHECKLIST.md`

### 전역(Global)
- `Ctrl/Cmd + K`: 커맨드 팔레트(전역 검색)
- `/`: 퀵 채팅/검색 토글(컨텍스트)
- `Tab / Shift+Tab`: 포커스 순환
- `Ctrl/Cmd + W`: 현재 탭 닫기
- `Ctrl/Cmd + T`: 새 탭
- `Ctrl/Cmd + 1..9`: 탭 전환
- `Ctrl/Cmd + ,`: 설정 열기
- `F11` or `Ctrl/Cmd + Ctrl/Cmd + F`: 전체화면 토글(플랫폼 의존)

### 레이아웃/셸
- `Alt + 1/2/3/4`: 분할 프리셋(1/2, 1/3, 1/4)
- `Alt + [` / `Alt + ]`: 분할 크기 조절
- `Ctrl/Cmd + \`: 사이드바 토글

### Inbox/Project
- `Ctrl/Cmd + A`: 모두 선택
- `Delete`: 삭제(Trash로)
- `Enter`: 상세 열기(패널/모달)
- `G L` / `G G`: Grid/List 전환(임시 제안)

### Editor
- `/`: 명령 삽입
- `Ctrl/Cmd + B/I/U`: 서식(볼드/이탤릭/밑줄)
- `Ctrl/Cmd + Z / Shift+Ctrl/Cmd+Z`: Undo/Redo
- `Ctrl/Cmd + S`: 저장(자동저장 상태 표시)

### Viewer
- `+ / -`: 줌 인/아웃
- `Space`: 재생/일시정지(비디오)
- `F`: 전체화면

### DoD(Shortcuts)
- 전역/화면별 주요 플로우가 키보드만으로 가능
- 충돌 없는 키맵(플랫폼별 예약 키 고려)

### 확인 필요
- `G L`/`G G`와 같은 문자 시퀀스 허용 여부
- 탭 고정/핀 단축키 추가?(`Ctrl/Cmd + Shift + P` 등)
