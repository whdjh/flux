### 레이아웃 설계

  프리셋
    1분할: 100%
    2분할: 50/50, 33/67, 67/33
    3분할: 25/50/25, 20/60/20
    4분할: 25/25/25/25 (최대 4분할)

  분할/리사이즈
    최소 폭: 패널 320px, 사이드바 240~420px
    핸들: 6px, 더블클릭 → 현재 그룹 균등 분할로 리셋
    스냅: 2% 단위 스냅, 임계 8px, Alt 키로 스냅 무시

  사이드바
    좌/우 토글 가능, 상태 기억(열림/접힘/폭)
    접힘 너비: 64px(아이콘 모드), 도킹/오버레이 모드 지원(좁은 폭에서 오버레이)
    드래그 리사이즈, 최소·최대 폭 강제

  탭
    각 패널 상단 탭바, 재정렬/핀 고정/스크롤 지원
    단축키: Ctrl+T 새 탭, Ctrl+W 닫기, Ctrl+Tab/Shift+Ctrl+Tab 이동, Ctrl+1..9 점프

  상태 저장
    범위: 앱 전역 + 프로젝트(폴더) 단위
    항목: 좌/우 사이드바 상태와 폭, 분할 프리셋/비율, 활성 탭
    시점: 앱 시작/종료, 프로젝트 전환 시 자동 저장·복원

  단축키(레이아웃)
    Ctrl+B: 좌측 사이드바 토글
    Ctrl+Shift+B: 우측 사이드바 토글
    Ctrl+Alt+S: 수직 분할 추가/해제(현재 패널 기준)
    Ctrl+Alt+[ / ]: 분할 프리셋 이전/다음

  애니메이션
    패널 열고닫기 40ms ease-out, 리사이즈는 실시간(0ms)
    오버레이 사이드바: 페이드+슬라이드 40ms

  접근성
    분할 핸들: role="separator", aria-orientation="vertical"
    키보드 리사이즈: 핸들 포커스 상태에서 ←/→ 10px, Shift+←/→ 50px
    포커스 링/명확한 대비 모드 제공

  투명/다중창
    투명 배경(Liquid Glass) 사용 시 패널 경계선/그림자 보강
    멀티모니터: 새 창 중앙 배치, 마지막 위치·크기 기억

  예외/가드
    최소 폭 미만 방지(클램프), 과분할(>4) 금지
    가로 폭 협소 시 우측 사이드바 자동 접힘(임계 1200px)

  라이브러리 선택
    Resizable(shadcn): ResizablePanelGroup / ResizablePanel / ResizableHandle 사용 계획
    Masonry(masonic): 기본 채택(가상화), 대량 목록 최적

  테스트 체크리스트
    분할 프리셋 전환, 스냅 동작, 최소·최대 폭, 상태 저장·복원
    사이드바 토글/오버레이, 탭 단축키, 투명 모드 경계 가독성
    접근성(키보드 리사이즈/포커스), 다중창 위치 기억

  기본 해상도/프리셋(Eagle 스타일)
    기본 해상도: 1440×900(16:10), 비율 락 없음
    창 프리셋: 1280×800, 1440×900, 1680×1050, 1920×1200, 2560×1600

  Masonry 브레이크포인트(콘텐츠 폭 기준)
    ≤1024: 2컬럼
    ≤1440: 3컬럼
    ≤1920: 4컬럼
    >1920: 5컬럼
    거터: 16px(모바일 12px)

  안전 영역/제약
    콘텐츠 최소: 960×600 보장(패널 최소폭과 충돌 시 패널 우선 클램프)
    우측 사이드바 자동 오버레이 전환 임계: 전체 창 폭 1200px

### Tauri 구현 원칙(bridge 레이어)

UI는 React로, OS 기능은 Tauri 명령·플러그인·사이드카로 분리해. 호스트 의존 코드는 bridge 레이어에만 모으고, 도메인 로직과 상태, 뷰는 순수 React로 유지해. 이렇게 하면 러스트나 런타임을 바꾸더라도 UI를 그대로 재사용하기 쉬워.

bridge: `src/bridge/tauri/*.ts`에서 `invoke` 래퍼를 제공하고, 입력 검증과 에러 매핑을 담당해. 명령은 Rust에서 파일/프로세스/창/클립보드/DB 같은 OS 기능만 최소 표면으로 노출해. 외부 바이너리가 필요할 땐 사이드카를 쓰되, 번들 용량과 업데이트 전략을 함께 고려해.

보안은 옵트인 원칙을 따른다. 네트워크 전송은 기본 비활성, API 키는 보안 저장소에 암호화해 보관하고, 명령 파라미터는 모두 검증해. 로그에는 민감정보를 남기지 않아야 해.

### Tauri 체크리스트(개발/런타임)

윈도우/레이아웃
  decorations=false, transparent=true, shadow=true 설정. window-state 플러그인으로 위치·크기 복원.
  첫 실행 해상도 자동 선택(1440×900 기본, 조건부 1680×1050)과 이후 마지막 크기 복원을 확인해.
  좌/우 사이드바 토글 시 스크롤/그리드 안정성, 패널 최소 폭(320px) 클램프가 지켜지는지 확인해.

단축키/입력
  전역 단축키 등록·해제와 포커스 예외(입력 중 비활성)를 검증해. OS 기본 단축키와 충돌이 없는지도 점검해.

데이터/DB
  SQLite 경로와 권한, FTS5 사용 여부, 마이그레이션 적용을 확인해. 대량(≥50k)에서도 인덱스 성능이 유지되는지 측정해.

파일 파이프라인
  저장/이동/삭제가 트랜잭션과 동기화되는지, 썸네일/프리뷰 생성 실패의 재시도·백오프가 동작하는지 확인해.

수집 브릿지
  로컬 HTTP 서버 포트 선택과 토큰 핸드셰이크, CORS/CSRF 가드를 검증해. 브라우저 확장에서 전송한 메타데이터 정규화가 일관적인지도 확인해.

AI/네트워크
  비용 상한/속도 제한/캐시가 적용되고, 실패 시 재시도와 오류 로그가 남는지 점검해.

로그/업데이트
  파일 회전과 레벨 필터가 동작하고, 이슈 리포트 번들에 필요한 정보만 포함되는지 확인해. 자동 업데이트를 쓴다면 채널/서명 검증을 함께 테스트해.

보안/프라이버시
  외부 전송 옵트인 기본값, 보안 저장소 암호화, shell 명령 allowlist, CSP 헤더 등 정책이 적용되는지 확인해.
