## 페이지별 구현 현황

### 메인 워크스페이스 (Single Page Application)

- Github 커밋 링크:  
- 스크린샷:  
    - 이미지 1  
    - 이미지 2  
- 설명:
    - 본 프로젝트는 별도의 `routes.ts` 파일 없이, 모든 기능이 유기적으로 연결된 단일 페이지 애플리케이션(SPA)으로 구축되었습니다. 주요 기능은 다음과 같이 모듈화된 컴포넌트와 패널로 구현되었습니다.
    -   **콘텐츠 그리드 (`DraggableContentGrid`)**: 수집된 콘텐츠를 다양한 레이아웃(Masonry, Grid, List)으로 보여주는 핵심 영역입니다.
    -   **향상된 사이드바 (`EnhancedSidebar`)**: 폴더 구조 탐색, 화면 줌, 협업 모드 전환 등 네비게이션 허브 역할을 합니다.
    -   **메모 사이드바 (`EnhancedMemoSidebar`)**: `Tiptap` 에디터를 내장하여 강력한 노트 작성 및 편집 기능을 제공합니다.
    -   **실시간 협업 패널 (`CollabPanel`)**: 사용자 목록 및 채팅 기능을 통해 실시간 협업 환경을 지원합니다.
    -   **모달 창**: `SearchModal`, `AuthModal` 등 기능별 모달을 통해 사용자 인터랙션을 처리합니다.
