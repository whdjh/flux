# System Footprint & URL Map for Flux

## 소개
- 본격적인 코딩에 들어가기 전에, 애플리케이션의 전체 구조, 페이지 구성, 사용자 흐름 등을 한눈에 파악하는 것이 이 과제의 목표입니다.
- 단순한 기능 단위의 나열이 아니라, 사용자가 실제 어떤 흐름으로 서비스를 경험하게 되는지를 중심으로 적어보세요.
- 페이지 구성, URL 경로, 사용자 행동, 역할별 권한 등을 사전에 정리하는 작업은, 설계의 누락이나 중복을 방지하고 개발 효율을 높이는 데 도움이 됩니다.
- 실제로 개발할 때 발생할 수 있는 여러 엣지 케이스나 오류 상황도 미리 생각해봄으로써, 더 나은 사용자 경험과 안정성을 갖출 수 있을 것입니다.

## 1. 주요 흐름 (Key Flows)
*애플리케이션 내에서 사용자가 수행하게 될 3~5가지 핵심 여정을 나열해보세요. 어떤 주요 작업을 하게 될까요?*

- **Content Curation**: 웹 서핑 중 발견한 텍스트, 이미지, 링크를 원클릭으로 수집하고, AI가 자동으로 요약 및 태깅해주는 흐름.
- **Knowledge Management**: 수집된 모든 정보를 통합 검색하고, 폴더와 태그를 이용해 체계적으로 관리하는 흐름.
- **Idea Development**: 수집한 정보들을 메모 에디터로 가져와 통합하고, AI 어시스턴트와 대화하며 새로운 아이디어로 발전시키는 흐름.
- **Team Collaboration**: 팀 워크스페이스에서 동료들과 실시간으로 문서를 공동 편집하고 피드백을 주고받는 흐름.
- **Workspace Personalization**: 사용자가 자신의 작업 스타일에 맞게 레이아웃을 조정하고, 스티커 메모 등 창 관리 기능을 활용하는 흐름.

## 2. 사용자가 방문할 URL/페이지
*주요 페이지의 URL과 해당 페이지의 목적, 접근 권한을 정리하세요*

| Page Name | URL Path | Purpose (페이지 목적) | Access Level (접근 권한) |
|-----------|----------|------------------------|---------------------------|
| Dashboard | `/` | 최근 수집한 정보, 주요 알림, 활동 요약 | User |
| Workspace | `/workspace` | 모든 폴더, 태그, 수집된 콘텐츠를 관리하는 메인 화면 | User |
| Content Detail | `/content/:id` | 개별 콘텐츠(텍스트, 이미지, 링크)의 상세 정보 확인 및 메모 추가 | User |
| Search Results | `/search` | 키워드, 태그, 유의어 기반의 통합 검색 결과 표시 | User |
| Team Workspace | `/team/:workspaceId` | 팀원들과 공유된 콘텐츠를 보고 실시간으로 협업 | Team Member |
| Settings | `/settings` | 계정 정보, 알림, 외부 서비스 연동 등 환경설정 | User |
| Admin | `/admin` | 팀 멤버, 구독 플랜 등 관리 | Admin |
| Login | `/login` | 서비스 로그인 | Public |
| Signup | `/signup` | 신규 사용자 계정 생성 | Public |

## 3. 각 페이지에서 가능한 사용자 행동
*주요 페이지별로 사용자가 할 수 있는 구체적인 액션을 나열해보세요*

### 내 워크스페이스 (`/workspace`)
- 폴더/태그 생성, 이름 변경, 삭제
- 콘텐츠를 폴더로 드래그 앤 드롭하여 정리
- 콘텐츠 목록 보기 (리스트, 그리드, 폭포형 등 뷰 전환)
- 새 메모 생성
- 여러 콘텐츠를 선택하여 일괄적으로 태그 추가 또는 삭제

### 콘텐츠 상세 (`/content/:id`)
- 수집된 콘텐츠의 원본(링크, 이미지 등) 확인
- AI가 생성한 요약 및 키워드 검토 및 수정
- 관련 메모 및 주석 추가
- 콘텐츠에 사용자 정의 태그 추가/삭제
- 콘텐츠를 다른 포맷으로 내보내거나 팀원과 공유

### 팀 워크스페이스 (`/team/:workspaceId`)
- 팀원과 실시간으로 메모 공동 편집
- 특정 콘텐츠나 문단에 댓글을 달아 토론
- 팀 활동 피드 확인
- 팀원 초대 및 권한 관리 (Admin)

### 설정 (`/settings`)
- 프로필 정보 및 비밀번호 변경
- 알림 수신 방법 및 빈도 설정
- 크롬 확장 프로그램 연동 상태 확인
- 구독 플랜 확인 및 변경
- 모든 데이터 내보내기/가져오기

## 4. 사용자 역할 및 권한
*다양한 사용자 유형과 각 역할의 접근 권한 범위를 정의해보세요*

- **Public**: 로그인, 회원가입 페이지 접근 가능.
- **Free User**: 기본적인 수집, 정리, 검색 기능 사용. AI 기능 및 저장 공간에 제한.
- **Pro User**: AI 요약/태깅, 무제한 저장 공간 등 모든 개인 기능에 접근 가능.
- **Team Member**: 초대받은 팀 워크스페이스 내에서 콘텐츠 생성, 편집, 댓글 작성 등 협업 기능 사용 가능.
- **Admin**: 팀원 초대 및 권한 관리, 구독 결제 등 팀에 대한 모든 관리 권한 보유.

## 5. 엣지 케이스 및 오류 처리
*예상 가능한 문제 상황과 그것을 어떻게 처리할 것인지 적어보세요*

- **404 Not Found**: 앱 내에서 유효하지 않은 경로로 이동 시, "페이지를 찾을 수 없습니다" 안내 페이지 표시.
- **403 Forbidden**: 접근 권한이 없는 워크스페이스나 콘텐츠에 접근 시, 권한 부족을 알리는 메시지 표시.
- **Offline Access**: 인터넷 연결이 끊겨도 로컬에 캐시된 데이터는 읽고 쓸 수 있도록 지원하고, 온라인 전환 시 자동으로 동기화.
- **Sync Conflict**: 여러 기기에서 동일한 콘텐츠를 동시에 수정했을 때, 충돌을 감지하고 사용자에게 버전을 선택하거나 병합할 옵션 제공.
- **AI API Error**: AI 요약/태깅 기능 호출 실패 시, 사용자에게 알리고 잠시 후 재시도할 수 있는 버튼 제공.
- **Data Validation**: 회원가입, 설정 등에서 잘못된 형식의 데이터 입력 시, 실시간으로 친절한 오류 메시지 표시.
- **Large Data Handling**: 수천 개 이상의 콘텐츠가 있어도 UI 성능이 저하되지 않도록 가상 스크롤(Virtualization) 기술 적용.
- **Extension Connection Error**: 데스크톱 앱과 크롬 확장 프로그램 간의 연동이 끊겼을 때, 상태를 알리고 재연결을 유도하는 UI 제공.
