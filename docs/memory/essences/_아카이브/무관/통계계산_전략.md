# 통계 계산 전략

중복 없이 효율적으로 TodoList 통계를 계산하고 표시하는 방법

---

## 🎯 핵심 원칙

### Single Source of Truth
```
통계 저장: sessions/{short_id}.md 에만
통계 표시: by-date/{date}.md 에서는 sessions/ 참조해서 계산

→ 중복 저장 없음!
```

---

## 🔧 구현 전략

### 방식 A: 실시간 계산 (권장)

sessions/ 파일에 **데이터만** 저장, 통계는 읽을 때 계산

#### sessions/73f472cd.md
```markdown
# Session: 73f472cd-...
Started: 2025-10-19 04:13:05

## TodoWrite 04:13:05
- ✅ Task 1 (completed)
- 🔄 Task 2 (in_progress)

## TodoWrite 04:16:25
- 📋 Task 3 (pending)
```

**통계 없음!** → 읽을 때 파싱해서 계산

#### by-date/2025-10-19.md
```markdown
<!-- 이 파일 생성 시 sessions/ 파일들을 읽어서 통계 계산 -->

## Daily Summary
- Total Tasks: 17  ← sessions/를 읽어서 계산
- Completed: 4     ← sessions/를 읽어서 계산
```

**장점**:
- ✅ 중복 없음
- ✅ 데이터와 통계 분리
- ✅ 항상 최신 통계

**단점**:
- ⚠️ 읽을 때마다 계산 (약간 느림)

---

### 방식 B: 캐시된 통계

sessions/ 파일 끝에 **통계 섹션** 추가 (주석 또는 메타데이터)

#### sessions/73f472cd.md
```markdown
# Session: 73f472cd-...

## TodoWrite 04:13:05
...

## TodoWrite 04:16:25
...

---

<!-- SESSION_STATS
total_tasks: 7
completed: 1
in_progress: 4
pending: 2
-->
```

또는 YAML 프론트매터:

```markdown
---

stats:
  total_tasks: 7
  completed: 1
  in_progress: 4
  pending: 2

```

**장점**:
- ✅ 빠른 읽기 (파싱 불필요)
- ✅ 한 파일에 모든 정보

**단점**:
- ⚠️ TodoWrite마다 통계 재계산 필요
- ⚠️ 동기화 문제 가능성

## 💡 권장: 하이브리드 방식

### sessions/: 데이터만
```markdown
# Session: 73f472cd-...

## TodoWrite 04:13:05
- ✅ Task 1
- 🔄 Task 2
```

### by-date/: 통계 캐시
```markdown
# TodoList History - 2025-10-19

## Sessions

### 73f472cd - "이전 세션이..."
- Time: 04:13 ~ 04:17
- Tasks: 7 (1✅, 4🔄, 2📋)  ← 캐시

## Daily Summary
- Total: 17 tasks  ← 캐시
```

**작동 방식**:
1. TodoWrite 발생
2. sessions/ 파일에 데이터 추가
3. by-date/ 인덱스의 해당 세션 통계 업데이트
4. by-date/ 전체 통계 재계산

**장점**:
- ✅ sessions/는 깔끔 (데이터만)
- ✅ by-date/는 빠름 (캐시된 통계)
- ✅ 단방향 의존성 (sessions/ → by-date/)

## 🧮 통계 계산 알고리즘

### 세션 통계 계산

```python
def calculate_session_stats(session_file):
    """sessions/{short_id}.md 파일에서 통계 계산"""

    with open(session_file, 'r', encoding='utf-8') as f:
        content = f.read()

    stats = {
        'total_tasks': 0,
        'completed': 0,
        'in_progress': 0,
        'pending': 0,
        'blocked': 0,
        'todowrite_count': 0
    }

    # TodoWrite 섹션 카운트
    stats['todowrite_count'] = content.count('## TodoWrite')

    # 태스크 카운트 (정규식)
    import re

    tasks = re.findall(r'^- [✅🔄📋🚧] .* \((completed|in_progress|pending|blocked)\)', content, re.MULTILINE)

    stats['total_tasks'] = len(tasks)

    for _, status in tasks:
        stats[status] += 1

    return stats

# 사용
stats = calculate_session_stats('sessions/73f472cd.md')
# {
#     'total_tasks': 7,
#     'completed': 1,
#     'in_progress': 4,
#     'pending': 2,
#     'blocked': 0,
#     'todowrite_count': 3
# }
```

### 날짜 통계 계산

```python
def calculate_daily_stats(date):
    """특정 날짜의 모든 세션 통계 합산"""

    import os
    import glob

    # 1. 해당 날짜의 모든 세션 찾기
    date_file = f'by-date/{date}.md'

    if not os.path.exists(date_file):
        return None

    # 2. 파일에서 세션 ID 추출
    session_ids = extract_session_ids_from_date_file(date_file)

    # 3. 각 세션 통계 계산
    daily_stats = {
        'total_sessions': len(session_ids),
        'total_todowrites': 0,
        'total_tasks': 0,
        'completed': 0,
        'in_progress': 0,
        'pending': 0,
        'blocked': 0
    }

    for session_id in session_ids:
        session_file = f'sessions/{session_id}.md'
        if os.path.exists(session_file):
            stats = calculate_session_stats(session_file)

            daily_stats['total_todowrites'] += stats['todowrite_count']
            daily_stats['total_tasks'] += stats['total_tasks']
            daily_stats['completed'] += stats['completed']
            daily_stats['in_progress'] += stats['in_progress']
            daily_stats['pending'] += stats['pending']
            daily_stats['blocked'] += stats['blocked']

    return daily_stats
```

## 🔄 업데이트 흐름

### TodoWrite 발생 시

```
1. sessions/{short_id}.md 업데이트
   - 새 TodoWrite 섹션 추가
   - 통계는 계산하지 않음

2. 세션 통계 계산
   - calculate_session_stats() 실행
   - 결과 저장 (변수)

3. by-date/{date}.md 업데이트
   - 해당 세션 통계 업데이트
   - 일일 통계 재계산
   - 파일에 쓰기

→ sessions/는 변경 적음 (데이터만)
→ by-date/는 자주 변경 (통계 재계산)
```

## ⚡ 성능 최적화

### 1. 캐싱 전략
```python
# by-date/ 파일에 통계 캐시
# sessions/ 파일 변경 시에만 재계산

def need_recalculation(session_file, cache_time):
    """재계산 필요 여부 판단"""
    import os
    session_mtime = os.path.getmtime(session_file)
    return session_mtime > cache_time
```

### 2. 증분 업데이트
```python
# 전체 재계산 대신 증분 업데이트
def update_stats_incrementally(old_stats, new_tasks):
    """새 태스크만 추가해서 통계 업데이트"""
    for task in new_tasks:
        old_stats['total_tasks'] += 1
        old_stats[task['status']] += 1
    return old_stats
```

## 📚 참고 구현

### Sub-Agent에서 사용

```markdown
## Record TodoWrite

1. Append to sessions/{short_id}.md
2. Calculate new session stats
3. Update by-date/{date}.md with cached stats
4. Return confirmation

**통계 저장 위치**:
- sessions/: 없음 (데이터만)
- by-date/: 캐시 (빠른 접근)

**통계 계산 시점**:
- TodoWrite 추가 직후
- by-date/ 업데이트 시
```

## 🎯 최종 권장 사항

### ✅ DO
- sessions/에는 순수 데이터만 저장
- by-date/에 통계 캐시
- 통계는 sessions/에서 계산

### ❌ DON'T
- sessions/에 통계 중복 저장
- 통계를 수동으로 업데이트
- 오래된 캐시 사용 (항상 재계산)
