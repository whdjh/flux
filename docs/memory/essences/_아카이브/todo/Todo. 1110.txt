### Core Documentation Philosophy
- **"달랑" 원칙**: 핵심만 담기, 불필요한 설명 배제
- **단일 책임**: 한 문서 = 하나의 명확한 목적
- **빠른 참조 우선**: 스캔 가능한 구조 (코드 블록, 리스트, 트리)
- **계층적 문서화**: 간단한 docs (실무용) + 상세 문서 (학습용) 분리
- **한글 파일명**: 접근성과 명확성 (배포.md, 개요.md, 구조.md, 흐름.md)
- **실용성 우선**: 복사-붙여넣기 가능, 즉시 사용 가능하게
