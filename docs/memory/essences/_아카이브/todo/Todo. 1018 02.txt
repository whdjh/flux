**"생애주기 개인 건강 반려 데이터"**

---

### 제품 정체성
**"워치 데이터로 건강 위험을 예측하고, 오늘 할 일 1가지를 제안하는 AI 코치"**

핵심 가치: 측정 → 의미 해석 → 구체적 행동 1가지

---

### 타겟
**40-60대 중장년층**
- 만성 건강 이슈 보유자
- 스마트워치 착용 가능
- 예방적 관리 원함

---

### 범위 (워치 데이터 기반)
- 편두통 전조
- 수면 장애 (무호흡, 불면)
- 스트레스/번아웃
- 심혈관 이상
- 저혈당 위험
- 과부하 상태

---

### 데이터 수집

**워치 (필수, 자동)**
- HRV (심박 변동성)
- 심박수 (안정/활동)
- 수면 (REM, 깊은/얕은, 효율, 무호흡)
- 활동량, 걸음수
- 스트레스 지수
- 산소포화도
- 혈당 (CGM 있으면)

**수동 입력**
- 증상 기록 (두통, 어지러움 등)
- 복약 기록
- 음식/카페인 섭취

**선택**
- 캘린더 일정
- (확장) 건강보험심평원 처방 데이터

### Agent 시스템 (5개)

**1. Pattern Agent - 데이터 탐정**
```
역할: 이상 패턴 감지
입력: 워치 데이터 + 기준선
처리: 
  - 단일 이상 감지 (HRV ≤ P10)
  - 조합 패턴 분석 (HRV↓ + RHR↑ + 수면↓)
  - 위험도 계산
출력: {risk_level, patterns, confidence, explanation}
트리거: 실시간 + 매일 새벽
```

**2. Goal Setting Agent - 목표 기획자**
```
역할: 개선 우선순위 및 목표 제안
입력: Pattern 분석 + 사용자 이력
처리:
  - 여러 이슈 중 우선순위 판단
  - 현실적 목표 계산
  - 단계별 로드맵
출력: {priority_issues, suggested_goal, timeline}
트리거: 2주 후 + 월 1회 + 목표 달성 시
```

**3. Coaching Agent - 트레이너**
```
역할: 오늘 할 일 제안
입력: Pattern 결과 + Goal + 현재 퀘스트
처리:
  - 위험 수준별 조정
  - 구체적 행동 1가지
  - 격려 메시지
출력: {today_action, adjustment, quest}
예: "카페인 15시 이후 금지", "30분 산책"
트리거: 위험 감지 시 + 매일 아침
```

**4. Chat Agent - 대화 상대**
```
역할: 자연어 대화 + Agent 조율
입력: 사용자 메시지 + 대화 히스토리
처리:
  - 의도 파악
  - 적절한 Agent 호출
  - 답변 생성
출력: 텍스트/음성 답변
트리거: 사용자 메시지
```

**5. Medical Context Agent - 의학 자문**
```
역할: 약물/증상 의학 판단
입력: 약물 정보 + 증상 + 일정
처리:
  - 약물 DB 조회
  - 상호작용/금기사항 체크
  - 증상 심각도 판단
출력: {drug_interaction, symptom_assessment}
트리거: 복약 입력 시 + 증상 입력 시
```

### Agent 협업 플로우

**케이스 1: 편두통 전조 감지**
```
[Pattern Agent]
HRV 25 (P10 이하) + RHR 95 (P90 이상)
→ "편두통 전조 위험 85%"

[Goal Setting Agent]
"이번 주 목표: 카페인 조절"

[Coaching Agent]
"오늘 할 일: 카페인 15시 이후 금지"

[알림 발송]
사용자 실천 → 24h 후 두통 없음
→ "전조 회피 성공 +1"
```

**케이스 2: 약물 경고**
```
사용자: 복약 기록 입력

[Medical Context Agent]
"졸피뎀 + 내일 프리다이빙 일정"
→ "중추신경계 위험"

[Coaching Agent]
"오늘 졸피뎀 금지, 일찍 취침"

[Chat Agent] (추가 질문 시)
"왜 위험해요?" → 설명
```

**케이스 3: 목표 설정 대화**
```
사용자: "건강 목표 세우고 싶어요"

[Chat Agent] → [Goal Setting Agent] 호출

[Goal Setting Agent]
데이터 분석 → "수면(우선) vs 활동량(중간)"
→ "수면 개선 추천"

[Chat Agent]
"데이터 보니 수면 개선이 효과적입니다.
 4주 목표로 수면 효율 85% 어떠세요?"

사용자: "네"

[Goal Setting Agent] → [Coaching Agent]
"1주차: 취침 시간 고정"
→ "오늘부터 밤 11시 취침"
```

### 차별점

**vs 일반 헬스앱**
- AI 개인 패턴 학습
- 전조 예측 (사후 아님)
- 오늘 할 일 1가지 (명확함)

**vs 워치 앱**
- 의미 해석 (숫자 → 이해)
- 구체적 행동 제안

**vs 병원**
- 일상 맥락 + 실시간
- 즉시 피드백
- 예방 중심

**핵심:** "측정 → 의미 → 행동"

## UI 원칙

**1. 단순함 (40-60대)**
- 큰 글씨
- 명확한 버튼
- 최소 스크롤

**2. 핵심 우선**
- 오늘 할 일 가장 위
- 3번 탭 이내 접근
- 중요 정보만

**3. 시각적 명확성**
- 이모지 활용 (⚠️✅🎯)
- 색상 코딩 (빨강=위험, 초록=정상)
- 그래프 단순

**4. 즉시 피드백**
- 완료 버튼 → 즉시 칭찬
- 입력 → 즉시 분석
- 질문 → 빠른 답변
