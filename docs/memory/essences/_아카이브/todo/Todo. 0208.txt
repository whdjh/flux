The user is asking whether the remote swap approach will result in a clean transition. Let me think about this honestly.

The issue is: the two repos (hackathon-claude-sync and dotclaude) have completely different git histories. When we do git fetch origin (the new dotclaude remote) and then git checkout -b main origin/main --force, we'll get the dotclaude files, but:

Any tracked files from hackathon-claude-sync that aren't in dotclaude will remain as untracked files
The git history will be completely different
There might be leftover files from the old repo
So it's NOT as clean as rm + clone.

The real problem is that untracked files from the old repo will stick around and clutter things. I could use git clean -fd to remove them, but that's risky since it might delete runtime data I want to keep—though ideally that stuff should be in .gitignore anyway.

Actually, the safest approach is probably to back up the runtime data first, then do a hard reset to the new remote and clean up untracked files, then restore the data. But honestly, the user's instinct about just removing and cloning fresh might be the cleanest solution after all. Let me think through the actual tradeoffs here.

The real issue with rm + clone during an active session is that Claude Code might try to read or write to ~/.claude while it's being replaced—config files are mostly loaded into memory, but things like todos or session data could cause problems if the directory vanishes mid-operation. I should be straightforward about these limitations rather than overselling the remote swap approach.

# dotclaude Migration Plan (WSL)

## Context

현재 `~/.claude`가 `hackathon-claude-sync` repo(branch: windows)로 관리 중.
`junyjeon/dotclaude` repo(branch: main)로 교체하되, 런타임 데이터를 보존해야 함.

## 방식: rm + clone 스크립트

이 세션에서 마이그레이션 스크립트를 생성 → 세션 종료 → 별도 터미널에서 실행.

## 보존할 런타임 데이터

- projects/ (209MB) - 세션 데이터
- todos/ (1.4MB) - 할일 상태
- statsig/ (44KB) - 통계
- plugins/ (62MB) - 설치된 플러그인 + 마켓플레이스
- file-history/ (6MB) - 파일 변경 이력
- credentials/ + .credentials.json - 인증 정보
- history.jsonl - 명령 히스토리
- debug/ - 디버그 로그

## 스크립트 내용 (`/tmp/migrate-dotclaude.sh`)

```bash
#!/bin/bash
set -euo pipefail

BACKUP_DIR="/tmp/claude-backup-$(date +%Y%m%d%H%M%S)"
TARGET="$HOME/.claude"

echo "=== Step 1: 런타임 데이터 백업 ==="
mkdir -p "$BACKUP_DIR"
for dir in projects todos statsig plugins file-history credentials debug; do
  [ -d "$TARGET/$dir" ] && cp -r "$TARGET/$dir" "$BACKUP_DIR/"
done
[ -f "$TARGET/.credentials.json" ] && cp "$TARGET/.credentials.json" "$BACKUP_DIR/"
[ -f "$TARGET/history.jsonl" ] && cp "$TARGET/history.jsonl" "$BACKUP_DIR/"
echo "백업 완료: $BACKUP_DIR"

echo "=== Step 2: ~/.claude 제거 및 clone ==="
rm -rf "$TARGET"
git clone https://github.com/junyjeon/dotclaude.git "$TARGET"
echo "Clone 완료"

echo "=== Step 3: 런타임 데이터 복원 ==="
for dir in projects todos statsig plugins file-history credentials debug; do
  [ -d "$BACKUP_DIR/$dir" ] && cp -r "$BACKUP_DIR/$dir" "$TARGET/"
done
[ -f "$BACKUP_DIR/.credentials.json" ] && cp "$BACKUP_DIR/.credentials.json" "$TARGET/"
[ -f "$BACKUP_DIR/history.jsonl" ] && cp "$BACKUP_DIR/history.jsonl" "$TARGET/"
echo "복원 완료"

echo "=== Step 4: 플러그인 설치 ==="
claude plugin marketplace add https://github.com/anthropics/everything-claude-code
claude plugin install everything-claude-code@everything-claude-code
echo "플러그인 설치 완료 (mgrep은 plugins/ 복원으로 유지됨)"

echo "=== Step 5: 사운드 테스트 ==="
if [ -f "$TARGET/scripts/play-sound.js" ]; then
  node "$TARGET/scripts/play-sound.js" done
  echo "사운드 테스트 실행됨 (소리가 들리면 정상)"
else
  echo "⚠ play-sound.js가 dotclaude repo에 없음. 확인 필요"
fi

echo "=== 검증 ==="
echo "Remote: $(git -C "$TARGET" remote -v | head -1)"
echo "Branch: $(git -C "$TARGET" branch --show-current)"
echo "Projects: $(ls "$TARGET/projects/" 2>/dev/null | wc -l) dirs"
echo "Plugins: $(ls "$TARGET/plugins/installed_plugins.json" 2>/dev/null && echo 'OK' || echo 'MISSING')"

echo ""
echo "=== 완료 ==="
echo "백업 위치: $BACKUP_DIR"
echo "문제 발생 시: cp -r $BACKUP_DIR/* $TARGET/ 로 복구"
```

## 실행 방법

1. 이 세션에서 스크립트 생성: `/tmp/migrate-dotclaude.sh`
2. 이 세션 종료 (`exit` 또는 Ctrl+C)
3. 별도 터미널에서:
   ```
   chmod +x /tmp/migrate-dotclaude.sh
   /tmp/migrate-dotclaude.sh
   ```
4. 새 claude 세션 시작하여 확인
