요청하신 기능을 모두 구현했습니다.

1. 의류 이미지 AI 인식으로 상품명 자동 생성
2. 창의적 작명 (기존 나열식과 차별화)
- 나쁜 예: "블랙 스트라이프 유니클로 면혼방 맨투맨"
- 좋은 예: "유니클로 어반 시크 보더 스웨트"
3. 중복 방지 (여러 번 시도해도 과거 이름과 겹치지 않게)
- 예: "아디다스 레드 카라티" → "아디다스 빨강 피케셔츠" → "아디다스 빅로고 딥레드 카라티셔츠"
4. 객관적 데이터 활용 (이미지로 인식 불가능한 브랜드, 소재, 사이즈 정보)
5. 의류 라벨 OCR (세부컷 최하단 라벨 자동 인식)
---

흐름은 이렇습니다.
1. 이미지와 엑셀 데이터를 결합해서 상품명을 생성합니다.
이미지를 분석해서 상품의 외관과 특징을 파악합니다. 하단 라벨 영역을 자동으로 잘라서 소재, 혼용률 정보를 OCR로 읽습니다. 엑셀 데이터(브랜드, 카테고리, 색상, 소재, 패턴)와 이미지 분석을 결합해서 AI가 상품명을 생성합니다. 성별/계절 정보로 작명 스타일을 조절합니다(남성용은 모던/시크 톤, 여성용은 페미닌/소프트 톤). 같은 상품을 여러 마켓에 올릴 수 있도록 한 상품당 여러 개의 다른 이름을 만들 수 있습니다.

2. 기존 상품명과 중복을 피합니다.
과거 생성한 모든 상품이름을 Google Sheets에 저장해서 AI가 새로 만든 이름과 비교합니다. 중복이면 자동으로 다른 이름을 만듭니다. 재시도 횟수는 기본 3회이며 1-5회로 조정 가능합니다. Google Sheets 연동은 중복 데이터 기록을 위해 사용됩니다.
