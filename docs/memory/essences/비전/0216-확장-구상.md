# 확장 구상

현재 핵심 기능(수집 → 정리 → 메모)을 먼저 만들고, 이후 확장할 방향 두 가지.


## 확장 1: 큐레이션 NFT

수집물을 블록체인으로 관리하고 NFT로 거래한다.

거래 대상은 개별 Item이 아니라 큐레이션된 컬렉션(Document) 전체다. 단순히 수집만 한 게 아니다. 수집하고, 메모를 더하고, 정리하고, AI와 함께 분석하고, 자기만의 관점을 얹은 결과물이다. 이 과정 전체가 가치다.

```
Document (큐레이션 컬렉션)
  ├─ 직접 쓴 코멘터리, 분석, 메모  ← 원본 콘텐츠
  ├─ ItemEmbed: 수집한 이미지       ← 큐레이션 (선별 + 배치 + 맥락)
  ├─ ItemEmbed: 수집한 링크         ← 큐레이션
  ├─ ItemEmbed: 스크린샷            ← 원본 콘텐츠
  └─ AI 요약, 키워드                ← AI 협업 결과
```

NFT가 증명하는 건 "이 조합을 이 사람이 이 시점에 만들었다"는 사실이다. 개별 콘텐츠의 저작권이 아니라, 선별 + 배치 + 코멘터리 + AI 분석이라는 큐레이션 행위에 대한 소유권이다.

민팅 흐름:

```
Document 스냅샷 (loro CRDT state, deterministic)
  → SHA-256 해시 → on-chain (소유권 증명)
  → 원본 콘텐츠 → IPFS/Arweave (영구 저장)
  → 외부 참조 → 메타데이터에 포인터만
```

loro CRDT의 결정적 상태가 변조 증명에 유리하다. 현재 아키텍처 변경 없이 "내보내기" 모듈로 붙일 수 있다. 블록체인 선택(Solana, Base 등)은 추후 결정.


## 확장 2: 수집물 공유 플랫폼

큐레이션된 컬렉션을 다른 사용자에게 공유하는 플랫폼. NFT 거래와 별개로, 공유 자체만으로도 가치가 있다. 디자이너의 영감 보드, 연구자의 리서치 모음, 기획자의 레퍼런스 컬렉션 등.

구체적인 형태는 추후 결정.
