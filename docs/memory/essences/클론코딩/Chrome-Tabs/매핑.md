## 핵심 차이점

### 허용되는 차이

1. **구현 언어**: C++ vs TypeScript
2. **플랫폼 API**: Windows API vs Web API
3. **상태 관리**: Observer 패턴 vs React state
4. **가변 너비**: 직접 계산 vs Flexbox

### 허용 안 되는 차이

1. **타이밍 변경**: 167ms, 200ms 값 반드시 동일
2. **Opacity 미사용**: Chrome처럼 opacity 없이 width만 애니메이션
3. **간격 문제**: 탭 추가 시 간격 없이 즉시 나타남
