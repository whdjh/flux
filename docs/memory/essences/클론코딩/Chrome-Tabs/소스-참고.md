# Chrome 소스코드 참고

> Chrome 탭 시스템의 실제 C++ 구현. 정확한 클론코딩을 위한 참고 자료.

## 드롭 인덱스 계산

**파일**: `chrome/browser/ui/views/tabs/tab_drag_controller.cc`

```cpp
// MoveAttached() 메서드에서 호출
int to_index = attached_context_->GetInsertionIndexForDraggedBounds(
    GetDraggedViewTabStripBounds(dragged_view_point),
    GetViewsMatchingDraggedContents(attached_context_),
    num_dragging_tabs(),
    group_);

// 인덱스 조정 로직
// 같은 tabstrip 내에서 이동할 때, 드래그된 탭이 배열에서 차지하는 위치를 고려
if (min_distance_index > first_dragged_tab_index) {
  min_distance_index -= num_dragged_tabs;
}
```

**핵심 알고리즘** (`GetInsertionIndexForDraggedBounds`):
1. 모든 가능한 삽입 위치 순회
2. 각 위치에서 `CalculateIdealX()` - 이상적인 x 좌표 계산
3. 현재 드래그 bounds의 x와 비교해서 거리 계산
4. 거리가 가장 작은 위치 선택
5. 드래그된 탭 인덱스보다 크면 `index -= num_dragged_tabs` 조정

## 탭 애니메이션

**파일**: `chrome/browser/ui/views/tabs/tab.cc`

```cpp
// Chrome은 bounds 애니메이션 사용 (width/height 직접 변경)
// opacity나 scale 변환 없음

// Layout() 메서드에서 구동
if (title_bounds != target_title_bounds_) {
  target_title_bounds_ = title_bounds;
  title_animation_.Start();
}

// 애니메이션 보간
gfx::Tween::RectValueBetween(
  value,
  start_title_bounds_,
  target_title_bounds_
);
```

**핵심**:
- Bounds 기반 (position + size)
- Layout 재계산으로 구동
- Opacity/Scale 사용 안 함
- `gfx::Tween::RectValueBetween`로 rect 보간

## 탭 스트립 애니메이션

**파일**: `chrome/browser/ui/views/tabs/tab_strip.cc`

탭 추가/제거 시 전체 레이아웃 재계산으로 애니메이션 발생.

## 웹 구현 전략

Chrome의 C++ bounds 애니메이션을 Web Animations API로 어떻게 매핑할지:

1. **Width 애니메이션**: `animate([{ width: '0px' }, { width: 'auto' }])`
2. **인덱스 조정**: `if (dropIndex > draggedIndex) dropIndex -= 1`
3. **거리 최소화**: 모든 탭 위치 계산 후 최소 거리 선택
