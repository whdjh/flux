# 클론 코딩 차이점

Chrome 브라우저와 우리 구현의 차이점을 추적하는 문서.

## 차이점 분류

### 허용 가능 (플랫폼 차이)

언어나 플랫폼 차이로 인한 불가피한 차이. 사용자 경험에 영향 없음.

| 항목 | Chrome | 우리 구현 | 이유 |
|-----|--------|----------|------|
| 언어 | C++ | TypeScript | 플랫폼 차이 |
| UI 프레임워크 | Views (Chromium) | React | Web 기술 스택 |
| 상태 관리 | Observer 패턴 | React state | React 방식 |
| 렌더링 | 직접 DOM 조작 | Virtual DOM | React 최적화 |
| 가변 너비 | C++에서 계산 | CSS Flexbox | Web의 자연스러운 방법 |
| GPU 가속 | 직접 제어 | 브라우저 자동 | 추상화 레벨 차이 |

**판단 기준**: 사용자가 Chrome과 구별할 수 없으면 허용.

### 허용 불가능 (동작 차이)

사용자 경험에 영향을 주는 차이. 즉시 수정 필요.

**현재 상태**: ✅ 모두 해결됨

#### 과거 문제 (해결됨)

1. **Opacity 사용 문제** [해결: 2024-01-XX]
   - 문제: 탭 애니메이션에 opacity 추가
   - Chrome: opacity 사용 안 함
   - 영향: 탭 추가 시 간격 발생
   - 해결: opacity 완전 제거, width만 애니메이션

2. **Index 조정 버그** [해결: 2024-01-XX]
   - 문제: `calculatedIndex -= 1` 로직 누락
   - Chrome: 드래그된 탭 제거 고려
   - 영향: 드롭 위치 부정확
   - 해결: Chrome 알고리즘 정확히 구현

3. **고정 너비 문제** [해결: 2024-01-XX]
   - 문제: 탭 너비가 픽셀로 고정
   - Chrome: 가변 너비 시스템
   - 영향: 탭이 공간을 나눠가지지 못함
   - 해결: flexGrow 애니메이션으로 전환

4. **"모든 탭 닫기" 버튼 오작동** [해결: 2024-01-XX]
   - 문제: DOM 클릭 이벤트 시뮬레이션 실패
   - 영향: 버튼이 동작하지 않음
   - 해결: ref.closeTab() 직접 호출

### 판단 필요 (팀 논의)

**현재 상태**: 없음

## 미구현 기능

Chrome에는 있지만 우리는 아직 구현하지 않은 기능.

### 1. 여러 탭 동시 드래그
- Chrome: Ctrl+클릭으로 여러 탭 선택 → 드래그
- 우리: 탭 1개만 드래그 가능
- 우선순위: 낮음 (기본 기능 완성 우선)

### 2. 탭 그룹
- Chrome: 탭을 그룹으로 묶기, 색상 지정
- 우리: CSS만 정의됨, 기능 없음
- 우선순위: 중간

### 3. 고정 탭
- Chrome: 탭을 고정해서 왼쪽에 작게 표시
- 우리: CSS만 정의됨, 기능 없음
- 우선순위: 중간

### 4. 탭을 새 창으로 분리
- Chrome: 탭을 창 밖으로 드래그 → 새 창 생성
- 우리: 미구현
- 우선순위: 낮음 (Electron 통합 필요)

### 5. 탭 미리보기
- Chrome: 탭에 마우스 오버 → 미리보기 팝업
- 우리: 미구현
- 우선순위: 낮음
