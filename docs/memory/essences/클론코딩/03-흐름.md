# 흐름

## 기본 워크플로우

리서치 워크플로우는 5단계로 진행된다.

```
수집 → 검토 → 통합 → 정제 → 발상
  ↓      ↓      ↓      ↓      ↓
Inbox  폴더   분할   메모   AI 어시스턴트
```

수집은 Alt+우클릭이나 드래그앤드롭으로 한다. 검토는 4가지 뷰(폭포/양쪽/그리드/목록)로 본다. 통합은 좌우 분할로 레퍼런스와 메모를 나란히 둔다. 정제는 드래그앤드롭으로 핵심 정보를 추출한다. 발상은 AI 어시스턴트로 아이디어를 확장한다.

## 데이터 흐름

### 수집 플로우

```
브라우저 (Alt+우클릭)
    ↓
확장 프로그램 (콘텐츠 추출)
    ↓
로컬 서버 (IPC 통신)
    ↓
Main Process (파일 저장)
    ↓
Renderer Process (UI 업데이트)
    ↓
Supabase (클라우드 동기화)
```

확장 프로그램은 웹 페이지에서 텍스트, 이미지, 링크, 동영상을 추출한다. 메타데이터는 제목, URL, 파비콘, 생성일을 포함한다. 로컬 서버는 8080 포트로 확장과 앱을 연결한다.

Main Process는 파일을 로컬 디렉토리에 저장한다. 이미지는 public/captures/, 메타는 data/items.json에 둔다. Renderer는 새 아이템을 Inbox에 추가한다. Supabase는 비동기로 동기화한다.

### AI 처리 플로우

```
아이템 수집
    ↓
메타 추출 (병렬)
    ↓
Openrouter API 호출
    ↓
요약(1-3줄) + 키워드(3개) 생성
    ↓
메타데이터 저장
    ↓
UI 업데이트 (200ms 후)
```

AI 처리는 병렬로 실행한다. 사용자 UX를 막지 않는다. 요약 실패 시 원본 텍스트 첫 100자를 대체로 쓴다. 타임아웃은 5초다.

### 검색 플로우

```
사용자 쿼리 입력
    ↓
디바운스 (150ms)
    ↓
Elasticsearch-rs 호출
    ↓
유의어 확장 + 의미 검색
    ↓
결과 정렬 (관련도순)
    ↓
하이라이트 렌더링
```

검색 대상은 제목, 본문, AI 요약, 키워드다. 유의어 확장은 Elasticsearch synonym filter를 쓴다. 의미 검색은 벡터 임베딩 기반이다. 오프라인 시 로컬 인덱스만 검색한다.

## 사용자 여정

### 시나리오: 디자인 리서치

Jina는 온보딩 UI 레퍼런스를 수집한다.

```
1. 웹서핑 중 발견
   ↓
2. Alt+우클릭으로 수집
   ↓
3. Inbox에서 '온보딩 프로젝트' 폴더로 이동
   ↓
4. 폴더를 기본 수집 위치로 설정
   ↓
5. 추가 자료 자동 저장
```

이제 아이디어를 정리한다.

```
6. 폴더 열기 + 화면 분할 (레퍼런스 | 메모)
   ↓
7. 이미지 2-3개를 메모로 드래그앤드롭
   ↓
8. 슬래시(/) 커맨드로 체크리스트 추가
   ↓
9. AI에게 "성공적인 온보딩 UI 원칙은?" 질문
   ↓
10. AI 답변을 메모에 통합
```

며칠 후 회의 준비를 한다.

```
11. '온보딩' 검색
    ↓
12. 이전 메모 즉시 발견
    ↓
13. 회의 자료로 활용
```

## 상태 흐름

### 아이템 상태

```
수집됨 → 분류됨 → 정제됨 → 완료됨
  ↓       ↓        ↓        ↓
Inbox   Folder   Memo    Archive
```

아이템은 4가지 상태를 거친다. 수집됨은 Inbox에 있는 상태다. 분류됨은 폴더로 이동한 상태다. 정제됨은 메모에 통합된 상태다. 완료됨은 Archive로 옮긴 상태다.

### UI 상태 전이

```
기본 레이아웃
    ↓ (창 분할)
분할 레이아웃 (2-4분할)
    ↓ (포스트잇 버튼)
포스트잇 모드 (독립 창)
    ↓ (맨 앞 고정)
오버레이 모드 (Always on Top)
```

레이아웃은 동적으로 전환된다. 분할은 1/2, 1/3, 1/4 프리셋을 제공한다. 포스트잇은 Liquid Glass UI로 투명하다. 오버레이는 웹서핑 중에도 보인다.

### 협업 상태

```
개인 모드
    ↓ (공유 링크 생성)
협업 모드 (읽기 전용)
    ↓ (편집 권한 부여)
동시 편집 모드
    ↓ (라이브 커서 + 채팅)
실시간 협업
```

협업은 Supabase Realtime으로 구현한다. 라이브 커서는 색상과 이니셜로 구분한다. 충돌은 타임스탬프 우선으로 해결한다.
