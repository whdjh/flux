# 설계

## 프로젝트 개요

웹 서핑 중 발견한 정보를 단축키 하나로 수집하고, AI가 자동으로 분류 및 요약하며, 이를 바탕으로 아이디어를 발전시킬 수 있는 통합 작업 공간이다.

현재 지식 노동자들은 정보 과부하와 싸우고 있다. 북마크, 카카오톡, 다운로드 폴더, 스크린샷이 여기저기 흩어져 있고, 이전에 찾은 정보를 다시 찾는 데 많은 시간을 낭비한다. 기존 도구들은 각자의 영역에서는 훌륭하지만 수집부터 정리, 아이디어 발상까지 전체 과정을 하나의 플랫폼에서 끊김 없이 지원하지 못한다. 이 도구는 그 간극을 메운다.

## 기술 스택

- TailwindCSS

- Lucide + Icones (아이콘)

백엔드:
- Supabase (PostgreSQL, Auth, Realtime)

- Elasticsearch-rs (유의어 검색)

에디터:
- Monaco Editor (VSCode 엔진)

AI:
- Openrouter (모델 선택)
- Elevenlabs React SDK (TTS/STT)
- MCP (Model Context Protocol)

배포:
- Netlify (정적 호스팅)

## 아키텍처

시스템은 3계층으로 구성된다.

```
┌────────────────────────────────────────┐
│         Presentation Layer             │
│  - 3-Panel Layout (336px/content/336px) │
│  - Tabs, Split Views                   │
│  - Monaco Editor (3곳 공유)             │
└──────────────┬─────────────────────────┘
               │ IPC (preload)
┌──────────────▼─────────────────────────┐
│          Application Layer             │
│  - Electron Main Process               │
│  - File System Operations              │
│  - Local Server (Extension ↔ App)     │
└──────────────┬─────────────────────────┘
               │ Network
┌──────────────▼─────────────────────────┐
│            Data Layer                  │
│  - Supabase (PostgreSQL + Realtime)   │
│  - Elasticsearch-rs (Search Index)     │
│  - Local Storage (SQLite?)             │
└────────────────────────────────────────┘
```

### 3-Panel 레이아웃

VSCode 스타일의 레이아웃을 따른다.

- 좌측 사이드바 (336px): 폴더 트리, Inbox, Projects, Tags
- 메인 콘텐츠: 분할 뷰 지원 (1/2/3/4분할), 탭 시스템
- 우측 패널 (336px): 메모 또는 AI 어시스턴트

리사이즈 가능하고, 좁은 폭에서는 오버레이로 전환된다. Shadcn의 Resizable 컴포넌트를 쓴다.

### IPC 통신

Type-safe IPC로 Main Process와 Renderer Process를 연결한다.

계층:
1. Renderer → Preload (contextBridge)
2. Preload → Main (ipcMain/ipcRenderer)
3. Main → File System / Network

보안:
- contextIsolation: true
- nodeIntegration: false
- 화이트리스트 기반 IPC 채널

### 데이터 흐름

수집 → 저장 → 인덱싱 → 검색

1. 수집: 브라우저 확장프로그램 → 로컬 서버 → Electron App
2. 저장: Supabase PostgreSQL (메타데이터 + AI 요약)
3. 인덱싱: Elasticsearch-rs (제목, 본문, AI 요약, 키워드)
4. 검색: Elasticsearch-rs (유의어 포함) + Supabase (필터링)

## 설계 원칙

### 사용자 중심

사용자 경험이 최우선이다. 직관적인 UI로 학습 곡선을 최소화한다. 사용자의 작업 흐름(웹서핑)을 방해하지 않는 설계가 핵심이다. 사용자의 뇌와 손의 에너지를 아껴주며 시간을 절약해주는 설계를 추구한다.

### 최소 에너지, 최대 효과

최소한의 에너지로 최대한의 정리 효과를 얻는 것이 목표다. AI가 예측 가능하게 분류하고 프라이버시를 보장한다. 협업 기능으로 팀 작업까지 확장한다.

### 전환 비용 제거

모든 정보를 한 곳에서 관리한다. 앱 전환 없이 수집, 정리, 메모, 검색, AI 대화를 할 수 있다. 투명 UI(Liquid Glass)로 다른 작업과 자연스럽게 어우러진다.

## 보안

### 로컬 서버

브라우저 확장프로그램과 Electron App은 로컬 서버를 통해 통신한다. 외부 노출 없이 안전하다.

### Supabase

Row Level Security (RLS)로 사용자 데이터를 격리한다. 인증된 사용자만 자신의 데이터에 접근할 수 있다.

### IPC

contextIsolation과 화이트리스트 기반 IPC로 XSS와 code injection을 방지한다.
