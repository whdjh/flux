# 환경설정

## 환경변수

### `.env.example`

```bash
# Database
DATABASE_URL="postgresql://postgres:[PASSWORD]@db.[PROJECT_ID].supabase.co:5432/postgres"

# Supabase (Renderer에서 사용)
VITE_SUPABASE_URL="https://[PROJECT_ID].supabase.co"
VITE_SUPABASE_ANON_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# API Keys (선택)
VITE_API_KEY=""

# Development
NODE_ENV="development"
```

### 환경변수 설명

DATABASE_URL은 Drizzle ORM이 DB 연결에 사용한다. Main 프로세스에서만 접근 가능하다. Supabase Dashboard → Settings → Database → Connection String에서 확인할 수 있다.

VITE_SUPABASE_URL은 Supabase 프로젝트 URL이다. Renderer 프로세스에서 `import.meta.env.VITE_SUPABASE_URL`로 접근한다. `VITE_` 접두사가 필수다. Vite가 Renderer에 노출하기 때문이다.

VITE_SUPABASE_ANON_KEY는 Supabase 익명 키다. 공개 키이고, Row Level Security (RLS) 정책이 적용된다. Supabase Dashboard → Settings → API → anon public에서 확인할 수 있다.

NODE_ENV는 `development`, `production`, `test` 중 하나다. 자동 설정되지만 명시적으로 지정할 수 있다.

### 환경변수 로드

```typescript
// Main 프로세스
import dotenv from 'dotenv';
dotenv.config();

const databaseUrl = process.env.DATABASE_URL;

// Renderer 프로세스
const supabaseUrl = import.meta.env.VITE_SUPABASE_URL;
```

## Vite 설정

### 3개 설정 파일 구조

```
vite.main.config.ts      → Main 프로세스 (Node.js)
vite.preload.config.ts   → Preload 스크립트 (Bridge)
vite.renderer.config.ts  → Renderer 프로세스 (React)
```

### Main 프로세스 설정

**파일**: `vite.main.config.ts`

```typescript
import { defineConfig } from 'vite';
import { resolve } from 'path';

export default defineConfig({
  build: {
    lib: {
      entry: resolve(__dirname, 'src/main/index.ts'),
      formats: ['cjs']
    },
    rollupOptions: {
      external: [
        'electron',
        'fs',
        'path',
        ...builtinModules
      ]
    }
  },
  resolve: {
    alias: {
      '@main': resolve(__dirname, 'src/main'),
      '@backend': resolve(__dirname, 'src/backend')
    }
  }
});
```

Node.js 환경에서 실행되고 CommonJS 포맷을 사용한다. Electron과 Node 내장 모듈은 External로 제외한다.

### Preload 설정

**파일**: `vite.preload.config.ts`

```typescript
export default defineConfig({
  build: {
    lib: {
      entry: resolve(__dirname, 'src/preload/index.ts'),
      formats: ['cjs']
    },
    rollupOptions: {
      external: ['electron']
    }
  }
});
```

보안을 위해 contextBridge와 ipcRenderer만 사용한다. 최소한의 코드로 구성한다.

### Renderer 설정

**파일**: `vite.renderer.config.ts`

```typescript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { resolve } from 'path';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
      '@/shared': resolve(__dirname, 'src/shared'),
      '@/features': resolve(__dirname, 'src/features'),
      '@/app': resolve(__dirname, 'src/app')
    }
  },
  server: {
    port: 3000
  }
});
```

React 플러그인을 사용하고 Path Alias를 설정한다. Hot Module Replacement (HMR)를 지원한다.

## Electron Forge 설정

**파일**: `forge.config.ts`

```typescript
import type { ForgeConfig } from '@electron-forge/shared-types';
import { MakerZIP } from '@electron-forge/maker-zip';
import { MakerSquirrel } from '@electron-forge/maker-squirrel';
import { MakerDeb } from '@electron-forge/maker-deb';
import { MakerRpm } from '@electron-forge/maker-rpm';
import { VitePlugin } from '@electron-forge/plugin-vite';

const config: ForgeConfig = {
  packagerConfig: {
    name: 'Electron Boilerplate',
    executableName: 'electron-boilerplate',
    icon: './assets/icon',
    asar: true
  },
  makers: [
    new MakerZIP({}, ['darwin']),
    new MakerSquirrel({
      name: 'electron_boilerplate'
    }),
    new MakerDeb({
      options: {
        maintainer: 'Your Name',
        homepage: 'https://example.com'
      }
    }),
    new MakerRpm({})
  ],
  plugins: [
    new VitePlugin({
      build: [
        {
          entry: 'src/main/index.ts',
          config: 'vite.main.config.ts'
        },
        {
          entry: 'src/preload/index.ts',
          config: 'vite.preload.config.ts'
        }
      ],
      renderer: [
        {
          name: 'main_window',
          config: 'vite.renderer.config.ts'
        }
      ]
    })
  ]
};

export default config;
```

### Forge 설정 항목

**packagerConfig**:
- `name`: 앱 이름 (메뉴바 표시)
- `executableName`: 실행 파일 이름
- `icon`: 아이콘 경로
- `asar`: 소스 코드 패키징 (난독화)

**makers**:
- MakerZIP: macOS .zip
- MakerSquirrel: Windows 설치 파일
- MakerDeb: Linux .deb
- MakerRpm: Linux .rpm

## TypeScript 설정

### Root `tsconfig.json`

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "resolveJsonModule": true,
    "allowSyntheticDefaultImports": true,
    "forceConsistentCasingInFileNames": true,
    "isolatedModules": true,
    "noEmit": true,

    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"],
      "@main/*": ["src/main/*"],
      "@backend/*": ["src/backend/*"],
      "@shared/*": ["src/shared/*"],
      "@features/*": ["src/features/*"],
      "@app/*": ["src/app/*"]
    }
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "out", ".vite"]
}
```

### Renderer `tsconfig.json`

```json
{
  "extends": "./tsconfig.json",
  "compilerOptions": {
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "jsx": "react-jsx",
    "types": ["vite/client"]
  },
  "include": ["src/app/**/*", "src/features/**/*", "src/shared/**/*"]
}
```

Renderer는 `DOM`, `DOM.Iterable` 타입을 포함한다. React 17+ 방식인 `jsx: "react-jsx"`와 Vite 타입을 사용한다.

### Node `tsconfig.node.json`

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowSyntheticDefaultImports": true,
    "esModuleInterop": true
  },
  "include": [
    "vite.*.config.ts",
    "forge.config.ts",
    "drizzle.config.ts"
  ]
}
```

**설정 파일 전용**: Vite, Forge, Drizzle 설정

## Path Alias

### 설정 위치 3곳

**1. TypeScript** (`tsconfig.json`):
```json
"paths": {
  "@/*": ["src/*"],
  "@main/*": ["src/main/*"]
}
```

**2. Vite** (`vite.*.config.ts`):
```typescript
resolve: {
  alias: {
    '@': resolve(__dirname, 'src'),
    '@main': resolve(__dirname, 'src/main')
  }
}
```

**3. Jest/Vitest** (테스트):
```typescript
export default defineConfig({
  test: {
    alias: {
      '@/': new URL('./src/', import.meta.url).pathname
    }
  }
});
```

### Alias 사용

```typescript
// Before
import { Button } from '../../shared/components/ui/button';

// After
import { Button } from '@/shared/components/ui/button';
```

## 트러블슈팅

### Path Alias 작동 안 함

**원인**: TypeScript, Vite, Vitest 중 하나에만 설정
**해결**: 3곳 모두 설정 확인

### Vite 환경변수 undefined

**원인**: `VITE_` 접두사 누락
**해결**: Renderer에서 사용할 환경변수는 반드시 `VITE_` 시작

### ESLint와 Prettier 충돌

**해결**: `eslint-config-prettier` 설치
```bash
npm install -D eslint-config-prettier
```

```json
// .eslintrc.json
"extends": [
  "eslint:recommended",
  "prettier" // 맨 마지막에 추가
]
```

### TypeScript 빌드 느림

**원인**: 불필요한 파일 포함
**해결**: `tsconfig.json`의 `exclude` 확인
```json
"exclude": ["node_modules", "out", ".vite", "drizzle"]
```
