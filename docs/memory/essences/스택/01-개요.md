# 개요

VS Code와 Chrome의 장점을 결합한 Electron 데스크톱 애플리케이션 보일러플레이트

## 프로젝트 목적

영감 수집 도구를 만들기 위한 기반 작업. 3단계 로드맵 중 1단계.

### 로드맵
1. Electron 보일러플레이트 (현재) - 견고한 기반 구축
2. Tauri 마이그레이션 - 성능 및 보안 향상
3. 영감 수집 툴 - 최종 목표 달성

## 핵심 아이디어

VS Code와 Chrome의 장점을 하이브리드로 결합한다.

VS Code는 파일 탐색, Monaco 에디터, 레이아웃을 제공한다. Chrome은 탭 시스템, 드래그앤드롭, 북마크를 제공한다.

## 주요 특징

### Demo-First 개발 워크플로우
demos/ 폴더에서 빠른 프로토타입을 만든다. 검증이 끝나면 features/로 승격한다. 이렇게 실험과 안정성을 분리한다.

### 5-Layer 보안 시스템
1. CSP (Content Security Policy)
2. Security Headers
3. Zod 입력 검증
4. Rate Limiting
5. Path Validation

보안 테스트 100% 통과

### Clean Architecture (Backend)
3계층 구조로 구성한다. Domain Layer는 비즈니스 로직을 담는다. Application Layer는 Use Cases를 담는다. Infrastructure Layer는 DB와 외부 서비스를 담는다.

## 기술 스택

Frontend: React 19, TypeScript, Tailwind CSS v4
Desktop: Electron 36.5, Electron Forge
Database: Drizzle ORM, Supabase, PostgreSQL
Build: Vite 5
Testing: Vitest
State: Zustand
UI: Shadcn UI, Radix UI, Monaco Editor
