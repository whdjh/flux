# 빌드

이 프로젝트는 Vite 기반 빌드 시스템을 사용한다. 개발, 테스트, 프로덕션 빌드를 위한 명령어와 데이터베이스 관리 도구를 제공한다.

## 개발 모드

개발 서버를 실행하고 코드 품질을 검사한다.

```bash
# 개발 서버 시작 (Hot Reload)
npm run dev

# 타입 체크만
npm run typecheck

# 린트 체크
npm run lint
```

## 테스트

Vitest를 사용한 테스트 실행 명령어다.

```bash
# 모든 테스트 실행
npm test

# Watch 모드
npm run test:watch

# UI 모드
npm run test:ui

# Coverage
npm run test:coverage
```

## 프로덕션 빌드

Electron Forge를 사용해 배포용 실행 파일을 생성한다.

```bash
# 패키징 (배포 파일 생성)
npm run make

# 특정 플랫폼
npm run make -- --platform=darwin   # macOS
npm run make -- --platform=win32    # Windows
npm run make -- --platform=linux    # Linux
```

## 빌드 출력

빌드 결과물은 `out/` 디렉토리에 플랫폼별로 생성된다.

```
out/
├── make/
│   ├── zip/darwin/arm64/          # macOS .zip
│   ├── squirrel.windows/x64/      # Windows 설치 파일
│   └── deb/arm64/                 # Linux .deb
└── electron-boilerplate-darwin-arm64/  # 실행 파일
```

## 데이터베이스

Drizzle ORM으로 데이터베이스 스키마를 관리한다.

```bash
# Drizzle 스키마 → DB 동기화
npm run db:push

# 마이그레이션 생성
npm run db:generate

# Drizzle Studio (DB GUI)
npm run db:studio
```

## 유틸리티

프로젝트 의존성과 보안을 관리하는 npm 명령어다.

```bash
# 의존성 업데이트 확인
npm outdated

# 보안 취약점 검사
npm audit

# 보안 취약점 자동 수정
npm audit fix
```

## 빌드 설정 파일

각 프로세스별로 빌드 설정 파일이 분리되어 있다.

- `vite.main.config.ts` - Main 프로세스
- `vite.preload.config.ts` - Preload 스크립트
- `vite.renderer.config.ts` - Renderer (React)
- `forge.config.ts` - Electron Forge
- `tsconfig.json` - TypeScript
