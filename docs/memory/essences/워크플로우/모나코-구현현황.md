## 기능 상세

### MonacoEditorWrapper

EditorTab과 Monaco Editor를 동기화한다.

- 탭 전환 시 콘텐츠 자동 교체
- 파일 확장자 기반 언어 감지 (30+ 언어)
- Ctrl+S 저장 단축키
- automaticLayout으로 분할뷰 리사이즈 대응
- 무한루프 방지 (isInternalChange 플래그)

### useAutoSave

2초 debounce 자동 저장.

- isSaving 상태 표시
- isPending (저장 대기 중) 상태
- 저장 실패 시 최대 3회 재시도
- saveNow()로 즉시 저장 가능

### useEditorHistory

파일별 버전 히스토리.

- 저장 시마다 스냅샷 생성
- 최대 50개 버전 (FIFO)
- localStorage 저장 (세션 간 유지)
- undo/redo 지원
- canUndo/canRedo 상태
