## 13단계 개발 루프 — 마일스톤

**Phase 분리의 원칙**: 같은 Phase 안의 항목은 git worktree + tmux로 **병렬 실행 가능**. Phase 간에는 직렬(앞 Phase가 완료돼야 뒤 Phase 시작).

### Phase 1 — 공유 기반 (직렬)

병렬 불가. 이게 흔들리면 Phase 2 전체가 다시 돌아야 해서 반드시 먼저 확정.

| 상태 | 작업 | 출력물 |
|:---:|---|---|
| 🕐 | `packages/shared`: 엔티티 타입(Item·Document·Folder·Session·ItemEmbed) | `packages/shared/src/entities/*.ts` |
| 🕐 | `packages/shared`: Zod 스키마 (API 입출력 · 검증) | `packages/shared/src/schemas/*.ts` |
| 🕐 | API 계약 확정: flux-be ↔ 클라이언트 REST/WSS 프로토콜 | `docs/아키텍처.md` API 섹션 갱신 |
| 🕐 | 공통 에러 타입 · 결과 envelope | `packages/shared/src/errors.ts` |

### Phase 2 — 독립 패키지 (병렬 4개) ✅

`packages/shared`만 의존하는 4개 패키지. git worktree 4개로 병렬 구현 후 통합 완료.

| 상태 | 세션 | 작업 | 테스트 |
|:---:|---|---|:---:|
| ✅ | A | `packages/api-client` — REST/WSS 클라이언트, 지수 백오프 재연결, Zod 검증 | 67 |
| ✅ | B | `packages/store` — SQLite 래퍼, 5 repository + sync queue + 마이그레이션 | 25 |
| ✅ | C | `packages/editor-core` — loro FluxDoc + 텍스트/임베드 연산 + fast-check 수렴 | 58 |
| ✅ | D | `packages/ui` — Button/Card/Input/Tree/Icon/Chip/Tooltip/SplitView | 83 |

전체: 297 tests passing (shared 64 + Phase 2 233, ui drag 1건 Playwright로 이관).
