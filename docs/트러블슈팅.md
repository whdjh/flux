# 트러블슈팅

발견한 문제와 해결 과정을 기록한다. 같은 문제를 다시 만났을 때 검색하면 답이 보이도록.

## 기록 시점

- 1시간 이상 막혔던 문제 (빠른 해결은 커밋 메시지로 충분)
- 재발 가능성 있는 문제
- 팀원이 곧 만날 가능성 있는 문제
- 외부 도구·라이브러리 버그 우회

기록 안 해도 되는 것: 단순 오타·문법 실수, 한 번만 일어나는 환경 이슈.

## 분류

| 영역 | 예시 |
|---|---|
| 빌드 | tsc·pnpm·turbo·next build·tauri build 실패 |
| 타입체크 | TS 타입 추론 실패, 라이브러리 타입 누락 |
| 테스트 | vitest·playwright 환경 이슈, 모킹 실패 |
| 의존성 | pnpm install·lockfile 충돌, peer dep |
| 배포 | Vercel·EAS·Tauri updater·Chrome Store 거절 |
| 성능 | 수집 100ms 초과, 에디터 60fps 미달, 메모리 누수 |
| UI | 레이아웃 깨짐, 접근성, 반응형, 다크모드 |
| 보안 | XSS·CSRF·secret 노출 |
| 동기화 | loro CRDT 병합 충돌, WebSocket 재연결, 오프라인 큐 |
| 기타 | 위에 없는 모든 것 |

## 심각도

- 🔴 **차단**: PR 머지·배포 못 함
- 🟡 **회피 가능**: 우회로 있음, 근본 해결 필요
- 🟢 **참고**: 동작은 함, 알아두면 좋음

## 템플릿

기록할 때 아래 블록을 복사해서 "기록" 섹션 위에 붙여넣는다.

```markdown
### YYYY-MM-DD · {영역} · 🔴/🟡/🟢 {한줄 제목}

**증상**
{어떤 현상이 발생했는지. 에러 메시지·스크린샷·재현 단계}

**원인**
{왜 발생했는지. 라이브러리 버전·OS·환경 변수 등 맥락}

**해결**
{어떻게 해결했는지. 적용한 코드·명령어·설정 변경}

**방지**
{재발 방지 방법. 테스트 추가, 린터 규칙, 문서화 등}

**관련**
- 커밋: `{해시}`
- PR: #{번호}
- 이슈: #{번호} (외부 라이브러리면 GitHub 링크)
```
