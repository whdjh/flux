## 화면 단위 템플릿

새 화면을 추가할 때 `docs/screens/<화면ID>_<이름>.md`로 만들고 아래 템플릿을 채운다.

```markdown
# {화면명}

## 흐름
{이전 화면} → **{현재 화면}** → {다음 화면}

## 레이아웃
\`\`\`
{아스키 아트로 화면 구성}
\`\`\`

## 컴포넌트
| 위치 | 컴포넌트 | 동작 |
|------|----------|------|

## 상태
{로딩, 빈 상태, 에러 상태}

## 관련 에센스
- docs/essences/UI-UX/...
```
