사용자가 여러 소스에서 정보를 쉽게 수집하고, 그 정보를 직관적으로 정리하고 분류할 수 있도록 돕는 도구.
그리고 수집한 정보를 정독, 취합, 액기스 단계로 자연스럽게 필터링하면서,
사용자가 필요한 것만 남기고 아이디어를 도출할 수 있게 해주는 거지.

이걸 위해 표시 시스템, 클립보드, 스크린샷, 메모 등 다양한 수집방식을 통합하고, 메타데이터와 AI태깅으로 정리하기 쉽게 만드는게 중요하다는 거네.

표시 시스템에 대해선 사용자가 쉽게 아이콘이나 태그를 활용해서 각 수집물에 의미를 부여하고,
필터링이나 검색이 용이하도록 하는 게 핵심일 것 같아.

사용자들이 수집한 콘텐츠를 어떻게 시각적으로 구분할지,
필터링이나 검색 기능을 어떻게 직관적으로 만들지,
