1. 정윤이형 - 옵시디언 잘 쓰고 있으니까 괜찮다. 맥북의 미션 컨트롤 - 핫코너처럼 우측 하단에 뜨는 메모 어떤지.

2. 김성수 대표님 - 노션은 렉이 심하고, 옵시디언엔 협업 기능이 없으니까, 협업 기능을 만들면 사용하겠다.

3. 단짝 친구 - 그냥 있는거 쓴다. 사람은 앞에 있는거 쓴다. 보이는거. 평소엔 우측에 세로로 길게 윈도우 메모장을 세팅해둔다.

4. IR 멘토님 - 기록해둔 링크를 2줄로 요약해주는 기능이 있으면 쓰겠다. 너무 필요하다.

5. 기록학자 김익한 교수님 - "음력 단계에서는 심플하게 메모를 할 수 있고 자동 분류나 요약 기능 같은 것에 의해서 쉽게 데이터베이스로 관리할 수 있는 기능이 있다면 참 좋겠다 생각해 보았습니다."

8. claude-3.5-sonnet - 
	1. 하이브리드 접근: 심플한 메모 기능과 고급 AI 기능을 결합. 사용자가 원하는 수준의 복잡성을 선택할 수 있게 함.
	2. 컨텍스트 인식: 현재 사용자의 작업 환경을 인식하여 관련 정보를 자동으로 제안하는 기능 추가.
	3. 음성 인터페이스: 음성으로 메모를 추가하고 검색할 수 있는 기능 구현. 이동 중이나 멀티태스킹 상황에서 유용.
	4. 개인화: 사용자의 사용 패턴을 학습하여 UI와 기능을 자동으로 최적화하는 시스템 도입.
	5. 오프라인 모드: 인터넷 연결 없이도 주요 기능을 사용할 수 있게 하여 어디서나 사용 가능하게 함.
	6. 프라이버시 중심 설계: 사용자 데이터 보호를 최우선으로 하는 암호화 및 로컬 저장 옵션 제공.

*개발 스택

프론트엔드:
   - Tauri: 경량 크로스 플랫폼 데스크톱 앱 프레임워크
   - React + TypeScript: 컴포넌트 기반 UI 개발, 정적 타입 지원
   - TailwindCSS: 유틸리티 우선 CSS 프레임워크
   - WebAssembly(WASM):

백엔드:
   - Rust: 시스템 프로그래밍 언어, 고성능 및 메모리 안전성
   - Actix-web: Rust 기반 웹 프레임워크
   - Tokio: 비동기 런타임 라이브러리
   - Swagger: API 문서화

데이터베이스:
   - PostgreSQL: 관계형 데이터베이스, JSON 지원, pgvector 확장(서버용)
   - SQLite: 로컬 캐싱 및 오프라인 모드용(로컬 오프라인 모드용)
   - Redis: 램에서 캐싱 및 세션 관리
   - Qdrant: Rust 기반 벡터 검색 엔진

검색 엔진:
   - Tantivy: Rust 기반 전문 검색 엔진

자동 분류 및 태깅:
   - lindera: Rust 기반 형태소 분석기
   - fasttext-rs: FastText의 Rust 포팅

AI 및 NLP:
   - Cluade-3.5-sonnet: GPT-4o 보다 모든 면에서 나은 성능
   - Rust-bert: Rust용 BERT 구현체
   - Tokenizers: Rust 기반 고성능 토크나이저

동기화 및 협업:
   - yrs: Rust 기반 CRDT 구현체
   - tokio-tungstenite: WebSocket 지원

암호화 및 보안:

작업 큐:

    - Prometheus + Grafana: 모니터링 및 시각화
