# 스냅노트(SnapNote) 통합 정리본

## 한 줄 요약

사용자의 에너지를 최소화하면서 다양한 형태의 정보를 원클릭으로 수집·정리하고, 필요 시 직관적으로 찾아 활용할 수 있는 AI 기반 메모 & 정보 관리 생산성 소프트웨어.

## 가설

"사용자는 정보를 모으고 싶어하지만, 정리는 귀찮아하고, 나중에 꼭 필요할 때 쉽고 빠르게 찾길 원한다."

- 여러 도구 사용으로 정보가 분산
- 정리 부담
- 필요할 때 찾기 어려움

## 가설 확장

- 사용자들은 복잡한 정리 과정을 피하고 싶어하며, 자동화된 방식으로 맥락까지 유지되는 정리 시스템을 원한다.
- LLM, NLP 등을 활용해 수집 시점에 메타데이터(시간, 출처, URL 제목, favicon, 3가지 키워드, 맥락 정보, 한 줄 요약)를 자동 부여하면 사용자가 고민 없이도 정보 재활용이 쉬워진다.

## Pain point

1. **수집 불편**: 텍스트, 이미지, 링크, 동영상, 클립보드, 스크린샷 등을 매번 다른 앱으로 관리, 복붙 반복
2. **저장 불편**: 정리하기 위해 노션, 픽픽, 북마크, 갤러리 등 여러 앱을 전전
3. **검색 불편**: 저장 위치 기억 어려움, 여러 앱 오가며 검색, 맥락 및 연관 정보 찾기 어려움

## 니즈

- 최소한의 노력으로 다양한 형식의 정보 수집
- 자동 분류·정리
- 직관적·통합적 검색
- 어디서든 접근 가능한 크로스 플랫폼
- 맥락 보존을 통한 활용성 증대

## 문제 해결

- Alt+클릭 등 원클릭 수집
- 자동 메타데이터(출처, 맥락, 키워드) 부여
- 통합 저장소 + AI 기반 정리
- NLP 활용 연관 검색 및 컨텍스트 복원

## 목표

사용자의 에너지를 최소화하고, 데이터 관리 효율성 극대화.

- 한곳에서 모든 정보 수집·정리
- 나중에 필요할 때 즉시 찾기
- 정리는 프로그램이 하고, 사용자는 활용에 집중

## 기록학(아카이빙 원칙 적용)

- 진본성: 원본 보존, 출처 정보 저장
- 무결성: 자동 백업, 중복 방지
- 맥락성: 수집 당시 컨텍스트(탭 정보, 주변 검색어, 연관 콘텐츠) 자동 저장
- 검색성: 메타데이터 기반 다양한 검색(키워드, 맥락, 유의어)

Records Continuum Model 적용:

1. 데이터 수집(생산)
2. 메타데이터 부여(포착)
3. 체계적 정리(조직화)
4. 실제 활용(다원화)  
    → 이 흐름을 자동화, 자연스럽게 이어지게 함.

## 철학

- "심플 is best"
- 접근성, 직관성 극대화
- 사용자의 흐름 방해 X
- 사용자 시간을 절약하는 개발
- 터치·클릭 횟수 최소화
- '정리는 프로그램이, 활용은 사용자가'라는 원칙에 충실

## 코어기능

1. 수집: Alt+클릭으로 모든 형식 원클릭 수집(텍스트, 이미지, 링크, 동영상, 클립보드, 스크린샷)
2. 정리: AI(LLM) 기반 키워드 추출, 자동 분류, 맥락 정보 저장, 7가지 북마크 아이콘으로 상태 표시
3. 검색: 통합 검색(키워드, 맥락, 연관 정보), NLP 기반 유의어 탐색
4. 메모: 기본 텍스트 편집기(멀티커서 지원), 우측 사이드바 메모장
5. 기타: 창 분할 UI, 크로스 플랫폼, 로컬 저장 보안, 플러그인/템플릿, 향후 협업·클라우드 지원

북마크 아이콘:

- 빈 체크: 미확인
- 체크박스: 확인됨
- X 체크박스: 제외
- 동그라미: 진행 중
- 세모: 주의/중요
- X: 취소/폐기
- 별: 즐겨찾기

## UI

- 다크톤 기반, 눈 피로 최소화
- 2~6분할 창 관리, 4px 단위 그리드
- 우측 사이드바 메모장
- Alt+클릭으로 창 크기 조절, 글자 단위 크기 제어
- 단순하고 직관적인 레이아웃

## 개발 스택

- Frontend: Tauri, Vite, React+TypeScript, UnoCSS
- Backend: Rust, PostgreSQL or SQLite, Redis
- AI/NLP: Claude-3.5, Rust-bert, fasttext-rs
- 검색: Tantivy + GPT-4 mini(고려), ElasticSearch-rs(가능성 검토)

## 시장 카테고리

- Personal Knowledge Management(PKM)
- Information Management Software
- 디지털 아카이빙/메모 앱/생산성 소프트웨어

## 시장 포지션

- Notion, Obsidian, Roam Research, Readwise 등 기존 제품 사이에 위치
- 차별점: 최소한의 사용자 에너지로 전 과정 자동화, 심플 UI, AI 활용

## 경쟁 제품

- Evernote, OneNote, Notion (문서 정리)
- Pocket, Instapaper, Readwise (링크/콘텐츠 수집)
- Obsidian, Roam (지식 관리)  
    → 스냅노트는 이들 기능을 통합·자동화한 차별화된 접근

## 타겟

- 지식 노동자, 연구자, 학생, 콘텐츠 크리에이터, 프리랜서, 디지털 노마드
- 다양한 형식의 정보 자주 다루는 사용자

## MVP

- 2~3개월 내: 핵심 데이터 구조, 로컬 저장소, Alt+클릭 스크래핑, 기본 메모, 7가지 아이콘 태그, 시간순 정리, 기본 검색
- 이후 단계적으로 AI 분류, NLP 키워드 추출, 고급 검색, 테마, 백업/복구, 협업 기능 추가

**내가 이해한 맥락을 다시 정리하자면**:  
너는 분산된 정보를 한 번에 모아서 나중에 쉽게 찾고 활용할 수 있는 '스냅노트'라는 툴을 기획 중이야. 이 툴은 사용자로 하여금 복잡한 정리 과정을 거치지 않고도 자동으로 정보를 정돈하고, 검색할 때 맥락까지 쉽게 복원하는 것을 목표로 해. Rust와 Tauri 기반으로 가볍고 빠르게, LLM/NLP 등을 활용해 메타데이터를 자동 부여해주며, 심플한 UI로 사용자 친화성을 확보하려는 생각이 담겨있지. 이런 대량의 아이디어와 메모를 위와 같은 구조화된 틀에 통합해 깔끔히 정리한 것이 지금의 답변이야.

이렇게 정리한 내용은 향후 기획서나 개발 사양서로 활용하기 좋을 것이고, 필요한 경우 각 섹션을 세분화해 더 구체화할 수 있어.
