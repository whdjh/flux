# Amazon Press Release & FAQ Screener

## 소개
이 문서는 Amazon의 '거꾸로 일하기(Working Backwards)' 방식에 따라 작성된 가상의 보도자료와 FAQ입니다. 제품이 성공적으로 출시되었다고 가정하고, 고객 중심의 관점에서 작성되었습니다.

## SECTION 1: PRESS RELEASE COMPONENTS

### **보도자료 제목**
  리서치 통합 플랫폼 'Flux', 파편화된 정보 워크플로우 혁신

### **부제목**
  AI 기반 원클릭 수집부터 아이디어 발상까지, 지식 노동자의 인지적 마찰을 최소화하는 데스크톱 앱

### **장소 및 출시일**
  대한민국 – 2025년 8월 15일

### **오프닝 문단**
  Flux는 정보 수집부터 아이디어 발상까지 전체 리서치 워크플로우를 하나의 플랫폼에서 지원하는 데스크톱 애플리케이션입니다. 여러 앱을 오가며 발생하는 '인지적 마찰'을 해결하여, 지식 노동자들이 깊은 사고에 집중할 수 있도록 돕습니다. 원클릭 수집, AI 자동 요약, 통합 검색 기능을 통해 사용자의 생산성을 기하급수적으로 향상시킵니다.

### **문제 정의**
  현대 지식 노동자들은 정보가 브라우저 북마크, 메모 앱, 클라우드 저장소에 파편화되어 있어 작업 전환 시마다 평균 23분의 집중력 손실을 겪고 있습니다. 이는 단순한 시간 낭비를 넘어, 창의적 사고에 필요한 '인지적 모멘텀'을 파괴하여 지적 생산성의 질을 저하시키는 근본적인 문제입니다.

### **해결 방법**
  Flux는 드래그 앤 드롭 원클릭 수집, AI 기반 자동 요약 및 태깅, 유의어 포함 통합 검색, 그리고 Apple liquid glass 스타일의 직관적 UI를 통해 정보 관리의 모든 단계를 매끄럽게 연결합니다. 특히 '인지 보호막' 개념을 도입하여 사용자의 사고 흐름이 끊어지지 않도록 설계되었습니다.

### **고객 인용문 1**

### **제품 사용 방식**
  사용자는 웹 브라우징 중 중요한 텍스트나 이미지를 드래그해 끌어다 놓거나 클릭 단축키를 사용하면 Flux에 즉시 수집됩니다. AI가 자동으로 1-3줄 요약과 핵심 키워드를 생성하며, 통합 검색을 통해 언제든지 필요한 정보를 빠르게 찾을 수 있습니다. 메모 기능과 협업 도구를 통해 수집된 정보를 체계적으로 정리하고 팀원들과 공유할 수 있습니다.

### **고객 인용문 2**
  "여러 앱을 오가며 정보를 관리하던 스트레스가 완전히 사라졌습니다. 특히 AI가 자동으로 달아주는 태그가 정말 정확해서, 나중에 찾을 때 검색 키워드도 쉽게 떠올릴 수 있어요." - 이지은, 마케팅 연구원

### **창업자/CEO 인용문**
  "우리는 단순한 정보 저장 도구가 아닌, 지식 노동자의 '생각하는 방식' 자체를 지원하는 플랫폼을 만들고자 했습니다. Flux는 파편화된 정보 관리로 인한 인지적 피로를 해소하여, 사용자가 정말 중요한 창의적 사고에 집중할 수 있도록 돕는 '인지 보호막' 역할을 합니다."

### **시작 방법**
  Flux는 Windows, macOS에서 사용 가능하며, 기본 기능은 무료로 제공됩니다. AI 기능과 협업 도구를 포함한 프로 버전은 월 $20부터 시작하며, 팀 버전은 사용자당 월 $25입니다. 공식 웹사이트에서 즉시 다운로드하여 사용할 수 있습니다.

### **마무리 문단**
  Flux를 통해 지식 노동자들은 정보 관리의 복잡함에서 벗어나, 정말 중요한 아이디어 창출과 깊은 사고에 집중할 수 있게 되었습니다. 파편화된 디지털 환경에서 통합된 워크플로우로의 전환을 경험해보세요. 지금 바로 flux.app에서 무료로 시작하세요.

## SECTION 2: EXTERNAL FAQ

### 1. 기존 대안들과 어떻게 다른가요?
  Notion, Obsidian, Evernote 등 기존 도구들은 특정 단계(노트 작성, 수집)에 특화되어 있지만, Flux는 '리서치 워크플로우 전체'를 통합 지원합니다. 특히 '인지적 마찰' 해소에 초점을 맞춰, 정보 수집부터 아이디어 발상까지의 모든 과정을 끊김 없이 연결합니다.

### 2. 가격은 얼마인가요?
  기본 기능은 무료이며, AI 기능과 고급 협업 도구를 포함한 Pro 버전은 월 $20, 팀 버전은 사용자당 월 $25입니다. 연간 결제 시 20% 할인을 제공합니다.

### 3. 무료 체험 또는 프리미엄 플랜이 있나요?
  모든 기능을 14일간 무료로 체험할 수 있으며, 기본 수집 및 검색 기능은 영구 무료로 제공됩니다. 프리미엄 기능에는 AI 요약, 고급 협업 도구, 무제한 저장 공간이 포함됩니다.

### 4. 어떤 플랫폼/기기에서 사용할 수 있나요?
  Windows, macOS 데스크톱 환경에서 사용 가능하며, Chrome 확장 프로그램을 통해 웹 브라우저와 연동됩니다. 모바일 앱은 2026년 상반기 출시 예정입니다.

### 5. 기술 지식이 없어도 사용할 수 있나요?
  네, 드래그 앤 드롭만으로 정보를 수집할 수 있으며, AI가 자동으로 정리해주므로 별도의 기술 지식이 필요하지 않습니다. 직관적인 UI와 단축키를 통해 누구나 쉽게 사용할 수 있습니다.

### 6. 내 데이터는 얼마나 안전하게 보호되나요?
  모든 데이터는 엔드투엔드 암호화되며, Supabase의 SOC 2 Type II 인증을 받은 보안 시스템을 사용합니다. 사용자의 개인 데이터는 AI 학습에 사용되지 않으며, 완전한 데이터 소유권을 보장합니다.

### 7. 기존에 사용하던 툴들과 연동이 가능한가요?
  Notion, Obsidian, Evernote 등 주요 노트 앱에서 데이터를 가져올 수 있으며, API를 통해 Zapier, IFTTT 등 자동화 도구와도 연동 가능합니다.

### 8. 설정 후 결과를 보기까지 얼마나 걸리나요?
  설치 후 5분 내에 첫 번째 정보 수집과 AI 요약을 경험할 수 있습니다. 즉시 가치를 체감할 수 있도록 설계되었습니다.

### 9. 어떤 종류의 고객 지원이 제공되나요?
  이메일 지원, 실시간 채팅, 상세한 도움말 문서, 그리고 주간 실시간 질문답변 세션을 제공합니다. Pro 사용자는 우선 지원을 받으며, 팀 버전은 전담 고객 지원 담당자가 배정됩니다.

### 10. 당신의 제품은 이 업계의 어떤 핵심 문제를 어떻게 해결하나요?
  지식 관리 업계의 핵심 문제는 '파편화'입니다. 정보가 여러 앱에 흩어져 있어 작업 전환 비용이 발생하고, 이는 창의적 사고를 방해합니다. Flux는 '인지적 마찰' 해소를 통해 이 문제를 근본적으로 해결합니다.

## SECTION 3: INTERNAL FAQ

### 1. 가장 기술적으로 어려운 부분은 무엇인가요?
  Elasticsearch-rs를 이용한 실시간 유의어 검색 엔진과 Monaco Editor를 활용한 Apple liquid glass UI 구현이 가장 도전적입니다. 또한 크롬 확장 프로그램과 데스크톱 앱 간의 실시간 연동도 복잡한 기술적 과제입니다.

### 2. 어떤 제휴나 외부 리소스가 필요한가요?
  OpenRouter API를 통한 다중 AI 모델 접근, Supabase의 백엔드 서비스, 그리고 Elevenlabs의 음성 AI 기술이 필요합니다. Chrome Web Store와 각 OS별 앱 스토어 승인도 필요합니다.

### 3. 성공을 측정할 핵심 지표는 무엇인가요?
  주간 활성 사용자(WAU) 수, 사용자당 일일 정보 수집량, AI 요약 수용률, 그리고 월간 순수 추천 지수(NPS)입니다.

### 4. 성공을 방해할 수 있는 가장 큰 리스크는 무엇인가요?
  기존 워크플로우에 익숙한 사용자들의 전환 저항, 대형 기술 기업(Google, Microsoft)의 유사 기능 출시, 그리고 AI API 비용 상승이 주요 리스크입니다.

### 5. 최소 기능 제품(MVP)은 어떤 모습이어야 하나요?
  드래그 앤 드롭 수집, AI 자동 요약/태깅, 메모 기능, 기본 검색 기능, 그리고 폴더 기반 정리 시스템을 포함한 데스크톱 앱과 크롬 확장 프로그램입니다.

### 6. 초기 고객을 어떻게 확보할 계획인가요?
  생산성 도구 커뮤니티, 연구자 네트워크, 그리고 '빌드 인 퍼블릭' 전략을 통해 초기 베타 테스터를 모집합니다. 인플루언서 마케팅과 콘텐츠 마케팅도 병행합니다.

### 7. 단위 경제성(unit economics)은 어떻게 구성되나요?
  고객 획득 비용(CAC) $25, 월간 반복 수익(MRR) $20, 고객 생애 가치(LTV) $400로 LTV/CAC 비율 16:1을 목표로 합니다. AI API 비용이 주요 변동비입니다.

### 8. v1(초기 버전)을 만들기 위해 어떤 자원이 필요한가요?
  3명의 개발팀(풀스택 2명, AI 전문가 1명), 4개월의 개발 기간, 그리고 $500의 개발 비용이 필요합니다. 추가로 인프라 및 AI API 비용으로 월 $2,000이 소요됩니다.

### 9. 지금이 이 제품을 만들기에 적절한 시기인 이유는 무엇인가요?
  AI 기술의 성숙화로 자동 요약/태깅이 실용적 수준에 도달했고, 원격 근무 확산으로 지식 노동자의 생산성 도구 수요가 급증했습니다. 또한 기존 도구들의 한계가 명확해진 상황입니다.

### 10. 경쟁사에 비해 당신의 제품이 갖는 차별점 또는 모방이 어려운 요소는 무엇인가요?
  '인지적 마찰' 해소에 특화된 UX 설계, 사용자 개인 데이터로 학습하는 맞춤형 AI, 그리고 수집-정리-발상 전체 워크플로우의 매끄러운 통합이 핵심 차별점입니다. 이는 단순한 기능 복사로는 모방하기 어려운 전체적인 사용자 경험입니다.
