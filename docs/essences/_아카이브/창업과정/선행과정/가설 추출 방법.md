### 바텀업 방식 (Bottom-up)

작은 문제점 -> 큰 시장

- 작은 부분에서 시작해 전체를 구성

- 세부적인 것부터 시작해서 큰 그림을 완성

- 예시:

- 코딩할 때 작은 함수들을 먼저 만들고 이를 조합해 큰 시스템 구축

- 데이터를 먼저 수집하고 패턴을 찾아 결론 도출

### 탑다운 방식 (Top-down)

큰 시장 -> 문제점 발견
- 큰 그림에서 시작해 세부사항으로 분해

- 전체 구조를 먼저 설계하고 세부 구현

- 예시:

- 전체 시스템 구조를 먼저 설계하고 각 모듈 구현

- 목표를 먼저 정하고 세부 실행계획 수립

### 디자인 싱킹 방식 (Design Thinking)

- 사용자 중심의 문제 해결 방식

- 5단계로 진행:

- 공감 - 사용자 니즈 이해

- 문제 정의 - 핵심 문제 도출

- 아이디어 도출 - 해결책 브레인스토밍

- 프로토타입 - 아이디어 구체화

- 테스트 - 검증 및 개선

각 방식의 활용:

- 바텀업: 데이터 분석, 상세 구현 필요할 때

- 탑다운: 큰 프로젝트 기획, 전략 수립할 때

- 디자인 싱킹: 혁신적 제품/서비스 개발할 때
