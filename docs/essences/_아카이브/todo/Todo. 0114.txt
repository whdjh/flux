## 에이전트들

Planner는 세션 시작 시 실행된다. 스모크 테스트를 돌리고 Feature Map을 분석해서 다음 작업을 추천한다. "뭘 해야 하지?" 고민할 필요가 없다.

Context Builder는 의존 기능의 설계 결정을 자동으로 보여준다. auth를 구현할 때 jwt에서 결정한 내용이 바로 보인다. 구현하면서 "~하기로 했다"라고 말하면 자동으로 기록된다. "어떻게 하기로 했더라?" 찾아볼 필요가 없다.

Verifier는 완료 감지 시 자동으로 검증한다. 빌드, 테스트, 린트, 타입체크를 돌린다. 실패하면 자동 수정을 3회까지 시도한다. 빼먹을 일이 없다.

Commit Agent는 todo-history를 읽어서 커밋 메시지를 만든다. 매번 커밋 메시지를 고민할 필요가 없다.

Todo Logger는 TodoWrite 직후 자동으로 작업 내역을 기록한다. "오늘 뭐 했지?" 기억을 더듬을 필요가 없다. Commit Agent가 이 기록을 읽는다.

Chat Logger는 세션 대화 내역을 저장한다. "저번에 어떻게 해결했더라?" 찾아볼 수 있다.
