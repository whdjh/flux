1. 핵심 데이터 구조

- 기본 식별 정보 (ID, 생성일시, 수정일시)
- 컨텐츠 저장 (텍스트, 링크)
- 메타데이터 (출처, 태그)
- 로컬 파일 시스템 기반 저장

2. 데이터 수집 기능

- Alt + 클릭으로 텍스트/링크 스크래핑
- 기본 메모 입력
- 7가지 북마크 아이콘으로 상태 표시
    - 빈 체크: 미확인
    - 체크박스: 확인 완료
    - X 체크박스: 제외/거절
    - 동그라미: 진행중
    - 세모: 주의/중요
    - X: 취소/폐기
    - 별: 즐겨찾기

3. 기본 정리 기능

- 시간순 정리
- 북마크 상태별 필터링
- 기본 검색 (제목, 내용)

4. 최소 UI 구성

- 좌측 사이드바: 홈, 최신 스크랩, 메모장
- 메인 영역: 스크랩/메모 표시
- 우측 사이드바: 북마크별 모아보기
- 심플한 라이트/다크 테마

기술 스택:

- Frontend: Tauri + React + TypeScript
- Backend: Rust
- 저장소: 로컬 파일 시스템
- 상태관리: Redux

핵심 기능에만 집중:

- 원클릭 스크래핑
- 북마크 시스템
- 시간순 정리
- 기본 검색

제외되는 기능:

- 화면 분할
- AI/NLP 기능
- 클라우드 동기화
- 협업 기능
- 블록체인 거래소
- 플러그인 시스템
- 템플릿
- 고급 검색
- 자동 백업

검증할 가설:

1. 사용자들은 원클릭 스크래핑으로 더 쉽게 정보를 수집할 수 있다
2. 7가지 북마크 아이콘으로 정보의 상태를 직관적으로 관리할 수 있다
3. 시간순 정리와 북마크 필터링만으로도 기본적인 정보 관리가 가능하다
