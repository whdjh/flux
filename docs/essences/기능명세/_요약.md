# 기능명세

프로젝트 정의, 기술 스택, 페르소나, 레이아웃, 유저 흐름, 경쟁 분석, 철학은 각각 비전.md, 스택.md, 유저리서치.md, UI-UX.md, 경쟁분석.md에 있다. 이 파일은 기능 명세 본체만 담는다.


## 핵심 기능

애플리케이션은 7가지 핵심 기능으로 구성된다. 수집, 정리, 메모, 창관리, 검색, AI 어시스턴트, 협업이다. 이 기능들은 수집 → 검토 → 통합 → 정제 → 발상이라는 리서치 워크플로우를 따라 설계되었다.

### 수집

크롬 확장프로그램과 연동한다. Alt + 우클릭 또는 드래그앤드롭으로 콘텐츠를 수집한다. 텍스트 하이라이트, 이미지, 링크, 동영상을 지원한다. 클립보드와 스크린샷도 수집 대상이지만 카테고리 폴더에서만 확인할 수 있다.

수집과 동시에 AI가 1~3줄 요약과 키워드 3개를 생성한다. 병렬 처리로 UX가 느려지지 않게 한다. 메타데이터는 제목, URL, 파비콘, AI 요약, 키워드, 생성일을 저장한다. 확장 프로그램과 앱은 로컬 서버를 통해 통신하므로 외부 노출 없이 안전하다.

### 정리

좌측 사이드바에 폴더 트리 구조를 제공한다. 로컬 폴더와 파일을 연동할 수 있으므로 기존 워크플로우를 방해하지 않는다. All 폴더에서 모든 콘텐츠를 모아보고, 카테고리 폴더로 분류한다. 카테고리는 텍스트 하이라이팅, 링크, 이미지, 동영상, 클립보드, 스크린샷이다. 클립보드와 스크린샷은 All 폴더에 안 뜬다.

메인 윈도우 우측 상단에 정렬 옵션 버튼이 있다. Eagle 스타일의 4가지 정렬을 제공한다. 폭포(벽돌 모양, masonic 구현), 양쪽(Justified), 그리드, 목록이다.

정렬 필터(최신순, 오래된순)를 적용하여 콘텐츠 목록을 볼 수 있다.

### 메모

메모 기능은 세 곳에서 작동한다. 메인 윈도우(Obsidian/Notion 스타일 편집기), 우측 사이드바, 포스트잇 창이다. Monaco Editor를 공통으로 쓴다.

한 번 거르는 기능이 핵심이다. 수집 → 검토 → 정제 → 취합 과정에서 검토-정제-취합 단계를 돕는다. 메인 윈도우의 수집 정보를 우측 사이드바 메모 공간으로 드래그해서 옮긴다. 스티커를 붙이거나 텍스트에 형광펜 효과를 준다. 빈 체크박스, 완료 체크박스, X, 별, 동그라미, 세모 같은 시각적 장치로 정보를 걸러낸다.

텍스트 서식은 글자 크기, 볼드, 이탤릭, 밑줄, 실선, 글자 색, 배경 색을 지원한다. 슬래시(/) 커맨드로 제목, 토글, 할 일, 코드, 불렛 포인트, 인덱스, 구분선을 입력한다. 이미지 삽입과 하이퍼링크도 된다. Markdown(.md)과 텍스트(.txt) 형식으로 저장한다.

### 창 관리

프로그램 우측 상단에 포스트잇 버튼이 있다. 누르면 Liquid Glass UI 형태의 포스트잇 창으로 전환된다. 메모 기능을 그대로 가져가되 UI가 투명하고 간소화된다. 사용자가 크기와 위치를 지정하고 여러 창을 띄울 수 있다. 창을 맨 위로 고정시켜 웹서핑이나 게임 중에도 메모할 수 있다.

이 기능은 전환 비용을 제거하기 위해 설계되었다. 게임이나 작업 중 영감이 떠오르면 애플리케이션을 전환하지 않고 바로 기록한다. 투명 UI라서 시야를 가리지 않는다.

### 검색

메인 윈도우 가운데 위에 검색 버튼이 있다. Elasticsearch-rs로 유의어 포함 검색을 지원한다. 극단적으로 '그레이브즈'를 '그브'로 검색해도 찾는다. AI가 달아놓은 요약과 키워드도 검색 대상이다. 의미 기반 검색(Semantic Search)도 지원한다.

### AI 어시스턴트

우측 사이드바에 있으며 메모 UI와 전환 가능하다. 수집한 정보를 RAG 방식으로 가져와 대화한다. Cursor AI IDE처럼 생성, 대화, 수정이 가능하고 파일/폴더 관리까지 할 수 있다. MCP 서버를 연결할 수 있어 확장성이 높다.

Openrouter로 모델을 선택하고 세부 옵션을 정할 수 있다. Elevenlabs TTS/STT로 음성 대화도 지원한다.

### 협업

실시간 협업 모드다. Figma 협업 모드처럼 서로 동시에 수정할 수 있다. 슬래시(/) 입력 시 마우스 커서에서 채팅을 칠 수 있고 협업 모드 활성화 시 채팅창도 생긴다. 프로필 겹쳐보기, 커서 색상 구분, 동시 편집을 지원한다.


## 요구사항 정리

### 기본 프레임워크

Electron 기반 데스크톱 앱. 앱 배경 투명 설정으로 다른 작업 창 위에 띄워놓고 사용 가능. 좌/우 사이드바 열기/닫기/크기 조절. 여러 탭 생성/관리. 작업 영역 1/2, 1/3, 1/4 등 분할.

### 수집

브라우저 확장 프로그램 설치. 단축키(Alt + 우클릭) 또는 드래그앤드롭으로 텍스트/이미지/링크/동영상 수집. 메타데이터 자동 저장(제목, URL, 파비콘, 생성일). AI 요약 + 키워드 자동 생성. 로컬 서버 통신으로 보안 유지.

### 탐색 및 정리

수집된 모든 아이템을 콘텐츠 창에서 확인. 폴더 트리 구조로 주제 생성/수정/삭제. 아이템 이동으로 분류. 키워드/의미 기반 검색. 정렬 필터(최신순, 오래된순). 보기 옵션(리스트, 그리드, 양쪽, 벽돌).

### 메모

Monaco Editor 기반 텍스트 편집기. 제목/내용 작성, 저장/불러오기. / 커맨드. 텍스트 서식. 이미지 삽입. 하이퍼링크. 확대/축소. 행/열/글자 수 표시. Markdown/텍스트 형식.

### AI 어시스턴트

Openrouter API 채팅. 새 채팅/리스트. 모델 선택 드롭다운. 첨부(파일, 링크, 이미지, 동영상). 보이스 활성화(마이크 켜기/끄기).

### 스티커 메모

독립 창. 메인 메모장과 동일 편집 기능. 창 맨 앞 고정(단축키 + 버튼). 콘텐츠 드래그앤드롭. 시각적 장치(체크박스, X, 별, 동그라미, 세모)로 정보 선별/평가.

### UI 요구사항

Liquid Glass 디자인 적용. 투명 배경으로 다른 작업과 자연스럽게 어우러짐. 사이드바/탭/창 분할 직관적 제어. Shadcn UI 기반 일관성. 별도 설명서 없이 사용법 유추 가능한 직관적 설계.


## PRD 커버리지 맵

와이어프레임 페이지별 우선순위 매핑이다.

M0 (필수 선행):
- 00_App Shell: 전역 단축키, 투명/데코 토글, 접근성, 상태
- 01_Inbox: 수집된 카드 목록, 정렬/필터, 보기 4모드, 멀티선택/벌크
- 02_Project: 트리+콘텐츠, 폴더 CRUD, 빈 상태
- 03_Detail: 메타(제목/URL/날짜/태그/AI 요약/키워드)
- 04_Editor: 블록 삽입(/), 임베드 드롭, 자동 저장/버전, Undo/Redo
- 05_Search: 키워드/의미검색 토글, 정렬(점수/최신), 하이라이트
- 08_Settings: UI(테마/밀도/투명도)
- 09_Layout: 1/2, 1/3, 1/4 프리셋, 드래그 리사이즈, 탭 재정렬
- 10_Capture: Alt+우클릭 오버레이, 드롭존, 확장 <-> 앱 상태
- 15_Onboarding: 로그인/초기 설정

M1 (2차):
- 06_AI: 모델 선택, 첨부, 스트리밍/중지/비용 경고
- 07_Sticky: 토글/단축키/동기화/드롭
- 12_Export: 범위/옵션/파일명 규칙
- 17_Viewer: 미디어 확대/팬/전체화면

M2 (3차):
- 11_Collab: 라이브 커서, 아바타 스택, 댓글, 퀵 채팅 패널('/')
- 16_Voice: 마이크 토글, TTS 컨트롤, 전사

갭 점검:
- 로컬 DB/FS는 UI가 아닌 구현 범주. 아키텍처 다이어그램 별도 필요.
- 확장 프로그램 설치/설정 화면(브라우저 측)은 범위 밖. 웹스토어 가이드로 분리 권장.
- 오프라인 모드/에러 상태 공통 패턴: 스켈레톤/토스트/리트라이를 공통 규칙으로 명시 필요.
