# 유저흐름

사용자 시나리오와 UI/UX 플로우

---

## 앱 첫 실행

### 흐름

1. 애플리케이션 실행
2. Splash 화면 표시 (로딩)
3. Main Window 생성
4. 기본 레이아웃 렌더링
   - Titlebar (상단)
   - Sidebar (좌측) - 파일 탐색기
   - EditorArea (중앙) - 빈 상태
   - StatusBar (하단)
5. 파일 탐색기에 현재 디렉토리 표시

### UI 상태

```
┌─────────────────────────────────┐
│  Titlebar (앱 제목, 윈도우 버튼)  │
├──────┬──────────────────────────┤
│      │                          │
│ File │  Welcome to App!         │
│ Tree │                          │
│      │  Open a file to start    │
│      │                          │
├──────┴──────────────────────────┤
│  Status Bar (info)              │
└─────────────────────────────────┘
```

## 파일 탐색 및 열기

### 흐름

1. 사용자가 좌측 파일 탐색기에서 폴더 클릭
2. 폴더 확장/축소 애니메이션
3. 하위 파일 목록 표시
4. 파일 클릭
5. IPC 통신으로 파일 읽기 (`read-file`)
6. 새 탭 생성 (TabBar)
7. Monaco 에디터에 파일 내용 표시
8. 파일 아이콘 및 이름 표시
9. StatusBar에 파일 정보 표시 (줄 수, 인코딩)

### UI 상태 변화

```
Before:
┌─────────────────────────────────┐
│  [파일 탐색기]  [빈 에디터]      │
└─────────────────────────────────┘

After:
┌─────────────────────────────────┐
│  [파일 탐색기]  [탭] [에디터]    │
│               file.txt ×         │
│               ┌─────────────┐   │
│               │ 파일 내용    │   │
│               └─────────────┘   │
└─────────────────────────────────┘
```

## 파일 편집 및 저장

### 흐름

1. 사용자가 에디터에서 코드 수정
2. 탭에 변경 표시 (●) 또는 색상 변경
3. Cmd+S (저장 단축키)
4. IPC 통신으로 파일 쓰기 (`write-file`)
5. 성공 시 변경 표시 제거
6. Toast 알림 (선택)
7. StatusBar 업데이트 ("Saved")

### 에러 시나리오

**권한 없음**:
1. 파일 쓰기 실패
2. 에러 메시지 표시 (Dialog)
3. 변경 내용 유지 (손실 방지)
4. 다른 경로로 저장 옵션 제공

---

## 여러 파일 작업

### 흐름

1. 파일 A 열기 → 탭 A 생성
2. 파일 B 열기 → 탭 B 생성 (탭 A 옆)
3. 파일 C 열기 → 탭 C 생성
4. 탭 클릭으로 전환
5. 활성 탭 강조 표시 (언더라인 또는 배경색)
6. 탭 X 버튼으로 닫기
7. 마지막 탭 닫으면 빈 상태로

### UI 상태

```
3개 탭 열림:
┌─────────────────────────────────┐
│  file-a.txt | file-b.txt* | file-c.txt × │
│  ─────────                        │
│  [file-a.txt 내용]                │
└─────────────────────────────────┘

* = 활성 탭
```

## 탭 드래그앤드롭 재정렬

### 흐름

1. 사용자가 탭을 드래그 시작
2. 드래그 프리뷰 표시 (반투명)
3. 다른 탭 위로 호버
4. 삽입 위치 표시 (세로 선)
5. 드롭
6. 탭 순서 업데이트
7. 애니메이션으로 재배치

### 시각적 피드백

```
드래그 중:
[탭A] [탭B] [드래그중] | [탭C]
              ↓
[탭A] [│] [탭B] [탭C]
        ↑ 삽입 위치
```

## 설정 변경

### 흐름

1. Cmd+, (설정 단축키)
2. 설정 페이지 열림 (새 탭 또는 모달)
3. 카테고리 선택 (Appearance, Security, etc.)
4. 설정 값 변경 (Toggle, Input, Select)
5. 자동 저장 또는 Save 버튼
6. localStorage 또는 설정 파일에 저장
7. 설정 즉시 반영 (다크모드 등)

### 설정 카테고리

- **Appearance**: 테마, 폰트, 줄 번호
- **Editor**: 탭 크기, 자동 저장, 미니맵
- **Security**: 5-Layer 설정
- **Advanced**: 실험적 기능

## 에러 발생 시

### 파일 읽기 실패

1. IPC 에러 반환
2. Toast 에러 메시지
3. 에러 로그 기록
4. 재시도 옵션 제공

### 앱 크래시

1. Electron 에러 핸들러 포착
2. 에러 리포트 생성 (로그 파일)
3. 안전한 종료
4. 다음 실행 시 복구 제안 (세션 복원)

## 검색 기능 (계획)

### 흐름

1. Cmd+P (Quick Open)
2. 검색 인풋 포커스
3. 타이핑 → Fuzzy 검색
4. 검색 결과 실시간 표시
5. 방향키로 선택
6. Enter로 파일 열기
7. Esc로 닫기

### UI 상태

```
┌───────────────────────┐
│  Search: fil_         │
│  ─────────────────    │
│  file-a.txt          │
│  > file-b.txt  ◀     │
│  file-c.txt          │
└───────────────────────┘
```
