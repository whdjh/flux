## 기능별 상세

### 1. 수집 (0%)

**PRD 요구사항:**
- Alt+우클릭 단축키로 콘텐츠 수집
- 드래그앤드롭으로 수집
- 텍스트, 이미지, 링크, 동영상 지원
- AI 요약 + 키워드 자동 생성
- 메타데이터 저장 (제목, URL, 파비콘, 생성일)

**필요 작업:**
- [ ] 크롬 확장프로그램 개발

**예상 기간:** 2-3주
