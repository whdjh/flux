## 1. 텍스트 스타일
```markdown
일반 텍스트
*이탤릭* 또는 _이탤릭_
**볼드** 또는 __볼드__
***볼드 이탤릭*** 또는 ___볼드 이탤릭___
~~취소선~~
<u>밑줄</u>
`코드`
```

## 2. 제목
```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

## 3. 목록
```markdown
1. 순서 목록
2. 두번째
   1. 들여쓰기 1
   2. 들여쓰기 2

- 글머리 기호
* 별표도 됨
+ 더하기도 됨
  - 들여쓰기
```

## 4. 체크리스트
```markdown

- [x] 완료된 일
```


## 7. 링크와 이미지
```markdown
[링크 텍스트](URL)
[링크 텍스트](URL "마우스 오버시 툴팁")
![이미지 설명](이미지URL)
[이미지 설명](../images/photo.jpg)
[참조링크][1]
[1]: URL

자동링크: <https://example.com>
이메일: <example@example.com>
```
