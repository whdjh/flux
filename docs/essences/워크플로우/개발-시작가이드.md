# 프로젝트 설정 가이드

← [문서 네비게이션](../00-시작/00-시작하기.md)

## 빠른 시작

```bash
# 1. 저장소 클론
git clone [your-repo-url]
cd electron-boilerplate

# 2. 의존성 설치
npm install

# 3. 환경 변수 설정
cp .env.example .env
# .env 파일에 Supabase 자격 증명 추가

# 4. 데이터베이스 초기화
npx drizzle-kit push

# 5. 개발 서버 시작
npm start
```

## 환경 요구사항

- Node.js 18+ (권장: 20 LTS)
- npm 9+ 또는 yarn 1.22+
- Git
- VS Code (권장 - 프로젝트 설정 포함)

## 상세 설정

### 1. Supabase 설정

1. [Supabase](https://supabase.com)에서 프로젝트 생성
2. 프로젝트 설정 > API에서 다음 값 복사:
   - `SUPABASE_URL`: 프로젝트 URL
   - `SUPABASE_ANON_KEY`: anon/public 키
   - `DATABASE_URL`: Connection string (Transaction mode)

3. `.env` 파일에 값 입력:
```env
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_ANON_KEY=eyJxxxxx...
DATABASE_URL=postgresql://postgres.xxxxx:password@aws-0-xxxxx.pooler.supabase.com:6543/postgres?pgbouncer=true
```

### 2. VS Code 확장 프로그램 (권장)

프로젝트에 최적화된 VS Code 확장:
- ESLint
- Prettier
- TypeScript and JavaScript Language Features
- Tailwind CSS IntelliSense
- Vitest Runner

### 3. 프로젝트 구조 이해하기

```
src/
├── demos/        # 새 기능 실험 (여기서 시작!)
├── features/     # 검증된 프로덕션 기능
├── app/          # 핵심 인프라
└── shared/       # 공유 유틸리티
```

모든 기능은 데모에서 시작한다. `demos/` 폴더에서 프로토타입을 만들고, 검증이 끝나면 `features/`로 이동한다.

### 4. 첫 번째 데모 만들기

```typescript
// 1. 데모 컴포넌트 생성
// src/demos/my-feature/MyFeatureDemo.tsx
export const MyFeatureDemo = () => {
  return <div>My First Demo!</div>;
};

// 2. 데모 인덱스에 추가
// src/demos/DemoIndex.tsx에 추가:
{
  title: 'My Feature',
  path: '/demos/my-feature',
  status: 'wip'
}

// 3. 브라우저에서 확인
// http://localhost:3000/demos 접속
```

## 개발 명령어

### 기본 명령어
```bash
npm start          # 개발 서버 시작
npm run make       # 프로덕션 빌드
npm test           # 테스트 실행
npm run lint       # 린트 검사
```

### 데이터베이스 명령어
```bash
npx drizzle-kit push      # 스키마 변경 적용
npx drizzle-kit generate  # 마이그레이션 생성
npx drizzle-kit studio    # DB GUI 열기
```

## 문제 해결

### 포트 충돌
```bash
# 3000 포트가 사용 중인 경우
lsof -i :3000  # Mac/Linux
netstat -ano | findstr :3000  # Windows

# 프로세스 종료 후 재시작
```

### 데이터베이스 연결 실패
1. `.env` 파일의 DATABASE_URL 확인
2. Supabase 프로젝트 상태 확인
3. 네트워크 연결 확인

### Electron 창이 열리지 않음
1. Electron 프로세스 확인
2. 개발자 도구 콘솔 확인 (Ctrl+Shift+I)
3. 로그 파일 확인
