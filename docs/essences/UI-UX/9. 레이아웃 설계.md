### 레이아웃 보일러플레이트

### 컴포넌트 구성

앱은 상단 타이틀바, 좌·우 사이드바, 메인 분할 영역, 뷰어로 구성돼. 타이틀바는 창 제어 버튼을 제공하고 드래그 이동을 지원해. 메인 영역은 shadcn의 Resizable로 패널을 유연하게 분할하고, 뷰어는 masonic 기반 가상화 Masonry로 대량 목록에서도 부드럽게 렌더링해. 사이드바는 좌·우 모두 토글·리사이즈가 가능하고 좁은 폭에서는 오버레이로 전환돼.

### 레이아웃 설계
레이아웃은 생산성 중심으로, 최소 폭 320px 보장과 빠른(40ms) 전환을 기본으로 해. 분할은 균등/비율 프리셋을 제공하고 리사이즈 핸들은 더블클릭으로 균등 분할로 복귀해. 스냅은 2% 단위로 동작하며 Alt로 무시할 수 있어. 사이드바는 1200px 미만에서 자동 오버레이로 전환돼.

  프리셋
    1분할: 100%
    2분할: 50/50, 33/67, 67/33
    3분할: 25/50/25, 20/60/20
    4분할: 25/25/25/25 (최대 4분할)

  분할/리사이즈
    최소 폭: 패널 320px, 사이드바 240~420px
    핸들: 6px, 더블클릭 → 현재 그룹 균등 분할로 리셋
    스냅: 2% 단위 스냅, 임계 8px, Alt 키로 스냅 무시

  사이드바
    좌/우 토글 가능, 상태 기억(열림/접힘/폭)
    접힘 너비: 64px(아이콘 모드), 도킹/오버레이 모드 지원(좁은 폭에서 오버레이)
    드래그 리사이즈, 최소·최대 폭 강제

  탭
    각 패널 상단 탭바, 재정렬/핀 고정/스크롤 지원
    단축키: Ctrl+T 새 탭, Ctrl+W 닫기, Ctrl+Tab/Shift+Ctrl+Tab 이동, Ctrl+1..9 점프

  상태 저장
    범위: 앱 전역 + 프로젝트(폴더) 단위
    항목: 좌/우 사이드바 상태와 폭, 분할 프리셋/비율, 활성 탭
    시점: 앱 시작/종료, 프로젝트 전환 시 자동 저장·복원

  단축키(레이아웃)
    Ctrl+B: 좌측 사이드바 토글
    Ctrl+Shift+B: 우측 사이드바 토글
    Ctrl+Alt+S: 수직 분할 추가/해제(현재 패널 기준)
    Ctrl+Alt+[ / ]: 분할 프리셋 이전/다음

  애니메이션
    패널 열고닫기 40ms ease-out, 리사이즈는 실시간(0ms)
    오버레이 사이드바: 페이드+슬라이드 40ms

  접근성
    분할 핸들: role="separator", aria-orientation="vertical"
    키보드 리사이즈: 핸들 포커스 상태에서 ←/→ 10px, Shift+←/→ 50px
    포커스 링/명확한 대비 모드 제공

  투명/다중창
    투명 배경(Liquid Glass) 사용 시 패널 경계선/그림자 보강
    멀티모니터: 새 창 중앙 배치, 마지막 위치·크기 기억

  예외/가드
    최소 폭 미만 방지(클램프), 과분할(>4) 금지
    가로 폭 협소 시 우측 사이드바 자동 접힘(임계 1200px)

  라이브러리 선택
    Resizable(shadcn): ResizablePanelGroup / ResizablePanel / ResizableHandle 사용 계획
    Masonry(masonic): 기본 채택(가상화), 대량 목록 최적

  테스트 체크리스트
    분할 프리셋 전환, 스냅 동작, 최소·최대 폭, 상태 저장·복원
    사이드바 토글/오버레이, 탭 단축키, 투명 모드 경계 가독성
    접근성(키보드 리사이즈/포커스), 다중창 위치 기억

  기본 해상도/프리셋(Eagle 스타일)
    기본 해상도: 1440×900(16:10), 비율 락 없음
    창 프리셋: 1280×800, 1440×900, 1680×1050, 1920×1200, 2560×1600

  Masonry 브레이크포인트(콘텐츠 폭 기준)
    ≤1024: 2컬럼
    ≤1440: 3컬럼
    ≤1920: 4컬럼
    >1920: 5컬럼
    거터: 16px(모바일 12px)

  안전 영역/제약
    콘텐츠 최소: 960×600 보장(패널 최소폭과 충돌 시 패널 우선 클램프)
    우측 사이드바 자동 오버레이 전환 임계: 전체 창 폭 1200px

### QA 체크
첫 실행 시 1440×900(기본)을 적용하고 대형·저배율 디스플레이에서는 1680×1050을 자동 선택해. 이후 실행은 마지막 창 크기를 복원해야 해. 프리셋 전환과 상태 저장·복원은 안정적으로 동작해야 하며, 사이드바 토글 시 스크롤·그리드가 흔들리면 안 돼. 4K·HiDPI 환경에서도 리사이즈 핸들 조작감과 스냅 체감이 유지돼야 해.

### masonic 사용 지침
대용량 자산을 부드럽게 다루기 위해 masonic을 고정 채택해. 화면과 소량의 overscan만 렌더해 DOM/메모리/리플로우를 최소화하는 게 목표야.

  기본
    masonic 고정 채택(가상화 내장)

  설정
    breakpoints: ≤1024 2, ≤1440 3, ≤1920 4, >1920 5
    gutter: 16px(모바일 12px)
    overscan: 1~2 viewport
    estimateHeight: 카드 비율(예: 16:9) 기반 추정 → 로딩 후 실측 교정, 크기 캐시 유지
    positioner 캐시 재사용: 필터/정렬/리사이즈 시 스크롤 앵커 유지
    이미지 로딩: LQIP/Skeleton + IntersectionObserver
    DnD: key 안정적으로 유지, 드래그 중 측정 pause

  검색/프린트
    Ctrl+F 대체: 앱 내 검색 UI 제공(가상화로 화면 밖 DOM 미생성)
    Export/Print: 비가상화 모드 토글로 전체 렌더 후 캡처/내보내기

  체크리스트
    스크롤 위치 보존, 깜빡임 무
    성능 타깃: 60FPS, 메모리 300~400MB 이내
    1k/5k 아이템 시나리오 수동 검증

    썸네일/프리뷰 생성(이미지/비디오/오디오)
    메타데이터 추출(EXIF, 해상도, 길이, 포맷)
    파비콘/원본 페이지 메타 수집
    파일/폴더 감시(자동 인덱싱)

  수집 브릿지(브라우저 확장 ↔ 앱)

    페이로드 검증/정규화/큐잉

  검색/필터/정렬
