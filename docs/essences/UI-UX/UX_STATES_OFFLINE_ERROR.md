## 오프라인/에러/로딩 공통 패턴 가이드

- 목적: 와이어프레임/디자인/개발이 동일한 상태 처리 규칙으로 일관되게 구현
- 적용: 전 페이지(00~17). 토큰 출처: `design-system/tokens-and-shell.json`

### 1) 상태 모델
- Loading: 스켈레톤 우선(스피너 최소), 레이아웃 점프 금지
- Empty: 유용한 설명 + 1차 CTA(예: "첫 아이템 추가"), 2차 학습 링크 선택
- Success: 기본 상태, 중복 피드백 지양
- Offline: 읽기 우선(가능한 범위), 쓰기 큐잉/보류 표시, 상단 오프라인 인디케이터
- Error: 발생 위치 인라인 메시지 + 상황에 따라 토스트/모달. 재시도 명시
- Processing(Long): 진행률/단계 표시(취소 가능 시 버튼 제공)

### 2) 글로벌 규칙
- 네트워크 인디케이터: Topbar에 Online/Offline 배지
- 글로벌 에러 바운더리: 복구 버튼(새로고침/상위로 이동)
- 토스트: 우상단, 3~5초, 수동 닫기 제공, aria-live="polite"
- 재시도: 즉시 재시도 + 지수 백오프(1s, 2s, 4s), 대기 중 비활성
- 키보드 우선: Escape로 오버레이 닫기, Tab 순서 보장, 포커스 링 표시
- 히트 영역: 최소 44px, 터치 고려
- 색상 토큰 매핑: success/warning/danger/info = semantic 토큰 사용

### 3) 드래그 앤 드롭(DnD)
- 드롭 대상 가시화(hover 강조), 성공/실패 피드백
- 실패 시 원복(revert) + 토스트, 데이터 손실 금지
- 키보드 대체 경로 제공(컨텍스트 메뉴 이동)

### 4) 리스트/그리드 뷰
- 가상 스크롤 권장, 스켈레톤 행/카드
- 빈 상태와 에러 상태를 명확히 구분(아이콘/문구/CTA)
- 정렬/필터 적용 시 즉시 피드백(로딩 상태)

### 5) 메모 에디터
- 자동저장 인디케이터(저장됨/저장 중/오류)
- 오프라인 로컬 캐시 + 온라인 복구 시 병합(충돌 해결 규칙 명시)
- 나가기 전 미저장 경고

### 6) 수집(Capture)
- 오버레이 단계: 캡처 중 → 메타 추출 → 저장 성공/실패
- 권한 문제/드롭 실패 시 인라인 가이드 + 재시도

### 7) AI 어시스턴트
- 스트리밍 상태 표시, 중지 버튼
- 요청 오류/토큰 초과: 에러 메시지 + 입력 보존 + 재시도

### 8) 검색
- 오프라인 시 의미검색 비활성, 키워드 검색만 허용(로컬 인덱스)
- 무결성: 쿼리/필터/정렬 상태 유지

### 9) 접근성(A11y)
- 라이브 피드백: aria-live("polite"/"assertive") 적절 사용
- 모달: role="dialog"/"alertdialog", 포커스 트랩, ESC 닫기
- 단축키 목록 제공(도움말/명령 팔레트)
