## 와이어프레임 체크리스트

- 목적: 오늘 빈 화면 기준으로 페이지 수/핵심 요소를 빠르게 결정
- 규칙: 1680×1050, 사이드바 336, topbar 56, tabs 34, gutter 24
- Masonry 열수 = floor((콘텐츠폭 + 24) / (카드폭160 + 24))
- 토큰 출처: `design-system/tokens-and-shell.json`

### 0) App Shell 공통 (M0)
- 레이아웃: topbar / tabs / 좌측 sidebar(336) / splitter / content area
- 공통 컴포넌트: 글로벌 검색, 알림, 프로필, 단축키 힌트, 창제어(최소/최대/닫기)
- 테마: Liquid Glass, 라이트/다크/하이콘트라스트 토글; 창 투명/데코레이션 토글

체크리스트
- [ ] topbar 좌/우 배치(제품명·전역검색·프로필)
- [ ] 탭 패턴(고정/스크롤, 새 탭, 닫기)
- [ ] 사이드바 섹션: Inbox / Projects / Tags / Views / Favorites
- [ ] 분할 프리셋(1/2, 1/3, 1/4) 및 드래그 리사이즈 핸들
- [ ] 전역 단축키: /, Ctrl/Cmd+K, Tab 순환, 사이드바 토글
- [ ] 창 투명/데코레이션 토글
- [ ] 피드백: 토스트 위치/지속시간/레이어(zIndex)
- [ ] 접근성: 포커스링, 44px 히트영역, 대비 AA
- [ ] 상태: hover/focus/active/disabled/dragOver/selected

### 1) Inbox(수집함) (M0)
핵심: 수집된 아이템 피드 + 정렬/필터 + 보기모드(List/Grid/Masonry/Justified)
- [ ] 상단: 검색창, 정렬(최신/오래됨), 필터(타입/태그)
- [ ] 콘텐츠 카드 규격: 160×200, gutter 24
- [ ] 카드 메타: 제목, sourceUrl, favicon, createdAt, aiSummary/keywords
- [ ] 보기 전환: List / Grid / Masonry / Justified
- [ ] 폴더 트리(좌), 드래그 앤 드롭 이동
- [ ] 멀티 선택(Shift/Ctrl), 벌크 액션(이동/삭제/태그)
- [ ] 컨텍스트 메뉴(우클릭)
- [ ] 로딩 스켈레톤 vs 빈 상태(empty state)
- [ ] 페이지네이션 vs 인피니트 스크롤 결정
