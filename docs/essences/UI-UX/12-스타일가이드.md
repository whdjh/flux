# 스타일가이드

이 프로젝트는 Tailwind CSS v4와 Shadcn UI를 사용한다. 일관된 디자인을 위해 테마, 컬러, 타이포그래피를 체계적으로 관리한다.

## Tailwind CSS v4

Tailwind CSS v4를 사용한다. 테마는 `tailwind.config.ts`에서 설정한다.

### 테마 설정

```ts
export default {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        // 커스텀 컬러 정의
      }
    }
  }
}
```

### 유틸리티 클래스 사용

유틸리티 클래스는 시맨틱하게 사용한다. 중복되거나 불필요한 클래스를 나열하지 않는다.

```tsx
// Good: 시맨틱한 의미
<div className="flex items-center gap-2 p-4 bg-background">

// Bad: 너무 많은 클래스
<div className="flex flex-row justify-start items-center gap-x-2 gap-y-0 p-4 px-4 py-4">
```

## Shadcn UI 커스터마이징

Shadcn UI 컴포넌트를 설치하고 프로젝트에 맞게 커스터마이징한다.

### 컴포넌트 설치

```bash
npx shadcn-ui@latest add button
npx shadcn-ui@latest add input
npx shadcn-ui@latest add dialog
```

### 커스터마이징

**원본**: `src/shared/components/ui/button.tsx`

```tsx
// Variant 추가
const buttonVariants = cva(
  "inline-flex items-center justify-center",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground",
        destructive: "bg-destructive text-destructive-foreground",
        // 커스텀 variant 추가
        custom: "bg-blue-500 text-white hover:bg-blue-600"
      }
    }
  }
);
```

## 디자인 토큰

디자인 토큰은 CSS 변수로 관리한다. 라이트/다크 모드를 지원한다.

### 컬러 시스템

```css
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 221.2 83.2% 53.3%;
  --secondary: 210 40% 96.1%;
}

.dark {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  --primary: 217.2 91.2% 59.8%;
  --secondary: 217.2 32.6% 17.5%;
}
```

### 타이포그래피

```tsx
// 헤딩
<h1 className="text-4xl font-bold tracking-tight">Title</h1>
<h2 className="text-3xl font-semibold">Subtitle</h2>
<h3 className="text-2xl font-medium">Section</h3>

// 본문
<p className="text-base leading-7">Content</p>
<p className="text-sm text-muted-foreground">Description</p>
```

### 스페이싱

```tsx
// 일관된 간격 사용
gap-1  // 4px
gap-2  // 8px
gap-4  // 16px
gap-6  // 24px
gap-8  // 32px
```

## 다크모드

다크모드는 `class` 전략을 사용한다. `<html>` 태그에 `dark` 클래스를 토글한다.

### 토글 구현

```tsx
const [theme, setTheme] = useState<'light' | 'dark'>('light');

const toggleTheme = () => {
  const newTheme = theme === 'light' ? 'dark' : 'light';
  setTheme(newTheme);
  document.documentElement.classList.toggle('dark');
};
```

### 컴포넌트 스타일

```tsx
// 다크모드 대응
<div className="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
```

## 레이아웃 패턴

Flexbox와 Grid를 사용한다. 반응형 디자인을 기본으로 한다.

### Flex 레이아웃

```tsx
// 수평 정렬
<div className="flex items-center justify-between">

// 수직 스택
<div className="flex flex-col gap-4">

// 센터 정렬
<div className="flex items-center justify-center min-h-screen">
```

### Grid 레이아웃

```tsx
// 반응형 그리드
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
```

## 애니메이션

Radix UI의 data 속성을 활용한다. 커스텀 애니메이션은 CSS `@keyframes`로 정의한다.

### Radix UI 애니메이션

```tsx
<Dialog.Content
  className="data-[state=open]:animate-in data-[state=closed]:animate-out"
>
```

### 커스텀 애니메이션

```css
@keyframes slideIn {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}

.slide-in {
  animation: slideIn 0.3s ease-out;
}
```

## 반응형 디자인

Tailwind의 모바일 퍼스트 브레이크포인트를 사용한다. 기본값은 모바일, `md`부터 태블릿, `lg`부터 데스크톱이다.

### 브레이크포인트

```tsx
<div className="
  w-full         // 모바일
  md:w-1/2       // 태블릿 (768px)
  lg:w-1/3       // 데스크톱 (1024px)
  xl:w-1/4       // 대형 (1280px)
">
```

## 접근성

시맨틱 HTML과 ARIA 속성을 사용한다. 키보드 네비게이션과 스크린 리더를 고려한다.

### 시맨틱 HTML

```tsx
// Good
<button onClick={handleClick}>Click me</button>

// Bad
<div onClick={handleClick}>Click me</div>
```

### ARIA 속성

```tsx
<button
  aria-label="Close dialog"
  aria-pressed={isPressed}
>
```
