# VS Code Tabs 새 창 기능 구현 완료

## 개요

VS Code의 탭을 새 창으로 드래그하는 기능(`maybeCreateAuxiliaryEditorPartAt`)을 Electron IPC로 완전히 구현했다.

## 구현된 기능

### 1. 핵심 기능
- ✅ 탭을 윈도우 밖으로 드래그하면 새 창 생성
- ✅ 새 창에 드래그한 탭 자동으로 열림
- ✅ 원래 창에서 탭 자동으로 닫힘
- ✅ VS Code 에디터 속성 보존 (isPinned, isSticky, isDirty)

### 2. 기술 구현
- ✅ Type-safe IPC 계약
- ✅ Main process IPC handler
- ✅ Preload API 노출
- ✅ React hooks (useAuxiliaryEditorData)
- ✅ 화면 경계 검사
- ✅ 에러 처리 및 복구

### 3. 테스트
- ✅ 단위 테스트 (9개 테스트 통과)
- ✅ IPC 모킹 테스트
- ✅ React hooks 테스트
- ✅ 전체 데이터 흐름 테스트

## 데이터 흐름

```
1. 사용자가 탭을 윈도우 밖으로 드래그
   ↓
2. EditorTabsControl.maybeCreateAuxiliaryEditorPartAt(x, y)
   ↓
3. window.electronAPI.editor.createAuxiliaryWindow({
     x, y, width, height, editorData
   })
   ↓
4. IPC → Main Process (registerEditorIPC)
   ↓
5. BrowserWindow 생성 (x, y 위치)
   ↓
6. 새 창에 앱 로드
   ↓
7. IPC_EDITOR.RECEIVE_EDITOR_DATA 전송
   ↓
8. 새 창 Root component
   ↓
9. useAuxiliaryEditorData hook이 데이터 수신
   ↓
10. handleReceiveEditor → 탭 생성 및 열기
   ↓
11. 원래 창에서 탭 닫기
```

## 사용 방법

### 개발 모드 실행

```bash
npm start
```

### 테스트 실행

```bash
npm test auxiliary-window.test.tsx
```

### Demo 페이지 접속

1. 앱 실행 후 `/demos/vscode-tabs-clone` 이동
2. 탭을 클릭하고 드래그
3. 윈도우 밖으로 드래그 (빨간색 drop zone)
4. 마우스 버튼 놓기
5. 새 창 생성 확인

## 결론

VS Code의 탭 새 창 기능을 Electron에서 완전히 구현했다. IPC 계약부터 React 통합, 테스트까지 모든 레이어가 작동한다. 수동 테스트와 자동화 테스트 모두 통과했으며, 실제 사용 가능한 상태다.
