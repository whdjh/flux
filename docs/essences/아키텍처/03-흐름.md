# 흐름

## 애플리케이션 실행 흐름

1. `npm run dev` 실행
2. Vite가 3개 번들 동시 빌드
   - Main 프로세스 (vite.main.config.ts)
   - Preload 스크립트 (vite.preload.config.ts)
   - Renderer 프로세스 (vite.renderer.config.ts)
3. Electron Forge가 Main 프로세스 실행
4. Main이 BrowserWindow 생성
5. Preload 스크립트 로드 (contextBridge 설정)
6. Renderer 프로세스 (React 앱) 시작
7. React Router가 라우팅 처리
8. 사용자 상호작용 시작

## 빌드 흐름

1. `npm run make` 실행
2. TypeScript 타입 체크
3. Vite 프로덕션 빌드 (3개 번들)
4. Electron Forge Maker 실행
   - macOS: MakerZIP
   - Windows: MakerSquirrel
   - Linux: MakerDeb, MakerRpm
5. `out/` 디렉토리에 배포 파일 생성

## Demo-First 개발 흐름

1. 아이디어 발생
2. `src/demos/` 에 새 폴더 생성
3. 빠른 프로토타입 개발
4. 테스트 및 검증
5. 검증 완료 시:
   - 코드 리팩토링
   - 테스트 작성
   - 문서 작성
   - `src/features/`로 이동
6. Demo 폴더 삭제 또는 보관

## IPC 통신 흐름

1. Renderer가 preload API 호출
   ```ts
   window.electron.readFile('/path/to/file')
   ```
2. Preload의 contextBridge가 IPC 메시지 전송
3. Main 프로세스 IPC 핸들러 수신
4. Main이 Node.js API로 작업 수행
5. 결과를 IPC로 Renderer에 반환
6. Renderer가 상태 업데이트 (Zustand)

## 데이터 흐름

1. UI 상호작용 (React 컴포넌트)
2. Zustand Store 액션 dispatch
3. Store가 IPC 호출 또는 로컬 상태 변경
4. Backend Use Case 실행 (필요 시)
5. Infrastructure Layer (DB 접근)
6. 결과 반환 및 Store 업데이트
7. React 컴포넌트 리렌더링

## 보안 검증 흐름

1. 사용자 입력
2. Layer 1: CSP 헤더 검증
3. Layer 2: Security Headers 확인
4. Layer 3: Zod 스키마 검증
5. Layer 4: Rate Limiting 체크
6. Layer 5: Path Validation (파일 접근 시)
7. 안전한 처리 진행
