## 🔄 작동 원리

### TodoWrite 발생 시

#### 1. 세션 ID 추출
```bash
SESSION_ID="73f472cd-1e45-4150-9711-82f3468a7276"
SHORT_ID="73f472cd"
DATE="2025-10-19"
TIME="04:16:25"
```

#### 2. 세션 파일 확인/생성
```python
session_file = f"sessions/{SHORT_ID}.md"

if not exists(session_file):
    # 새 세션 파일 생성
    create_session_file(session_id, title, start_time)
```

#### 3. TodoWrite 추가
```python
# 기존 세션 파일에 새 TodoWrite 섹션 추가
append_todowrite(session_file, time, tasks)
```

#### 4. 날짜 인덱스 업데이트
```python
date_file = f"by-date/{DATE}.md"

if not session_in_index(date_file, SHORT_ID):
    # 이 날짜 인덱스에 세션 참조 추가
    add_session_reference(date_file, session_info)
else:
    # 세션 통계 업데이트
    update_session_stats(date_file, SHORT_ID, new_stats)
```

## 💡 설계 원칙

### 1. Single Source of Truth
```
실제 데이터: sessions/73f472cd.md (한 곳에만)
참조/인덱스: by-date/2025-10-19.md (링크만)

수정 시: sessions/ 파일만 업데이트
```

### 2. No Duplication
```
❌ 잘못된 방식:
sessions/73f472cd.md ← 전체 데이터
by-date/2025-10-19.md ← 같은 데이터 복사

✅ 올바른 방식:
sessions/73f472cd.md ← 전체 데이터
by-date/2025-10-19.md ← 참조 + 요약만
```

### 3. Flexible Access
```
세션별: sessions/73f472cd.md
날짜별: by-date/2025-10-19.md
월별(미래): by-month/2025-10.md
프로젝트별(미래): by-project/electron.md

모두 같은 데이터(sessions/)를 참조
```

## 🚀 장점

### 1. 중복 제거
- 디스크 용량 절약
- 데이터 불일치 방지
- 수정 시 한 곳만 변경

### 2. 유연한 접근
- 날짜로 찾기: `by-date/`
- 세션으로 찾기: `sessions/`
- 미래 확장 가능: `by-project/`, `by-tag/`

### 3. 파일 이동 불필요
```
세션이 날짜를 넘어가도:
- sessions/: 그대로 유지
- by-date/: 시작일에 참조 추가
→ 파일 옮길 필요 없음!
```

### 4. Git 친화적
```
sessions/: 실제 커밋 대상
by-date/: 자동 생성 가능 (선택적 커밋)

→ 필요시 by-date/를 .gitignore에 추가
→ sessions/만으로 모든 데이터 복원 가능
```
