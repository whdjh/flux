## 문서 구조 개요

```
docs/
├── 00-시작/        (4개) ← 현재 위치
│   └── 시작하기, 개요, 구조, README
│
├── 01-워크플로우/  (5개) ← Demo 단계
│   └── 시작가이드, 워크플로우, 환경설정, 개발원칙, 프로젝트철학
│
├── 02-아키텍처/    (15개) ← 통합 단계
│   ├── 핵심: 아키텍처, IPC, 보안, 상태관리, 빌드, 테스트
│   ├── 스타일: 스타일링, 스타일가이드
│   ├── 가이드: 데이터베이스, 라우팅, 프로젝트개요
│   └── 명세: 파일탐색기, 크롬탭, 분할뷰, 탭시스템
│
└── 03-참고자료/    (26개) ← 검색 전용
    ├── 비전 (4개), ADR (3개), 참고 (2개)
    ├── 가이드 (8개), 명세 (4개)
    └── 외부자료/ - 큐레이션된 학습 자료 (6개)
```

---

## 문서 사용 팁

문서는 계층적으로 로드한다. 00-시작/ → 01-워크플로우/ (Demo) → 02-아키텍처/ (통합) → 03-참고자료/ (검색)

| 키워드 | 문서 |
|--------|------|
| 환경 설정, 시작 | 개발-시작가이드.md, 개발-환경설정.md |
| IPC, 상태, 보안 | 06-IPC.md, 10-상태관리.md, 07-보안.md |
| 테스트, 스타일 | 09-테스트.md, 11-스타일링.md, 12-스타일가이드.md |
| 컴포넌트 | 명세-*.md 시리즈 |
