# 창 관리

## 목적

깊이 모델(5장)의 네 단계 — 감시·캡처·포스트잇·몰입 — 중에서 "포스트잇"과 "몰입"의 전환을 매끄럽게 한다. 사용자가 게임이나 작업 중 영감이 떠오르면 앱을 전환하지 않고 바로 기록한다. 투명 UI라서 시야를 가리지 않는다.

전환 비용 제거가 핵심이다. 풀 앱 ↔ 포스트잇 ↔ 분할 뷰 사이의 모드 전환이 단축키 한 번으로 일어난다.

## 입력

모드 전환 트리거
- 우측 상단 포스트잇 버튼 (풀 ↔ 포스트잇)
- 단축키 (사용자 지정 가능)
- 항상 위 토글 (포스트잇 모드에서)

레이아웃 조작
- 분할 뷰 프리셋 (1/2, 1/3, 1/4)
- 드래그 리사이즈 (사이드바·분할 비율)
- 사이드바 토글 (좌·우)
- 탭 재정렬·핀 고정

## 출력

창 모드
- 풀 앱 (전체 화면 또는 일반 윈도우)
- 포스트잇 (Liquid Glass UI, 투명 배경, 항상 위)
  - 메모 기능 그대로, UI 간소화
  - 사용자가 크기·위치 지정
  - 여러 창 동시
- 분할 뷰 (최대 4분할, 프리셋 + 커스텀 비율)

레이아웃 자동 저장
- 마지막 사이드바 폭, 분할 비율, 탭 순서·핀 상태
- 앱 재시작 시 복원

이벤트
- `window.mode.changed` (full / postit / split)
- `layout.saved` (auto)

## 흐름

포스트잇 전환
1. 사용자가 풀 앱에서 포스트잇 버튼 누름
2. 현재 노트가 투명 창으로 분리, 풀 앱은 백그라운드
3. 항상 위 + Liquid Glass UI 적용
4. 다른 작업 중에도 시야 안 가림

여러 포스트잇
- 새 포스트잇 버튼으로 추가 생성
- 각각 다른 노트 또는 빈 노트
- 위치·크기 독립

분할 뷰
1. 사용자가 분할 프리셋 선택 (1/2, 1/3, 1/4)
2. 각 분할에 다른 노트·아이템 디테일·검색 결과 등 배치
3. 드래그로 비율 조절, 자동 저장

레이아웃 복원
1. 앱 종료 시 현재 레이아웃 직렬화
2. 다음 시작 시 복원 (사이드바 폭, 분할, 탭 상태)

## 예외

OS 호환성
- macOS·Windows·Linux 각각 투명 창 API 다름
- Liquid Glass 못 쓰는 OS는 반투명 폴백
- 항상 위 권한 요청 (OS별 다름)

다중 모니터
- 포스트잇 위치를 모니터 단위로 저장
- 모니터 분리·재연결 시 적절한 폴백 (가장 가까운 모니터)

작은 화면
- 분할 뷰 1/4은 화면 폭 임계 미만이면 비활성
- 모바일은 분할 뷰 없음 (탭 전환만)

레이아웃 망가짐
- 사용자가 "기본 레이아웃 복원" 버튼으로 리셋

## 하지 않는 것

- 멀티 윈도우 (독립 창 여러 개) — 포스트잇은 예외
- 커스텀 테마 에디터
- 플러그인·확장 시스템
- 윈도우 매니저 통합 (i3, yabai 등)
- 모바일 분할 뷰 (모바일은 탭만)
