# AI

## 목적

수집·정리·검색·메모를 강화한다. 사용자가 시키지 않아도 메타데이터를 붙이고("시키지 않게" 원칙), 사용자가 묻지 않아도 관련을 제안한다. 단, 모든 행위는 제안이다 — 실행은 사용자가 한다.

자율 에이전트가 아니다. AI가 사용자 대신 수집하거나 정리를 실행하면 예측 불가능해진다. AI 역할은 메타데이터 자동 부착(요약·키워드)과 연결 제안에 한정한다. 보여주되 묻지 않고, 실행하지 않는다. 틀리면 사용자가 검토할 때 고친다.

## 입력

자동 트리거
- 아이템 수집 직후 (요약·키워드 생성)
- 노트 작성 중 (관련 항목 제안)
- 시간·주제 클러스터 감지 (세션 자동 생성)
- 활성 맥락 변경 (링크 미리보기 추출 기준 갱신)

수동 트리거
- 채팅 인터페이스 (우측 사이드바, 메모 UI와 토글)
- 메시지 입력
- 모델 선택 드롭다운 (OpenRouter 모델 목록)
- 음성 입력 버튼 (Elevenlabs STT)

대상
- 아이템 본문·메타·이미지(OCR)
- 노트 내용
- 검색 쿼리
- 사용자 활성 맥락(현재 폴더·세션)

## 출력

자동 부착
- AI 요약 (1~3줄)
- AI 키워드 (3개)
- AI 자동 세션 (시간+주제 묶음 제안)

링크 미리보기 (활성 맥락 기반)
- 활성 맥락이 "옷"이면 쇼핑몰 링크에서 상의 이미지만 추출
- 활성 맥락이 없으면 일반 OG 메타 사용
- 2장 3단계(포착) 마찰 감소

채팅 응답
- RAG: 수집한 정보 기반 답변
- 출처 인용 (어느 아이템·노트에서 가져왔는지)
- MCP 서버 호출 (확장 도구 — 사용자가 명시적으로 연결한 경우)

음성
- 마이크 입력 → STT → 텍스트 메시지
- 응답 텍스트 → TTS → 재생

이벤트
- `ai.metadata.attached` (item_id, summary, keywords)
- `ai.session.suggested` (item_ids, theme)
- `ai.suggestion.shown` (document_id, related_ids)

## 흐름

수집 후 메타데이터
1. 아이템 수집 직후 AI 큐에 enqueue
2. 백그라운드 워커가 OpenRouter 호출 (요약·키워드)
3. SQLite 메타 업데이트
4. UI에 즉시 반영 (사용자가 inbox 봤을 때 이미 붙어있음)

노트 작성 중 제안
1. 사용자가 노트 입력 중 (debounce)
2. 노트 텍스트 + 임베드된 아이템을 컨텍스트로 임베딩 검색
3. 우측 패널에 관련 아이템·노트 표시
4. 사용자가 클릭하면 노트로 끌어올 수 있음

채팅 RAG
1. 사용자가 메시지 입력
2. 메시지를 임베딩 → 관련 아이템·노트 검색
3. 검색 결과 + 원래 메시지를 모델에 전송
4. 응답 + 인용 표시

세션 자동 생성
1. 백그라운드 워커가 최근 수집 패턴 분석
2. 시간+주제 클러스터 감지하면 세션 제안
3. 사용자에게 알림 (실행은 사용자가 결정)

## 예외

오프라인
- 수집 시 자동 요약·키워드는 큐에 보류, 온라인 복귀 시 처리
- 채팅은 명시적 오프라인 표시 후 비활성

모델 호출 실패
- 재시도 (지수 백오프)
- 임베딩만이라도 로컬 폴백 (선택)
- 사용자가 큐 상태 확인 가능

부정확한 메타
- 사용자가 검토할 때 직접 수정 가능 (요약·키워드 인라인 편집)
- AI의 메타 부착 기준은 사용자가 커스터마이즈하지 않음 (제한 의도적)

비용 통제
- 모델 호출 단가별 토글
- 무료 티어 한도 도달 시 사용자에게 알림
- 자동 호출 빈도 사용자가 조절 가능

권한
- 협업 노트 RAG 시 권한 있는 데이터만 컨텍스트에 포함

## 하지 않는 것

- 자율 에이전트 (사용자 대신 외부 행동 실행 — 웹 크롤링·이메일·외부 API). 단, **로컬 컴퓨터 안 자료를 발견·인덱싱**하는 갈래는 별도 핵심 기능이라 본 부정에 해당하지 않는다 → `essences/기능명세/핵심-AI-자동-수집.md`
- 이미지 생성
- 코드 생성·실행
- AI 메타 기준 사용자 커스터마이즈 (자동성 보장)
- AI 자체 결정 실행 (모든 행위는 제안만)
