# 기능명세

9개 기능의 개요와 우선순위. 기능별 상세는 각 하위 파일, 배경은 `essences/기능명세/_요약.md`와 `essences/앱-재정의.md` 8장 참조.

## 중심 루프 + 강화

```
중심 루프:  수집 → 정리 → 메모 → 검색  (다시 수집으로)

강화:
  수집 ← 창 관리 (포스트잇, always on top)
  정리 ← AI (자동 태깅·요약)
  메모 ← 협업 (공동 편집)
  검색 ← AI (의미 검색)
  전체 ← 동기화 (멀티 디바이스)
  전체 ← 공유 (결과물 전달)
```

## 원칙

1. **끊기지 않게 > 시키지 않게 > 잊지 않게 > 기다리지 않게** (충돌 시 이 순서)
2. **보존**: 원본 유지, 비파괴 편집. 기능이 아니라 모든 기능의 전제
3. **AI 제안, 사용자 실행**: AI는 제안만 하고 실행 권한은 사용자에게

## 기능별 상세 파일 형식

각 `<기능>.md`는 `essences/기능명세/` 하위의 원재료를 참고해 다음 템플릿으로 채운다.

```markdown
# {기능명}

## 목적
{왜 필요한지 — 요구사항/가설과 연결}

## 입력
{사용자 행위, 외부 이벤트, API 요청}

## 출력
{화면 변화, 저장 내용, API 응답}

## 흐름
1. {단계}

## 예외
{에러 케이스, 오프라인 동작, 충돌 시}

## 관련 에센스
- essences/기능명세/...

## 관련 파일 (구현 이후)
- packages/{shared,api-client,store,editor-core,ui}/...
- apps/{cli,frontend/web,frontend/desktop,frontend/mobile,frontend/extension}/...
- apps/backend/... (계획)
```
