# 수집

## 목적

생각의 흐름을 끊지 않고 자료를 저장한다. 수집 순간에는 의미 판단("이게 왜 중요하지?")만 일어나고, 분류 판단("어디에 넣지?")은 하지 않는다. 분류는 AI가 메타데이터(요약·키워드)를 붙이고, 사용자가 검토하면서 자연스럽게 일어난다.

기존 도구의 마찰 — 단축키 누르고, 폴더 고르고, 태그 붙이고, 메모하기 — 가 이 기능에서는 없다. "Alt+우클릭 한 번"과 "Share Sheet 한 번"이 끝이다. 100ms 안에 끝나서 원래 보던 화면으로 즉시 돌아간다.

## 입력

데스크톱
- 브라우저 확장 Alt+우클릭 (텍스트 하이라이트, 이미지, 링크, 동영상)
- 데스크톱 앱 드래그앤드롭 (파일, 텍스트, 이미지)
- 클립보드 자동 감지 (스크린샷, 복사된 텍스트/이미지)

모바일
- Share Extension (다른 앱에서 "공유 → Flux")
- 카메라 (즉시 촬영)
- 클립보드 감지 (앱 진입 시)
- 음성 메모

확장-앱 통신
- 로컬 서버(127.0.0.1) 경유. 외부 노출 없음
- 로그인된 같은 사용자만 수신

## 출력

저장 데이터
- 원본 (URL이면 페이지 메타·파비콘, 이미지면 바이너리, 텍스트면 본문)
- 메타데이터: 제목, URL, 파비콘, 출처 앱, 타임스탬프
- AI 자동 부착: 1~3줄 요약, 키워드 3개

UI 피드백
- 수집 성공 토스트 (작은 알림, 즉시 사라짐)
- Inbox 카운트 증가
- 활성 맥락이 있으면 해당 폴더, 없으면 inbox

이벤트
- `item.created` (id, source, ts, context_id?)
- API: `POST /api/items` → 201 + item id

## 흐름

1. 사용자가 트리거(확장 Alt+우클릭, 드래그, Share Sheet 등)를 발동한다
2. 클라이언트가 원본+메타데이터를 추출한다 (DOM 파싱, 파일 읽기, MIME 감지)
3. 로컬 SQLite에 즉시 INSERT (낙관적 저장, 100ms 안)
4. UI에 성공 토스트 표시 + Inbox 카운트 갱신
5. 백그라운드에서 AI 큐에 푸시 → 요약·키워드 생성 → 메타 업데이트
6. 백그라운드 동기화 큐에 푸시 → 다른 기기로 전파

수집 시점에는 분류 다이얼로그를 띄우지 않는다. 활성 맥락(현재 열린 폴더·세션)이 있으면 거기로, 없으면 inbox로 자동 배치한다.

## 예외

오프라인
- 로컬 SQLite에 저장은 정상 동작
- AI 큐·동기화 큐는 보류, 온라인 복귀 시 자동 처리

큰 파일
- 100MB 초과 이미지/동영상은 사용자에게 확인 (저장 vs 링크만)
- 동영상 파일 자체 저장은 기본적으로 하지 않음 — 링크와 썸네일만

권한 거부
- 카메라·마이크 거부 시 해당 입력만 비활성, 다른 경로는 정상
- 클립보드 감지는 앱 활성 시점에만 (백그라운드 폴링 안 함)

중복
- 같은 URL이라도 다른 맥락에서 수집했을 수 있어 자동 제거하지 않음
- 검색 결과에서 사용자가 인지하고 정리

확장 통신 실패
- 로컬 서버 미기동 시 확장 아이콘에 경고 표시
- 앱 실행 후 자동 재연결

## 하지 않는 것

- 웹페이지 전체 아카이빙 (Pocket·Instapaper 영역)
- 동영상 파일 자체 저장 (링크와 썸네일만)
- RSS 피드 자동 수집
- 이메일 연동
- 자동 중복 제거
- 수집 시점 분류 다이얼로그 (AI 자동 메타데이터로 대체)
