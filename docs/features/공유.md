# 공유

## 목적

정보 흐름의 마지막 단계 — "나감". 노트를 다른 사람에게 보여주거나 다른 도구로 옮길 때 흐름이 끊기지 않게 한다. Flux 안에서 모든 것을 끝내는 올인원이 아니라, Flux에서 생각을 만들고 다른 도구로 넘기는 구조다(9장).

협업이 "함께 만든다"면 공유는 "보여주거나 넘긴다"다. 두 가지를 분리한다. 보여줄 때(읽기 전용 링크)와 넘길 때(파일 내보내기)는 다른 흐름이다.

## 입력

링크 공유
- 노트의 "공유" 메뉴
- 권한 선택: 읽기 전용 (기본) / 편집 가능 (→협업 전환)
- 링크 만료 옵션 (없음/날짜)
- 링크 비활성화

내보내기
- "내보내기" 메뉴 (Markdown / PDF)
- 범위 선택 (현재 노트 / 폴더 단위)
- 임베드된 아이템 포함 여부

## 출력

읽기 전용 링크
- 토큰 기반 URL (예측 불가능한 해시)
- 링크 받은 사람은 가입 없이 접근
- 노트 내용 + 임베드된 아이템 메타 표시
- 편집 UI 비활성, 댓글도 비활성 (읽기 전용)

편집자 초대 링크
- 협업으로 전환 (→협업 참조)
- 링크 클릭 시 가입·로그인 후 편집자 등록

내보내기 파일
- Markdown(.md) — 슬래시 블록을 표준 마크다운으로
- PDF — 브라우저 인쇄 또는 서버 렌더 (이미지·서식 보존)
- 임베드된 아이템은 인용 형태로 (URL·요약·키워드)

이벤트
- `share.link.created/revoked`
- `export.completed` (format, size)

## 흐름

읽기 전용 링크
1. 사용자가 노트의 "공유" → "읽기 전용 링크"
2. 백엔드가 토큰 생성 → 링크 반환
3. 받은 사람이 링크 열면 노트 렌더링 (가입 불필요)
4. 사용자는 언제든 비활성화 가능

편집자 초대 (협업 전환)
1. "공유" → "편집 가능 링크"
2. 받은 사람이 가입·로그인
3. 편집자로 등록 → 협업 모드 (→협업 참조)

Markdown 내보내기
1. "내보내기" → "Markdown"
2. 클라이언트가 노트 변환 (슬래시 블록 → 표준 마크다운)
3. .md 파일 다운로드 (이미지는 인라인 또는 zip 묶음)

PDF 내보내기
1. "내보내기" → "PDF"
2. 브라우저 인쇄 다이얼로그 또는 서버 렌더
3. .pdf 파일 다운로드 (서식·이미지 보존)

## 예외

링크 도용
- 토큰 노출 시 사용자가 무효화 (revoke)
- 만료 시간 옵션
- IP 단위 rate limit (운영)

큰 노트 PDF
- 페이지 분할 자동
- 이미지 다수 포함 시 클라이언트 메모리 한도 → 서버 렌더 폴백

비공개 임베드
- 임베드된 아이템 중 협업 노트의 비공개 자료 → 공유 링크에서는 가려짐
- "이 내용은 비공개" 플레이스홀더

내보내기 후 경로 단절
- 외부 도구로 옮기면 Flux의 내부 링크는 작동 안 함
- 명시적 동작 (Flux 안에서 끝나는 올인원 아님)

## 하지 않는 것

- 퍼블리싱 (블로그처럼 공개 페이지 생성)
- 소셜 피드 (Flux 안에서 다른 사용자 노트 발견)
- 템플릿 마켓플레이스
- 커스텀 도메인 호스팅
- API 공개 (외부에서 노트 조회)

## 관련 에센스

- `essences/앱-재정의.md` — 5장 정보 흐름(나감), 8장 공유 범위, 9장 비범위
- `essences/기능명세/_요약.md` — 공유는 명시적 섹션 없음, 협업의 부속 (1장 9개 기능 중)

## 관련 파일 (구현 이후)

- `apps/backend/` — 공유 토큰 발급·검증, 읽기 전용 렌더, 내보내기 작업
- `apps/frontend/web/` — 공유 메뉴, 토큰 관리 UI, 내보내기 다이얼로그
- `apps/frontend/web/share/[token]/` — 읽기 전용 노트 페이지 (가입 불필요)
- `apps/frontend/desktop/` — 데스크톱에서 PDF 인쇄
- `packages/api-client/` — share·export 클라이언트
- `packages/store/` — share_token 스키마 (token, expires_at, document_id, mode)
- `packages/shared/` — ShareToken·ExportFormat 타입
- `packages/editor-core/` — loro → Markdown 변환
